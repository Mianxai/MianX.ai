# Mianx.ai Multi-Agent Negotiation Framework

> **Negotiation allows bounded participants to exchange proposals
> inside a governed decision domain.**
>
> Negotiation does not create the decision domain.
>
> Negotiation does not create authority.
>
> Permanent:
>
> ```text
> NEGOTIATE
> WITHIN
> AUTHORITY
>
> NOT
>
> NEGOTIATE
> AUTHORITY
> INTO
> EXISTENCE
> ```

---

# 1. Purpose

This document defines how Mianx.ai may allow independently governed
Agents or Teams to negotiate bounded questions concerning:

```text
TASK
EXECUTION
PLAN

PRIORITY

SEQUENCING

DEADLINE

RESOURCE
USE

CAPACITY

COST

QUALITY
TARGET

WORK
DIVISION

HANDOFF

BID
TERMS

SCHEDULE

DEPENDENCY
RESOLUTION
```

without permitting negotiation to weaken mandatory enterprise controls.

---

# 2. Mission

The mission is:

> **Enable bounded, transparent and auditable Multi-Agent negotiation
> where participants can exchange proposals and reach operational
> agreements only within explicitly delegated decision domains and
> without creating or transferring Security authority.**
