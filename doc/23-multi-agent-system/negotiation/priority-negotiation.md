# Mianx.ai Multi-Agent Priority Negotiation

> **Priority determines ordering among work that is already eligible.**
>
> Priority does not make ineligible work eligible.
>
> Priority does not make unauthorized work authorized.
>
> Permanent:
>
> ```text
> PRIORITY
> CHANGES
> ORDER
>
> NOT
>
> AUTHORITY
> ```

---

# 1. Purpose

This document defines how Mianx.ai may negotiate and govern Priority
when multiple independently eligible:

```text
TASKS

WORKLOADS

WORKFLOWS

TEAMS

AGENTS

RESOURCE
REQUESTS
```

compete for limited execution capacity.

---

# 2. Mission

The mission is:

> **Provide fair, explainable, Security-preserving and auditable
> mechanisms for deciding which eligible work should receive attention
> first without allowing urgency or business importance to become
> privilege escalation.**
