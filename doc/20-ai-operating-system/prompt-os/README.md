# Mianx.ai Prompt Operating System

> **The Prompt Operating System is the governed instruction-composition
> layer of the Mianx.ai AI Operating System.**
>
> **It transforms enterprise governance, organizational hierarchy,
> role-specific policy, Project and Customer context, Task requirements,
> Model constraints, Tool permissions, and runtime Context into bounded
> prompts for AI Agents.**
>
> **Prompt OS does not create authority. It represents and carries
> authority that already exists through Founder governance, Enterprise
> Governance, AI OS Governance, AI Workforce controls, approved
> delegation, Project policy, Customer policy, Tenant policy, and runtime
> authorization.**
>
> **A prompt cannot grant an Agent a capability that the Agent does not
> already possess. A prompt cannot authorize an otherwise unauthorized
> Model, Tool, side effect, Customer scope, Tenant scope, Production
> operation, or Founder-reserved action.**
>
> **Lower Prompt OS layers must not override higher-authority layers.
> Dynamic Project, Customer, Tenant, Workflow, Task, user, tool, retrieved
> Memory, or external content must never silently become trusted governance
> instructions.**
>
> **The eight Prompt OS source documents currently exist as documentation.
> Their existence does not prove that a runtime prompt compiler, layer
> resolver, prompt registry, prompt validator, prompt signing service,
> runtime assembler, injection-defense engine, or Production Prompt OS is
> implemented or operational.**
