# Mianx.ai Agent Persona Library

> **This document defines the governed catalog of reusable Personas
> available to the Mianx.ai Agent Framework.**
>
> The Persona Library answers:
>
> ```text
> WHAT PERSONAS EXIST?
>
> WHAT PERSONA VERSION EXISTS?
>
> WHAT IS EACH PERSONA FOR?
>
> WHAT AGENT TYPES MAY BE COMPATIBLE?
>
> WHAT ROLES MAY BE COMPATIBLE?
>
> WHAT BEHAVIOR PROFILES DOES IT REFERENCE?
>
> WHAT LIFECYCLE STATE IS IT IN?
>
> WHAT PROJECT / CUSTOMER / TENANT
> RESTRICTIONS APPLY?
>
> WHAT PERSONA SUPERSEDES IT?
>
> WHAT SECURITY RESTRICTIONS APPLY?
> ```
>
> The Persona Library does **not** answer:
>
> ```text
> IS THIS PERSONA ASSIGNED TO THIS AGENT?
>
> IS THIS AGENT AUTHORIZED TO USE IT NOW?
>
> MAY THIS AGENT EXECUTE THIS ACTION?
>
> MAY THIS AGENT USE THIS TOOL?
>
> MAY THIS AGENT ACCESS THIS TENANT?
>
> MAY THIS AGENT OPERATE IN PRODUCTION?
> ```
>
> Permanent rule:
>
> ```text
> PERSONA LIBRARY
> =
> GOVERNED CATALOG
>
> NOT
>
> AUTHORITY SYSTEM
> ```
>
> Persona Library runtime storage, discovery, compatibility resolution,
> indexing, caching, lifecycle enforcement, Revocation propagation,
> Project/Customer/Tenant isolation, integrity, and Production catalog
> operation remain `NOT_PROVEN` unless implementation Evidence exists.

# 2. Persona Library Mission

The mission is:

> **Provide a reusable, governed, discoverable, Version-aware catalog of
> approved Persona definitions and metadata so Mianx.ai can scale Agent
> behavior consistently across roles, Projects, Customers, Tenants and
> Industry Operating Systems without turning catalog presence,
> compatibility, recommendation, popularity, or discoverability into
> hidden security authority.**

> **A governed catalog of Persona identities, Versions, lifecycle state,
> classification, compatibility, applicability, behavioral references,
> restrictions and discovery metadata.**
