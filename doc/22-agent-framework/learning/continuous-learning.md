# Mianx.ai Agent Continuous Learning

> **This document defines how one individual Mianx.ai Agent may learn
> from experience without turning experience directly into
> uncontrolled self-modification.**
>
> The permanent rule is:
>
> ```text
> LEARNING
> =
> GOVERNED IMPROVEMENT PROCESS
>
> NOT
>
> SELF-AUTHORIZED
> PRODUCTION MUTATION
> ```
>
> Therefore:
>
> ```text
> OBSERVATION
> ≠
> TRUTH
>
> FEEDBACK
> ≠
> TRUTH
>
> SUCCESS
> ≠
> GENERAL RULE
>
> FAILURE
> ≠
> AGENT DEFECT
>
> HIGH SCORE
> ≠
> SAFE IMPROVEMENT
>
> LEARNED PATTERN
> ≠
> CANONICAL KNOWLEDGE
>
> CANDIDATE MEMORY
> ≠
> APPROVED MEMORY
>
> CANDIDATE PROMPT CHANGE
> ≠
> ACTIVE PROMPT
>
> CANDIDATE SKILL
> ≠
> REGISTERED SKILL
>
> CANDIDATE CAPABILITY
> ≠
> ASSIGNED CAPABILITY
>
> CANDIDATE AGENT VERSION
> ≠
> ACTIVE AGENT VERSION
>
> LEARNING IMPROVEMENT
> ≠
> PRODUCTION AUTHORIZATION
> ```
>
> A learning process may discover:
>
> ```text
> WHAT WORKED
>
> WHAT FAILED
>
> WHAT WAS SLOW
>
> WHAT WAS UNCLEAR
>
> WHAT REQUIRED ESCALATION
>
> WHAT TOOL WAS INEFFECTIVE
>
> WHAT PLAN WAS WEAK
>
> WHAT KNOWLEDGE WAS MISSING
>
> WHAT PROMPT CAUSED ERROR
>
> WHAT PATTERN MAY GENERALIZE
> ```
>
> but every material behavioral change must travel through governed
> validation and promotion.
>
> Runtime continuous-learning services, feedback pipelines,
> experimentation infrastructure, learning stores, automated candidate
> generation, online adaptation, regression detection, learning
> promotion, rollback, Project/Customer/Tenant learning isolation, and
> Production learning remain `NOT_PROVEN` until actual implementation
> Evidence exists.

# 2. Continuous Learning Mission

The mission is:

> **Improve individual-Agent quality, reliability, efficiency, and
> decision support over time while preserving external governance,
> Version control, Security, isolation, evidence, rollback, and Human
> authority.**
