# Mianx.ai Agent Framework

> **The Mianx.ai Agent Framework defines the governed standard for what an
> individual AI Agent is, how it is described, what it is allowed to do,
> what capabilities it possesses, which tools and skills it may use, how
> it plans and executes work, how it accesses Memory, how it is evaluated,
> how it communicates, how its lifecycle is controlled, and what Evidence
> is required before it may operate in Production.**
>
> **The Agent Framework is not the AI Workforce organizational structure.**
>
> **The Agent Framework is not the complete AI Operating System.**
>
> **The Agent Framework is not the Memory Engine.**
>
> **The Agent Framework is not the Multi-Agent System.**
>
> **It is the governed individual-Agent foundation used by those systems.**
>
> **An Agent definition does not mean an Agent is allocated.**
>
> **An allocated Agent does not mean it is active.**
>
> **An active Agent does not mean it has unrestricted authority.**
>
> **A capable Agent does not mean it is permitted to use every capability.**
>
> **A Model response does not become an approved Agent action
> automatically.**
>
> **A registered Agent does not become Production-authorized automatically.**
>
> **Every live Agent must remain subordinate to current identity,
> authorization, Project scope, Customer scope, Tenant scope, governance,
> security, budgets, approvals, evidence requirements, and Founder
> authority.**

---

# 1. Purpose

This module establishes the enterprise framework for defining,
constructing, configuring, governing, evaluating, securing, operating,
and retiring individual AI Agents throughout the Mianx.ai ecosystem.

It provides one governed Agent model that can be reused across:

- MianX Core Platform;
- Mianx.ai AI Operating System;
- Shared AI Workforce;
- Project Factory;
- multiple Projects;
- multiple Customers;
- multiple Tenants;
- Industry Operating Systems;
- Customer Editions;
- internal enterprise operations;
- Human-AI collaboration;
- future autonomous enterprise capabilities.

---

# 2. Agent Framework Mission

The mission is:

> **Create reusable AI Agents that are capable enough to perform valuable
> enterprise work, constrained enough to remain safe, explicit enough to
> be auditable, modular enough to be reused, and governed enough to
> operate across many Projects and Customers without losing control.**

# 5. Primary Architectural Boundary

The Agent Framework answers:

> **What is one Mianx.ai Agent and what rules govern that Agent?**

It does not independently answer:

> **How should the entire AI workforce be organized?**

or:

> **How should hundreds of Agents coordinate with one another?**

Those responsibilities belong to other modules.

# 182. Anti-Patterns

Avoid:

- Agent definitions without stable IDs;
- Agents with unrestricted Tool access;
- hidden permissions;
- role and permission conflation;
- Customer-global Context by default;
- Tenant-global Context by default;
- hardcoded secrets;
- unbounded Model usage;
- uncontrolled self-modification;
- Agent output treated as fact automatically;
- Agent output treated as approval automatically;
- Tool success assumed without Evidence;
- Agent definitions directly coupled to one Model unnecessarily;
- no Versioning;
- no evaluation;
- no monitoring;
- no failure model;
- no lifecycle;
- no kill switch;
- no audit trail;
- no Project isolation;
- no Customer isolation;
- no Tenant isolation;
- uncontrolled durable Memory writes;
- Persona text used as authorization;
- Agent-to-Agent messages trusted automatically;
- fake Production claims.
