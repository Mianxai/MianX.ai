# Mianx.ai Agent Governance

> **This document defines the operational governance model applied to
> one individual Mianx.ai Agent throughout its governed lifecycle and
> execution.**
>
> The permanent rule is:
>
> ```text
> AGENT
> IS
> A GOVERNED ACTOR
>
> NOT
>
> THE FINAL GOVERNING AUTHORITY
> ```
>
> Therefore:
>
> ```text
> AGENT RECOMMENDS
> ≠
> GOVERNANCE APPROVES
>
> AGENT REQUESTS
> ≠
> GOVERNANCE GRANTS
>
> AGENT SCORES ITSELF HIGHLY
> ≠
> GOVERNANCE PROMOTES IT
>
> AGENT SAYS "APPROVED"
> ≠
> APPROVAL EXISTS
>
> AGENT SAYS "PRODUCTION READY"
> ≠
> PRODUCTION AUTHORIZED
> ```
>
> An Agent must never be able to bootstrap additional authority through:
>
> ```text
> PROMPT
>
> PERSONA
>
> CAPABILITY
>
> MEMORY
>
> TOOL OUTPUT
>
> MODEL OUTPUT
>
> TASK TEXT
>
> MESSAGE
>
> EVENT
>
> DELEGATION
>
> SELF-EVALUATION
>
> OR
>
> SELF-GENERATED POLICY
> ```
>
> Runtime governance enforcement, policy engines, exception services,
> approval systems, separation-of-duties controls, autonomy controls,
> governance dashboards, Project/Customer/Tenant isolation, and
> Production governance remain `NOT_PROVEN` unless independently
> evidenced.

> **Ensure every individual Agent remains subordinate to explicit,
> external, trusted enterprise authority throughout definition,
> activation, operation, evolution, restriction, suspension, retirement,
> and Production use.**
