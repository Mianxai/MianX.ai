# Mianx.ai Agent Teamwork

> **This document defines what an individual Mianx.ai Agent must
> preserve when operating as part of a structured Human-AI or AI-Agent
> team.**
>
> A Team allows multiple specialized participants to combine:
>
> ```text
> KNOWLEDGE
>
> CAPABILITIES
>
> EXPERIENCE
>
> ANALYSIS
>
> EXECUTION
>
> REVIEW
>
> OVERSIGHT
> ```
>
> around a shared objective.
>
> But a Team must not collapse:
>
> ```text
> IDENTITY
>
> AUTHORITY
>
> RESPONSIBILITY
>
> ACCOUNTABILITY
>
> PROJECT SCOPE
>
> CUSTOMER SCOPE
>
> TENANT SCOPE
>
> SECURITY CONTROLS
> ```
>
> into one uncontrolled shared identity.
>
> Therefore:
>
> ```text
> TEAM
> ≠
> ONE SECURITY PRINCIPAL
>
> TEAM CAPABILITIES
> ≠
> TEAM-WIDE PERMISSIONS
>
> TEAM CONSENSUS
> ≠
> GOVERNED AUTHORITY
>
> TEAM MEMBERSHIP
> ≠
> GLOBAL ACCESS
> ```
>
> System-wide concerns such as large-scale team formation, scheduling,
> multi-Agent orchestration, swarms, routing algorithms, and global
> coordination belong primarily to:
>
> ```text
> doc/23-multi-agent-system/
> ```
>
> This document defines the **individual-Agent teamwork contract**.
>
> Runtime implementation described here remains `NOT_PROVEN` unless
> supported by implementation and Evidence.

# 2. Teamwork Mission

The mission is:

> **Allow specialized Humans and Agents to operate as one coordinated
> work unit while retaining individual identity, bounded authority,
> clear responsibility, Evidence lineage, least privilege, and
> Project/Customer/Tenant isolation.**

# 5. Team Definition

A Team is a bounded set of eligible participants organized around a
defined objective or operating responsibility.

Potential Team members:

```text
HUMANS

AI AGENTS

AUTHORIZED SERVICES
```

# 6. Team vs Collaboration

```text
COLLABORATION
=
GENERAL SHARED-WORK RELATIONSHIP

TEAM
=
STRUCTURED GROUP
WITH DEFINED MEMBERSHIP,

RESPONSIBILITIES,

```

---

# 7. Team vs Delegation

```text
TEAMWORK
≠
```
