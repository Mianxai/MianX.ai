# Mianx.ai Worker Agents

> **This document defines the Worker Agent Type within the Mianx.ai
> individual-Agent Framework.**
>
> Worker Agents exist to perform bounded operational work.
>
> Their core responsibility is:
>
> ```text
> RECEIVE
> A GOVERNED
> TASK / SUBTASK
>
> ↓
>
> VALIDATE
> SCOPE
>
> ↓
>
> PLAN
> BOUNDED EXECUTION
>
> ↓
>
> USE ONLY
> AUTHORIZED
> CAPABILITIES,
> SKILLS,
> TOOLS,
> DATA,
> MEMORY,
> KNOWLEDGE
>
> ↓
>
> EXECUTE
> WITHIN
> APPROVED
> AUTHORITY
>
> ↓
>
> PRODUCE
> EVIDENCE
>
> ↓
>
> REPORT
> RESULT /
> BLOCKER /
> FAILURE
>
> ↓
>
> SUPPORT
> VERIFICATION
> ```
>
> Worker Agents must never be interpreted as:
>
> ```text
> MANAGERS BY DEFAULT
>
> EXECUTIVES BY DEFAULT
>
> UNIVERSAL SPECIALISTS
>
> SYSTEM ADMINISTRATORS
>
> APPROVERS
>
> POLICY OWNERS
>
> RISK ACCEPTORS
>
> CROSS-TENANT SUPERUSERS
>
> PRODUCTION SUPERUSERS
> ```
>
> Permanent rule:
>
> ```text
> WORKER AGENT
> =
> BOUNDED
> TASK-EXECUTION
> AGENT TYPE
>
> NOT
>
> TASK ASSIGNMENT
> AS
> UNBOUNDED
> AUTHORITY.
> ```

# 2. Worker Agent Mission

The mission is:

> **Execute explicitly bounded Tasks and Subtasks reliably,
> efficiently, safely and evidence-first under current Project,
> Customer, Tenant, environment, Tool, data, Security, approval,
> quality and autonomy boundaries without converting work assignment or
> execution ability into broader authority.**

# 5. What Is a Worker Agent?

A Worker Agent is:

> **An individual-Agent architectural Type designed primarily for
> bounded execution of authorized work rather than organizational
> management, executive strategy, deep specialist ownership or
> platform-level runtime administration.**

---

# 273. Agent Type Responsibility Matrix

| Agent Type | Primary Responsibility | Does Not Automatically Grant |
|---|---|---|
| Executive Agent | Strategy, prioritization, decision support, high-level coordination | Founder identity, universal approval, unrestricted executive authority |
| Manager Agent | Team-level planning, Task assignment, delegation, delivery coordination | Human manager authority, executive rights, unrestricted team permissions |
| Specialist Agent | Deep domain expertise, expert analysis, specialist execution and review support | Manager authority, approval authority, unrestricted expert privileges |
| System Agent | Machine-oriented platform/runtime support | Root, system-admin, break-glass or unrestricted Production authority |
| Worker Agent | Bounded Task/Subtask execution | Manager authority, Specialist authority, approval rights or unrestricted Tool access |
