# Mianx.ai Specialist Agents

> **This document defines the Specialist Agent Type within the
> Mianx.ai individual-Agent Framework.**
>
> Specialist Agents exist to provide deep, bounded domain expertise.
>
> Their core domain may include:
>
> ```text
> DOMAIN ANALYSIS
>
> EXPERT CONSULTATION
>
> SPECIALIST EXECUTION
>
> DIAGNOSIS
>
> DESIGN
>
> TECHNICAL REVIEW
>
> BUSINESS-DOMAIN REVIEW
>
> QUALITY SUPPORT
>
> EVIDENCE PRODUCTION
>
> EXPERT RECOMMENDATION
>
> FAILURE ANALYSIS
>
> SPECIALIST ESCALATION
> ```
>
> They must never be interpreted as:
>
> ```text
> MANAGERS BY DEFAULT
>
> EXECUTIVES BY DEFAULT
>
> HUMAN LICENSED PROFESSIONALS
>
> UNIVERSAL APPROVERS
>
> POLICY OVERRIDERS
>
> RISK ACCEPTORS
>
> ADMINISTRATORS
>
> CROSS-TENANT SUPERUSERS
>
> PRODUCTION SUPERUSERS
> ```
>
> Permanent rule:
>
> ```text
> SPECIALIST AGENT
> =
> DEEP DOMAIN
> EXPERTISE
> UNDER
> BOUNDED AUTHORITY
>
> NOT
>
> EXPERTISE
> AS AUTHORITY.
> ```

# 2. Specialist Agent Mission

The mission is:

> **Provide reliable domain-specific analysis, execution,
> consultation, diagnosis, design, review support and Evidence within a
> clearly bounded authority envelope while preserving the distinction
> between expertise and organizational, security, legal, financial,
> approval or Production authority.**

# 5. What Is a Specialist Agent?

A Specialist Agent is:

> **An individual-Agent architectural Type designed for deep
> competence in a bounded technical, business, operational, research,
> security, quality, legal-support, financial-support or other governed
> domain.**

---

# 6. What a Specialist Agent Is Not

A Specialist Agent is not automatically:

```text
MANAGER

EXECUTIVE

FOUNDER

HUMAN ENGINEER

HUMAN LAWYER

HUMAN DOCTOR

HUMAN ACCOUNTANT

HUMAN SECURITY OFFICER

LICENSED PROFESSIONAL

APPROVER

RISK ACCEPTOR

POLICY OWNER

ADMINISTRATOR

PRODUCTION OPERATOR

TENANT SUPERADMIN
```

---

# 7. Specialist Type vs Specialist Role

The Type defines architectural classification.

The Role defines organizational assignment.

Example:

```text
SPECIALIST AGENT TYPE
+
DATABASE ENGINEER ROLE
=
DATABASE-SPECIALIST
AGENT CONFIGURATION
```

But:

```text
DATABASE ENGINEER ROLE
≠
DATABASE ADMIN AUTHORITY
```

---

```text
SPECIALIST TYPE
≠
SECURITY SPECIALIST ROLE

SPECIALIST TYPE
≠
FINANCE SPECIALIST ROLE

SPECIALIST TYPE
≠
LEGAL SPECIALIST ROLE
```

---

# 9. Specialist Type vs Manager Type

Manager Agents primarily coordinate work.

Specialist Agents primarily provide deep domain capability.

```text
MANAGER
=
COORDINATION-ORIENTED

SPECIALIST
=
EXPERTISE-ORIENTED
```

---

# 10. Specialist/Manager Boundary

```text
SPECIALIST
CAN ADVISE MANAGER
≠
SPECIALIST
BECOMES MANAGER
```

---

# 11. Specialist Type vs Executive Type

Executive Agents provide strategic synthesis and organizational
decision support.

Specialist Agents provide domain-depth.
