# Mianx.ai Agent Persona Template

> **This document defines the standard enterprise template used to
> author one Mianx.ai individual-Agent Persona Definition.**
>
> A Persona Definition should answer:
>
> ```text
> WHAT PERSONA IS THIS?
>
> WHAT IS ITS STABLE ID?
>
> WHAT VERSION?
>
> WHY DOES IT EXIST?
>
> WHAT COMMUNICATION
> EXPERIENCE SHOULD IT CREATE?
>
> WHAT TONE?
>
> WHAT BEHAVIOR PROFILE?
>
> HOW PROACTIVE?
>
> HOW SHOULD IT EXPRESS
> UNCERTAINTY?
>
> HOW SHOULD IT COMMUNICATE
> CONFIDENCE?
>
> HOW SHOULD IT PRESENT
> EVIDENCE?
>
> HOW SHOULD IT
> DISAGREE?
>
> HOW SHOULD IT
> REFUSE?
>
> HOW SHOULD IT
> ESCALATE?
>
> HOW SHOULD IT
> ACKNOWLEDGE ERRORS?
>
> WHAT AUDIENCE?
>
> WHAT LANGUAGE?
>
> WHAT MUST IT
> NEVER IMPLY
> ABOUT IDENTITY,
> AUTHORITY,
> APPROVAL,
> OR HUMAN STATUS?
>
> WHAT PROJECT?
>
> WHAT CUSTOMER?
>
> WHAT TENANT?
>
> WHAT SECURITY
> AND PRIVACY
> BOUNDARIES APPLY?
>
> HOW IS IT EVALUATED?
>
> WHAT IS ITS LIFECYCLE?
> ```
>
> It must never conclude:
>
> ```text
> "THE PERSONA
> SOUNDS LIKE
> AN EXECUTIVE,
> THEREFORE
> THE AGENT HAS
> EXECUTIVE AUTHORITY."
> ```
>
> Permanent rule:
>
> ```text
> PERSONA TEMPLATE
> =
> BEHAVIORAL
> PRESENTATION
> AUTHORING STANDARD
>
> NOT
>
> IDENTITY,
> ROLE,
> PERMISSION,
> OR
> AUTHORITY.
> ```

# 5. What Is a Persona Definition?

A Persona Definition is:

> **A governed specification of how an Agent should present,
> communicate, express uncertainty, structure recommendations, refuse,
> escalate, acknowledge errors, and adapt language or tone while
> preserving all independent identity, security, Capability, Tool,
> scope, approval, and authorization boundaries.**

---

# 6. What a Persona Definition Is Not

A Persona Definition is not:

```text
A SECURITY PRINCIPAL

AN ORGANIZATIONAL ROLE

A PERMISSION SET

A CAPABILITY GRANT

A SKILL ASSIGNMENT

A TOOL POLICY

A MODEL POLICY

A DECISION-RIGHTS RECORD

AN APPROVAL RECORD

AN AUTONOMY GRANT

A HUMAN IDENTITY

A PRODUCTION GRANT
```

---

AGENT IDENTITY
