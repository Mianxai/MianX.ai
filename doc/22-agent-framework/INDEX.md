# Mianx.ai Agent Framework Documentation Index

> **This document is the authoritative navigation and planned-document
> registry for the `doc/22-agent-framework/` documentation module while
> the module remains in Draft and review state.**
>
> **It defines what documents belong to the Agent Framework, where those
> documents live, what responsibility each document owns, and the order
> in which the documentation should be completed and reviewed.**
>
> **Presence in this index does not mean implementation exists.**
>
> **Presence in this index does not mean the document is Approved,
> Canonical, Implemented, Tested, Production Ready, or Production
> Authorized.**
>
> **The Agent Framework must remain separate from the AI Workforce,
> AI Operating System, Memory Engine, and Multi-Agent System even where
> their responsibilities interact.**

Use the following status vocabulary throughout this index.

| Marker | Documentation State | Meaning |
|---|---|---|
| ✅ | `CONTENT_COMPLETE_FOR_REVIEW` | Substantive content has been drafted and is ready for review |
| 🟡 | `IN_PROGRESS` | Document is actively being completed |
| ⏳ | `PLANNED` | Required document exists in the plan but content completion is pending |
| 🔍 | `REVIEW_REQUIRED` | Content exists but requires a dedicated review gate |
