# Mianx.ai Agent Skill Framework

> **This document defines the complete operating framework for
> individual-Agent Skills inside Mianx.ai.**
>
> The Skill Framework must answer:
>
> ```text
> WHAT IS THE SKILL?
>
> WHAT SKILL VERSION?
>
> WHICH AGENT?
>
> WHAT AGENT VERSION?
>
> IS THE SKILL ASSIGNED?
>
> IS THE SKILL AVAILABLE?
>
> IS THE SKILL ACTIVE?
>
> WHAT PROFICIENCY EXISTS?
>
> IS THAT PROFICIENCY CURRENT?
>
> WHAT PREREQUISITES EXIST?
>
> ARE THEY SATISFIED?
>
> WHAT DEPENDENCIES EXIST?
>
> ARE THEY AVAILABLE?
>
> WHAT CAPABILITY
> DOES THE SKILL SUPPORT?
>
> WHAT TASK
> REQUIRES THE SKILL?
>
> DOES THE SKILL
> MATCH THE REQUIREMENT?
>
> WHAT TOOL / MODEL /
> PROMPT / MEMORY /
> KNOWLEDGE / DATA
> DOES IT REQUIRE?
>
> WHAT PROJECT?
>
> WHAT CUSTOMER?
>
> WHAT TENANT?
>
> WHAT ENVIRONMENT?
>
> WHAT SECURITY /
> AUTHORIZATION
> MUST STILL BE CHECKED?
> ```
>
> It must never conclude:
>
> ```text
> "THE AGENT
> HAS THE SKILL,
> THEREFORE
> IT MAY PERFORM
> THE ACTION."
> ```
>
> Permanent rule:
>
> ```text
> SKILL FRAMEWORK
> =
> COMPETENCE
> MANAGEMENT
>
> NOT
>
> AUTHORITY
> MANAGEMENT.
> ```
>
> Runtime Skill Resolver, Skill Assignment Service, Skill Binding Store,
> Skill Activation Runtime, Skill proficiency engine, Skill dependency
> resolver, Skill composition engine, Task-to-Skill matcher, fallback
> resolver, Skill runtime context, Project/Customer/Tenant isolation,
> Skill revocation propagation, and Production Skill runtime remain
> `NOT_PROVEN` unless implementation Evidence exists.

# 2. Skill Framework Mission

The mission is:

> **Provide one governed operating model for reusable individual-Agent
> Skills so Mianx.ai can consistently bind, evaluate, resolve, compose,
> select and lifecycle-manage Agent competence without turning Skill
> metadata, proficiency, Agent self-description, Tool availability,
> Model capability, Task urgency, or runtime convenience into hidden
> authorization or Production privilege.**

# 15. Skill Assignment

Skill Assignment associates a Skill Version with an Agent context.

Conceptually:

```yaml
agent_skill_assignment:
  assignment_id: required

  agent:
    agent_id: required
    agent_version: required_or_conditional
    allocation_id: conditional

  skill:
    skill_id: required
    skill_version: required

  status:
    assignment_status: required

  scope:
    project_id: conditional
    customer_id: conditional
    tenant_id: conditional
    environment: conditional

  proficiency:
    proficiency_ref: conditional
    proficiency_status: conditional

  governance:
    assigned_by: required
    approval_refs: []
    policy_refs: []

  lifecycle:
    assigned_at: required
    activated_at: conditional
    suspended_at: conditional
    revoked_at: conditional
    expires_at: conditional
```

Conceptual only.
