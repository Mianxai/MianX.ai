# Mianx.ai Agent Skill Development

> **This document defines how Mianx.ai develops a new individual-Agent
> Skill or a new Skill Version from initial need through controlled
> release and ongoing improvement.**
>
> Skill Development should answer:
>
> ```text
> WHY IS THIS SKILL NEEDED?
>
> WHAT PROBLEM DOES IT SOLVE?
>
> WHAT CAPABILITY DOES IT SUPPORT?
>
> WHAT IS IN SCOPE?
>
> WHAT IS OUT OF SCOPE?
>
> WHAT PREREQUISITES EXIST?
>
> WHAT TOOLS ARE REQUIRED?
>
> WHAT MODELS ARE REQUIRED?
>
> WHAT PROMPTS ARE REQUIRED?
>
> WHAT MEMORY / KNOWLEDGE
> ARE REQUIRED?
>
> WHAT DATA IS REQUIRED?
>
> HOW WILL IT BE IMPLEMENTED?
>
> HOW WILL IT BE TESTED?
>
> HOW WILL QUALITY BE MEASURED?
>
> HOW WILL SECURITY BE TESTED?
>
> WHAT EVIDENCE
> PROVES THE SKILL WORKS?
>
> WHAT VERSION IS RELEASED?
>
> WHO APPROVES IT?
>
> HOW IS IT ROLLED OUT?
>
> HOW IS REGRESSION DETECTED?
>
> HOW IS IT IMPROVED?
> ```
>
> It must never conclude:
>
> ```text
> "THE SKILL PASSED TESTING,
> THEREFORE
> EVERY AGENT MAY USE IT
> IN PRODUCTION."
> ```
>
> Permanent rule:
>
> ```text
> SKILL DEVELOPMENT
> CREATES
> A GOVERNED
> SKILL ARTIFACT.
>
> IT DOES NOT
> CREATE
> AGENT AUTHORITY.
> ```
>
> Runtime Skill Development Platform, automated Skill compilation,
> Skill test harnesses, benchmark infrastructure, sandboxed
> experimentation, automated release pipelines, canary rollout,
> regression monitoring, rollback automation, Skill assignment
> propagation, proficiency recalculation, and Production release
> enforcement remain `NOT_PROVEN` unless implementation Evidence exists.

# 2. Skill Development Mission

The mission is:

> **Provide a controlled, repeatable and evidence-based lifecycle for
> converting a legitimate Agent Skill need into a versioned,
> documented, evaluated, security-reviewed and governable Skill
> artifact without allowing experimentation, Agent learning, Model
> capability, developer convenience, benchmark success, or release
> pressure to bypass Skill governance or runtime authorization.**
