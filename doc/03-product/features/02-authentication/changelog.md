# Versioning Strategy

Authentication follows Semantic Versioning.

```
MAJOR.MINOR.PATCH

MAJOR

MINOR
New functionality

PATCH
Bug fixes and improvements
```

Example:

```
1.0.0

Major Release
```

```
1.1.0

New Features
```

```
1.1.1

Bug Fixes
```
