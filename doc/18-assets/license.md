# Purpose

This document defines the ownership, licensing, copyright, usage rights, distribution rules, and legal compliance requirements for all digital assets within the Mianx.ai ecosystem.

It ensures that all assets are:

- Legally compliant
- Properly licensed
- Securely managed
- Correctly attributed
- Protected from unauthorized use

---

# Scope

This policy applies to every asset stored in the **18-assets** directory, including:

- Logos
- Icons
- Illustrations
- UI Designs
- Wireframes
- Architecture Diagrams
- Database Diagrams
- Documentation
- Videos
- Screenshots
- Templates
- Presentations
- AI Generated Assets
- Marketing Materials
- Source Design Files

---

# Ownership

Unless otherwise specified, every asset created for Mianx.ai is the intellectual property of Mianx.ai.

Ownership includes:

- Copyright
- Design Rights
- Documentation Rights
- Source Files
- AI Generated Assets
- Internal Templates

# Copyright Policy

Every internally created asset is protected under applicable copyright laws.

Each published asset should include:

- Copyright Owner
- Creation Date
- Version
- License Type

Example

```text
© 2026 Mianx.ai
All Rights Reserved.
```

---

# License Types

## Internal

Used only inside Mianx.ai.

Cannot be shared publicly.

---

## Client

Created specifically for a client.

Ownership depends on the project agreement.

---

## Open Source

Released under an approved open-source license.

Examples

- MIT
- Apache 2.0
- BSD
- GPL

---

## Commercial

Purchased from external vendors.

Usage depends on vendor licensing.

---

## Third Party

Assets owned by external organizations.

Must comply with original license terms.

---

# Third-Party Assets

Before using external assets, verify:

- License Type
- Commercial Usage
- Modification Rights
- Attribution Requirements
- Redistribution Rules

---

# AI Generated Assets

AI-generated assets must include:

- Generation Date
- AI Model
- Prompt Reference
- Human Reviewer
- Approval Status

Human review is mandatory before production use.

---

# Attribution Requirements

When required, include:

- Original Author
- Source
- License
- Copyright Notice

---

# Usage Rules

Assets may only be used:

- For approved projects
- According to their license
- By authorized personnel
- Within approved repositories

---

# Restricted Usage

The following is prohibited without approval:

- Redistribution
- Resale
- Public sharing
- Trademark modification
- Logo alteration
- Commercial redistribution of third-party assets

---

# Brand Protection

Official logos, trademarks, and branding assets:

- Cannot be modified
- Cannot be recolored
- Cannot be stretched
- Cannot be recreated manually

Only approved versions may be used.

---

# Source Files

Original design files should always be preserved.

Examples

- Figma
- Illustrator
- Photoshop
- Blender
- Draw.io

Derived files should never replace originals.

---

# Version Control

Every licensed asset should maintain:

- Version Number
- Change History
- Owner
- License Type
- Approval Status

---

# Storage Policy

Licensed assets must be stored only in approved repositories.

Backups should be maintained.

---

# Compliance Requirements

All assets must comply with:

- Copyright Law
- Trademark Law
- Contract Agreements
- Third-Party Licenses
- Internal Policies

---

# Audit Requirements

Conduct regular audits to verify:

- Ownership
- Licensing
- Attribution
- Expired Licenses
- Unauthorized Usage

Recommended frequency:

- Quarterly

---

# License Review Checklist

Before publishing:

- [ ] Ownership verified
- [ ] License verified
- [ ] Third-party review completed
- [ ] Attribution added
- [ ] Approval received
- [ ] Version updated

---

# Violations

Examples

- Unauthorized asset use
- Missing attribution
- License violations
- Copyright infringement
- Unapproved redistribution

Violations must be reported immediately.
