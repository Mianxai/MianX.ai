# Purpose

This document serves as the master inventory of every asset maintained within the Mianx.ai ecosystem.

The inventory enables:

- Centralized asset tracking
- Asset discoverability
- Ownership management
- Version control
- Lifecycle management
- AI-powered asset discovery
- Enterprise governance

---

# Objectives

- Maintain a complete inventory of all assets.
- Track ownership and version history.
- Prevent duplicate assets.
- Improve reuse across projects.
- Support enterprise asset governance.
- Enable AI agents to locate reusable assets automatically.

# Asset Metadata

Each asset should include the following metadata.

| Property | Description |
|----------|-------------|
| Asset ID | Unique identifier |
| Asset Name | Human-readable name |
| Description | Purpose of the asset |
| Category | Asset category |
| File Type | PNG, SVG, PDF, PPTX, etc. |
| Location | Repository path |
| Owner | Responsible team |
| Version | Current version |
| Status | Draft / Approved / Archived |
| Created Date | Asset creation date |
| Last Updated | Last modification date |

---

# Best Practices

- Assign a unique Asset ID to every important asset.
- Store assets only in approved folders.
- Never overwrite approved versions.
- Archive instead of deleting.
- Keep metadata up to date.
- Perform quarterly inventory audits.
- Use consistent naming conventions.
