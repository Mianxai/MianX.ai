# Purpose

The **18-assets** folder serves as the centralized asset repository for the entire Mianx.ai ecosystem.

Its purpose is to organize, document, version, and maintain every reusable asset used across products, departments, AI agents, documentation, engineering, marketing, and enterprise operations.

A centralized asset library ensures:

- Consistency
- Reusability
- Brand compliance
- Faster development
- Better collaboration
- Easier maintenance

---

# Objectives

- Maintain a single source of truth for assets.
- Standardize asset naming and organization.
- Improve collaboration between teams.
- Enable asset reuse across projects.
- Support AI-generated and human-created assets.
- Preserve version history and licensing information.

# Asset Management Principles

- Single source of truth
- Version controlled assets
- Clear ownership
- Consistent naming
- Approved branding
- Easy discoverability
- Secure storage
- Long-term maintainability

---

# Version Control

Every important asset should maintain:

- Version Number
- Change History
- Owner
- Approval Status
- Last Modified Date

---

# Quality Standards

Every asset must be:

- Accurate
- Consistent
- High Resolution
- Properly Named
- Approved
- Documented
- Version Controlled

---

# Ownership

Each asset category must have an assigned owner responsible for:

- Updates
- Reviews
- Quality
- Versioning
- Approval

---

# Security

Sensitive assets must be:

- Access controlled
- Version tracked
- Backed up
- Audited regularly

# Best Practices

- Never duplicate assets unnecessarily.
- Use approved branding only.
- Maintain consistent file naming.
- Archive deprecated assets instead of deleting them.
- Keep all reusable assets centralized.
- Review assets periodically.
- Document significant updates.
