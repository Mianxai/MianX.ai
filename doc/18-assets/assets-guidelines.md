# Purpose

This document defines the enterprise standards for managing all digital assets used throughout the Mianx.ai ecosystem.

These guidelines ensure:

- Consistency
- Reusability
- Maintainability
- Scalability
- Discoverability
- Security
- Quality

---

# Objectives

- Standardize asset management.
- Prevent duplication.
- Improve collaboration.
- Support AI-powered asset discovery.
- Maintain enterprise quality.
- Preserve branding consistency.

# Asset Management Principles

## Single Source of Truth

Every official asset must exist in only one approved location.

---

## Reusability

Before creating a new asset, verify that an existing reusable asset does not already exist.

---

## Version Control

Every important asset must maintain version history.

---

## Ownership

Every asset must have an assigned owner.

---

## Traceability

Every asset should be traceable from creation to retirement.

```text
database/

videos/
screenshots/
exports/
workflows/
```

---

# Naming Rules

Every asset must:

- Use lowercase
- Use hyphens (-)
- Avoid spaces
- Be descriptive
- Include version when appropriate

Examples

```text
company-logo.svg

dashboard-wireframe.fig

api-v1-collection.json

authentication-workflow.drawio

landing-page-ui.fig
```

---

# Versioning Rules

Major changes

```text
v1.0
v2.0
v3.0
```

Minor changes

```text
v1.1
v1.2
v1.3
```

Patch updates

```text
v1.0.1
v1.0.2
```

# Quality Checklist

Before publishing:

- [ ] Correct folder
- [ ] Correct filename
- [ ] Metadata complete

- [ ] Approved

# Common Mistakes

Avoid:

- Duplicate assets
- Missing metadata
- Random filenames
- Outdated branding
- Multiple official versions
- Unapproved assets
- Missing ownership

# Asset Retirement

Assets should be archived when:

- Replaced
- Deprecated
- No longer supported
- Branding changes
- Product discontinued

Never permanently delete official assets without approval.

# Best Practices

- Create assets once, reuse everywhere.
- Store assets only in approved folders.
- Keep metadata complete.
- Version every important update.
- Archive instead of deleting.
- Review assets regularly.
- Follow branding standards consistently.
- Maintain a single source of truth.
