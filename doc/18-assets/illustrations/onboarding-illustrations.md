# Purpose

Onboarding illustrations help users understand the platform during their first experience.

They reduce confusion, explain product capabilities, introduce important concepts, and create an engaging first impression.

This document defines the enterprise standards for creating onboarding illustrations used across every Mianx.ai product.

---

# Objectives

The onboarding illustration system aims to:

- Reduce learning time
- Increase activation rate
- Improve first impressions
- Explain platform capabilities
- Support user education
- Guide users through setup
- Build confidence
- Increase feature discovery
- Maintain brand consistency
- Support accessibility

---

# Scope

These standards apply to:

- Welcome Screens
- Product Tours
- Account Creation
- Workspace Setup
- Organization Setup
- AI Agent Introduction
- Dashboard Introduction
- Feature Discovery
- Guided Tutorials
- First-Time User Experience
- Progressive Onboarding

---

# Onboarding Philosophy

Every onboarding illustration should answer one question:

> **What does the user need to understand right now?**

Illustrations should simplify—not decorate.

---

# Core Principles

Every onboarding illustration should be:

- Friendly
- Professional
- Simple
- Helpful
- Informative
- Positive
- Brand Consistent
- Accessible

---

# Welcome Illustrations

Purpose:

Introduce the platform.

Common themes:

- Innovation
- AI Collaboration
- Productivity
- Growth
- Digital Workspace

Avoid showing advanced product complexity.

---

# Account Creation

Illustrations should communicate:

- Security
- Identity
- Simplicity
- Trust

Objects may include:

- User
- Profile
- Shield
- Email
- Authentication

---

# Organization Setup

Illustrations explain:

- Company creation
- Teams
- Departments
- Business structure

Visual focus:

```text
Organization

↓

Workspace

↓

Departments
```

---

# Workspace Setup

Illustrations communicate:

- Workspace creation
- Configuration
- Collaboration
- Productivity

Recommended objects:

- Dashboard
- Workspace
- Settings
- Documents

---

# Team Invitation

Illustrations explain:

- Collaboration
- Invitations
- Shared Work
- Members
- Roles

Avoid using complex organizational charts.

---

# AI Workforce Introduction

Illustrations should introduce:

- AI CEO
- AI Departments
- AI Agents
- Automation
- Intelligent Collaboration

The focus is on workflows—not humanoid robots.

---

# Dashboard Introduction

Illustrations should explain:

- Navigation
- Widgets
- Analytics
- Workspace
- Productivity

Avoid displaying actual screenshots.

Use simplified dashboard representations.

---

# Product Tours

Illustrations support:

- Guided Tours
- Tooltips
- Walkthroughs
- Interactive Help

The illustration should complement—not replace—written guidance.

---

# Feature Discovery

Illustrations introduce:

- Automation
- Analytics
- Reports
- Knowledge Base
- Projects
- Tasks

One illustration should explain one feature.

---

# Completion Screens

Completion illustrations should communicate:

- Success
- Readiness
- Achievement
- Progress

Recommended elements:

- Checkmark
- Workspace
- Team
- AI Assistant

---

# Success States

Illustrations may represent:

- Account Ready
- Workspace Ready
- AI Ready
- Setup Complete
- Welcome Aboard

Positive reinforcement is encouraged.

---

# Visual Style

Follow:

- illustration-style.md
- illustration-guidelines.md

Characteristics:

- Flat
- Modern
- Minimal
- Friendly
- Professional

---

# Composition

Recommended layout:

```text
Illustration

↓

Headline

↓

Description

↓

Primary Action
```

Avoid placing critical details inside the illustration.

---

# Color Usage

Use:

- Brand Primary
- Brand Secondary
- Neutral Colors
- Accent Colors

Recommended distribution:

| Color | Usage |
|--------|-------|
| Neutral | 70% |
| Primary | 20% |
| Accent | 10% |

---

# Characters

Characters should appear:

- Welcoming
- Helpful
- Collaborative
- Inclusive
- Professional

Avoid exaggerated emotions.

---

# Devices

Devices may include:

- Desktop
- Laptop
- Tablet
- Mobile
- Dashboard

Avoid referencing specific hardware manufacturers.

---

# Backgrounds

Preferred:

- White
- Transparent
- Light Gray
- Soft Abstract Shapes

Avoid busy environments.

---

# Responsive Design

Illustrations should adapt to:

- Desktop
- Tablet
- Mobile

On mobile:

- Reduce decorative elements
- Increase spacing
- Preserve the primary message

---

# Accessibility

Illustrations should:

- Maintain sufficient contrast
- Avoid color-only communication
- Include descriptive alternative text when informative
- Support screen readers through surrounding content

Decorative artwork should use:

```html
aria-hidden="true"
```

---

# Animation Readiness

Illustrations should be layered for future animation.

Suggested layers:

- Characters
- Devices
- Background
- Decorative Shapes
- AI Elements

---

# Performance

Illustrations should:

- Use optimized SVG
- Minimize file size
- Support lazy loading
- Preserve quality at all resolutions

---

# AI-Assisted Creation

AI may assist with:

- Initial concepts
- Layout exploration
- Color suggestions
- Composition ideas
- Variant generation

Every AI-generated illustration requires human review.

- [ ] One clear message

- [ ] Accessible

- [ ] Optimized
- [ ] Source archived
- [ ] Metadata added
- [ ] Export generated
- [ ] Approved by Design Team

---

# Common Mistakes

Avoid:

- Overly complex scenes
- Too much text
- Decorative overload
- Inconsistent characters
- Mixed illustration styles
- Crowded layouts
- Product screenshots instead of illustrations
- Ignoring accessibility

---

# Best Practices

- Explain one concept at a time.
- Keep layouts simple.
- Guide users naturally.
- Reuse approved assets.
- Maintain illustration consistency.
- Design for every screen size.
- Optimize exports.
- Archive source files.
- Test with real users.
- Review before publishing.
