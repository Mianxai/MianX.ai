# Purpose

AI Workforce illustrations visually represent the autonomous workforce powering the Mianx.ai platform.

Unlike product or marketing illustrations, AI Workforce illustrations explain how intelligent agents collaborate, make decisions, exchange knowledge, execute workflows, and operate as one enterprise operating system.

These illustrations are used across documentation, presentations, dashboards, websites, onboarding, and internal architecture documentation.

---

# Objectives

The AI Workforce Illustration System aims to:

- Explain AI Workforce architecture
- Visualize autonomous collaboration
- Simplify complex AI concepts
- Standardize enterprise diagrams
- Strengthen Mianx.ai branding
- Support product education
- Improve documentation quality
- Enable reusable illustration assets
- Support AI-assisted asset generation
- Scale to future AI departments

# AI Workforce Philosophy

Every AI Workforce illustration should answer one question:

> **How do intelligent agents work together to accomplish business goals?**

The focus is on collaboration, orchestration, automation, and intelligence—not on humanoid robots.

---

# Core Principles

Every illustration should be:

- Professional

# Visual Metaphors

Approved metaphors include:

- Connected Nodes
- Knowledge Network
- Workflow Pipeline
- Shared Workspace
- Digital Collaboration
- Intelligence Graph

Avoid:

- Human brains
- Robot heads
- Science-fiction imagery
- Military command visuals

If characters are used they should represent:

- Collaboration
- Analysis
- Planning
- Support

Characters should remain abstract and enterprise-friendly.

# Color Usage

Recommended balance:

| Color | Usage |
|--------|-------|
| Neutral | 65% |
| Brand Primary | 25% |
| Accent | 10% |

Department-specific accent colors may be applied while preserving the core palette.

---

# Composition

Recommended hierarchy:

```text
Primary Agent

↓

Connected Teams

↓

Supporting Systems

↓

Background Network
```

Avoid dense connection maps.

---

# Responsive Design

Illustrations should adapt to:

- Desktop
- Tablet
- Mobile
- Documentation
- Presentations

The primary concept must remain recognizable at all sizes.

---

# Accessibility

AI Workforce illustrations should:

- Maintain sufficient contrast
- Avoid color-only communication
- Include descriptive alternative text when informative
- Use simple visual relationships

Decorative artwork should use:

```html
aria-hidden="true"
```

---

# Performance

Illustrations should:

- Use optimized SVG
- Support lazy loading
- Minimize complexity
- Preserve clarity across resolutions

---

# AI-Assisted Creation

AI may assist with:

- Architecture concepts
- Layout exploration
- Node arrangements
- Workflow variants
- Composition ideas

Every generated illustration must be reviewed and approved by the Design Team.

---

# Common Mistakes

Avoid:

- Humanoid robot imagery
- Science-fiction themes
- Excessive network complexity
- Random connections
- Decorative overload
- Mixed illustration styles
- Vendor branding
- Unstructured workflows

---

# Best Practices

- Represent systems, not robots.
- Focus on collaboration.
- Keep workflows easy to follow.
- Reuse approved visual patterns.
- Maintain enterprise consistency.
- Optimize exports.
- Preserve accessibility.
- Archive master files.
- Document metadata.
- Review every illustration before release.
