# Purpose

Hero illustrations are the largest and most important visual assets used throughout the Mianx.ai ecosystem.

They establish first impressions, communicate product value, reinforce branding, and visually explain complex ideas before users read any text.

This document defines the official standards for planning, designing, implementing, reviewing, and maintaining hero illustrations.

---

# Objectives

The Hero Illustration System exists to:

- Build a strong first impression
- Communicate product value
- Support storytelling
- Strengthen brand identity
- Improve user engagement
- Increase conversion rates
- Simplify complex concepts
- Support responsive layouts
- Standardize visual quality
- Enable scalable illustration creation

---

# Scope

These standards apply to:

- Homepage
- Landing Pages
- Product Pages
- Feature Pages
- Solutions Pages
- Pricing Pages
- AI Workforce
- Documentation Landing
- Enterprise Portal
- Mobile Landing Screens
- Marketing Campaigns

---

# Hero Illustration Philosophy

Every hero illustration should answer one question:

> **Why should the user continue exploring this page?**

Hero illustrations are not decorative artwork.

They are strategic communication tools.

---

# Hero Illustration Goals

Each hero illustration should:

- Explain
- Inspire
- Attract
- Guide
- Build trust
- Showcase innovation
- Demonstrate professionalism

---

# Visual Message

A hero illustration should communicate only one primary message.

Examples:

- AI Workforce Collaboration
- Enterprise Automation
- Digital Transformation
- Cloud Infrastructure
- Product Ecosystem
- Data Intelligence
- Customer Success

Avoid combining multiple unrelated messages.

---

# Design Principles

Hero illustrations should be:

- Simple
- Memorable
- Modern
- Professional
- Scalable
- Accessible
- Brand Consistent

---

Hero illustrations are grouped into:

Hero Library

---

# Homepage Hero

Homepage heroes communicate the overall vision of Mianx.ai.

Examples:

- AI Operating System
- Autonomous Enterprise
- Multi-Agent Collaboration
- Digital Workforce
- Future of Work

Homepage heroes should be timeless.

---

# Product Hero

Product heroes focus on one specific product.

Examples:

- Dashboard
- Analytics
- AI Studio
- Workflow Engine
- Knowledge Base

The illustration should explain the product's primary value.

---

# Solution Hero

Solution pages explain business outcomes.

Examples:

- Healthcare
- Education
- Finance
- Manufacturing
- Retail
- Restaurant
- Logistics

---

# AI Workforce Hero

Illustrations representing:

- CEO Agent
- CTO Agent
- AI Teams
- Department Collaboration
- Agent Communication
- Autonomous Workflows

Avoid portraying AI agents as humans.

---

# Marketing Hero

Marketing hero illustrations support:

- Campaigns
- Promotions
- Launches
- Product Announcements
- Events

Marketing heroes may contain stronger visual emphasis but must remain consistent with the official illustration style.

---

# Layout Structure

Recommended layout:

```text
+--------------------------------------------+

Headline

Description

CTA Buttons

Illustration

+--------------------------------------------+
```

---

# Composition

Hero illustrations should include:

- Primary Subject
- Supporting Elements
- Background Shapes
- Controlled Empty Space

Avoid cluttered compositions.

---

# Safe Area

Important objects must remain inside the safe area.

Recommended margin:

```text
Minimum

64px Desktop

32px Tablet

24px Mobile
```

No important visual element should touch screen edges.

---

# Visual Hierarchy

Order of attention:

```text
Primary Subject

↓

Supporting Objects

↓

Background

↓

Decorative Elements
```

---

# Characters

If characters are used they should appear:

- Professional
- Friendly
- Inclusive
- Collaborative

Avoid exaggerated cartoon styles.

---

# Objects

Objects may include:

- Cloud
- Dashboard
- AI Nodes
- Workflow Cards
- Servers
- Data Visualizations
- Documents
- Charts

Objects should follow official design system standards.

---

# Color Usage

Use official brand colors.

Recommended ratio:

| Color | Usage |
|---------|-------|
| Neutral | 70% |
| Brand Primary | 20% |
| Accent | 10% |

Avoid overly saturated palettes.

---

# Background Style

Recommended backgrounds:

- White
- Light Gray
- Transparent
- Soft Abstract Shapes

Avoid detailed scenery.

---

# Motion Readiness

Hero illustrations should be layered for animation.

Animation-ready assets should separate:

- Characters
- Devices
- Background
- Decorative Elements
- Connections

---

# Responsive Behavior

Illustrations must adapt to:

- Desktop
- Laptop
- Tablet
- Mobile
- Ultra-wide Screens

Important elements should never be cropped.

---

# Mobile Guidelines

On mobile:

- Simplify composition
- Reduce decorative elements
- Increase whitespace
- Maintain readability
- Preserve primary message

---

# Accessibility

Hero illustrations should:

- Maintain sufficient contrast
- Avoid color-only communication
- Include descriptive alternative text when informative
- Be ignored by assistive technologies when purely decorative

---

# Performance

Hero illustrations should:

- Use optimized SVG
- Support lazy loading
- Minimize file size
- Avoid unnecessary complexity
- Preserve visual quality

---

# AI-Assisted Creation

AI tools may assist with:

- Concept generation
- Composition exploration
- Color exploration
- Background ideas
- Variant generation

Human approval is mandatory.

---

# Review Workflow

```text
Concept

↓

Sketch

↓

Wireframe

↓

Illustration

↓

Accessibility Review

↓

Brand Review

↓

Approval

↓

Export

↓

Production
```

---

# Quality Checklist

Before approval:

- [ ] One clear message
- [ ] Brand compliant
- [ ] Official colors
- [ ] Responsive
- [ ] Accessible
- [ ] Performance optimized
- [ ] Source archived
- [ ] Export package generated
- [ ] Metadata registered
- [ ] Approved by Brand Team

---

# Common Mistakes

Avoid:

- Multiple visual stories
- Excessive details
- Random gradients
- Mixed illustration styles
- Unofficial colors
- Overcrowded layouts
- Poor responsiveness
- Decorative overload
- Large file sizes

---

# Best Practices

- Focus on one story.
- Keep compositions clean.
- Reuse approved assets.
- Follow illustration style.
- Design for responsiveness.
- Optimize every export.
- Archive master files.
- Maintain accessibility.
- Keep visual hierarchy clear.
- Review before publishing.
