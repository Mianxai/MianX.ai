# Purpose

This document defines the official illustration standards for the Mianx.ai ecosystem.

Its purpose is to ensure that every illustration follows one unified visual language regardless of the designer, project, department, product, or AI system that creates it.

These guidelines apply to every illustration used across:

- Products
- Websites
- Documentation
- Marketing
- Presentations
- Dashboards
- Mobile Applications
- AI Workforce
- Internal Platforms

---

# Objectives

The illustration system exists to:

- Create a unified visual identity
- Improve product communication
- Simplify complex concepts
- Support enterprise branding
- Improve onboarding
- Increase usability
- Improve accessibility
- Reduce visual inconsistency
- Support AI-generated artwork
- Scale across future products

---

# Scope

These standards apply to:

- Hero Illustrations
- Empty States
- Product Illustrations
- Workflow Graphics
- Architecture Diagrams
- Marketing Artwork
- AI Workforce Graphics
- Landing Pages
- Documentation Graphics
- Technical Illustrations
- Educational Graphics
- Social Media Artwork

---

# Core Principle

Illustrations exist to **support understanding**, not decoration.

Every illustration should answer at least one of these questions:

- What is happening?
- What should the user do?
- Why is this important?
- What problem is being solved?
- What does this feature represent?

If an illustration adds no value, it should not exist.

---

# Illustration Philosophy

The Mianx.ai illustration system follows five principles:

1. Clarity over decoration
2. Simplicity over complexity
3. Consistency over creativity
4. Communication over aesthetics
5. Brand identity over trends

---

# Illustration Goals

Every illustration should:

- Explain
- Educate
- Guide
- Encourage
- Build trust
- Improve comprehension
- Reduce cognitive load

Illustrations should never distract from user tasks.

---

# Visual Language

All illustrations must share one visual language.

Characteristics include:

- Clean geometry
- Soft corners
- Balanced spacing
- Minimal detail
- Modern appearance
- Friendly personality
- Professional tone
- Enterprise quality

---

# Illustration Style

The official style is:

- Flat Illustration
- Minimal Details
- Soft Shadows
- Limited Gradients
- Simple Geometry
- Clean Composition

Avoid:

- Hyper-realism
- Cartoon exaggeration
- Comic styles
- Photorealistic rendering
- 3D realism (unless officially approved)

---

# Brand Consistency

Every illustration must align with:

- Brand Colors
- Typography
- Icon System
- Design Tokens
- Spacing System
- Grid System

Illustrations must feel like part of the same ecosystem.

---

# Composition Principles

Good compositions should:

- Create visual hierarchy
- Lead the eye naturally
- Avoid clutter
- Maintain balance
- Preserve white space
- Focus on one message

---

# Layout Rules

Illustrations should:

- Use consistent margins
- Respect safe areas
- Align to the design grid
- Avoid cropped primary objects
- Scale gracefully

---

# Perspective

Approved perspectives:

- Flat
- Isometric (where appropriate)
- Slight Perspective

Avoid mixing multiple perspectives within one illustration.

---

# Shapes

Preferred shapes:

- Rounded rectangles
- Circles
- Soft polygons
- Smooth curves

Avoid:

- Jagged edges
- Random geometry
- Excessive complexity

---

# Line Style

Illustrations should use:

- Consistent stroke width
- Rounded joins
- Rounded caps
- Clean outlines

Do not mix multiple stroke systems.

---

# Color Usage

Illustrations should primarily use:

- Brand Primary
- Brand Secondary
- Neutral Palette
- Accent Colors

Color should communicate—not decorate.

---

# Color Balance

Recommended distribution:

- 70% Neutral
- 20% Brand Primary
- 10% Accent

This maintains readability and brand consistency.

---

# Shadows

Shadows should be:

- Soft
- Minimal
- Consistent
- Directional

Avoid dramatic lighting effects.

---

# Gradients

Gradients are optional.

If used:

- Keep them subtle.
- Follow brand colors.
- Avoid rainbow gradients.
- Avoid glossy effects.

---

# Typography Inside Illustrations

Avoid embedded text whenever possible.

If text is required:

- Use official typography
- Keep it editable
- Localize separately
- Never outline text permanently

---

# Characters

Illustrated characters should appear:

- Professional
- Friendly
- Inclusive
- Diverse
- Neutral

Avoid exaggerated expressions or stereotypes.

---

# Objects

Objects should:

- Be recognizable
- Follow the design system
- Use shared proportions
- Match icon style

---

# Icons Inside Illustrations

Illustrations may include icons.

Only approved Design System icons may be used.

Never redraw official icons manually.

---

# Storytelling

Illustrations should communicate a single story.

Examples:

- User creates workspace
- AI processes request
- Team collaboration
- Automation workflow
- Successful deployment

Avoid combining unrelated concepts.

---

# Emotion

Illustrations may communicate:

- Success
- Progress
- Discovery
- Innovation
- Collaboration
- Confidence

Avoid fear, confusion, or unnecessary drama.

---

# Empty State Principles

Empty-state illustrations should:

- Reduce frustration
- Explain the situation
- Suggest the next action
- Maintain a positive tone

---

# Marketing Illustrations

Marketing illustrations should:

- Support messaging
- Reinforce branding
- Explain products
- Build trust
- Inspire action

They should not overpromise product capabilities.

---

# Product Illustrations

Product illustrations should:

- Explain features
- Simplify workflows
- Reduce onboarding time
- Improve discoverability

---

# Technical Illustrations

Technical graphics should prioritize:

- Accuracy
- Clarity
- Labels
- Logical flow
- Consistent symbols

---

# AI Workforce Illustrations

AI Workforce artwork should represent:

- Agents
- Departments
- Collaboration
- Automation
- Intelligence
- Knowledge Flow

Avoid portraying AI as human employees.

---

# Accessibility

Illustrations must support:

- High Contrast
- Color Independence
- Screen Readers
- Responsive Scaling
- Keyboard Navigation (where interactive)

Decorative illustrations should use:

```html
aria-hidden="true"
```

---

# Responsive Behavior

Illustrations should work across:

- Mobile
- Tablet
- Desktop
- Ultra-wide Displays
- Documentation
- Presentations

---

# Performance

Illustrations should:

- Optimize SVG paths
- Reduce file size
- Avoid unnecessary detail
- Support lazy loading
- Preserve quality at all sizes

---

# AI-Assisted Illustration

AI tools may assist with:

- Concept generation
- Layout exploration
- Color suggestions
- Composition ideas
- Variant creation

Human review is mandatory before approval.

---

# Review Process

Every illustration passes through:

```text
Concept

↓

Wireframe

↓

Draft

↓

Review

↓

Accessibility Check

↓

Brand Approval

↓

Final Approval

↓

Export

↓

Release
```

---

# Quality Checklist

Before approval:

- [ ] Supports one clear message
- [ ] Follows brand guidelines
- [ ] Uses official colors
- [ ] Uses approved icons
- [ ] Proper spacing
- [ ] Responsive
- [ ] Accessible
- [ ] Optimized
- [ ] Exported correctly
- [ ] Source files archived

---

# Governance

Every illustration requires:

- Design Review
- Accessibility Review
- Brand Review
- Asset Registration
- Version Assignment
