# Purpose

Product illustrations visually explain features, modules, workflows, and capabilities inside Mianx.ai products.

Unlike marketing illustrations, product illustrations focus on helping existing users understand and use the product effectively.

They should reduce cognitive load, improve discoverability, support onboarding, and enhance the overall product experience.

---

# Objectives

The Product Illustration System aims to:

- Improve feature understanding
- Reduce user confusion
- Support product onboarding
- Explain workflows
- Improve task completion
- Increase feature adoption
- Maintain visual consistency
- Support accessibility
- Enable scalable illustration libraries
- Support AI-assisted illustration workflows

---

# Scope

These standards apply to:

- Product Dashboards
- Feature Pages
- Module Introductions
- AI Features
- Reports
- Analytics
- Workflow Pages
- Setup Wizards
- Empty Modules
- Help Centers
- User Guides
- Knowledge Base
- Interactive Tours

---

# Product Illustration Philosophy

Every product illustration should answer one question:

> **How does this feature help the user complete their work?**

Product illustrations should clarify functionality, not decorate interfaces.

---

# Core Principles

Every product illustration should be:

- Functional
- Clear
- Minimal
- Professional
- Reusable
- Accessible
- Responsive
- Brand Consistent

# Dashboard Illustrations

Dashboard illustrations explain:

- Workspace
- Analytics
- Productivity
- Monitoring
- Business Insights

They should complement dashboards without competing with live data.

---

# Feature Illustrations

Each major feature may have its own illustration.

Examples:

- Authentication
- Projects
- Tasks
- CRM
- Finance
- HR
- Inventory
- Orders
- Notifications
- AI Assistant

Each illustration should focus on one capability.

---

# Module Illustrations

Modules requiring dedicated artwork include:

- User Management
- Organization Management
- Project Management
- Task Management
- Workflow Engine
- AI Studio
- Knowledge Base
- Analytics
- Settings

---

# AI Feature Illustrations

Illustrations may represent:

- AI Agents
- AI Suggestions
- AI Workflows
- AI Reports
- AI Chat
- AI Memory
- AI Automation

Avoid representing AI as humanoid robots.

Focus on intelligence, automation, and collaboration.

---

# Analytics Illustrations

Illustrations support:

- Charts
- KPIs
- Reports
- Dashboards
- Trends
- Forecasts

Visuals should reinforce analytical thinking without duplicating actual charts.

---

# Workflow Illustrations

Workflow illustrations explain:

```text
Trigger

↓

Process

↓

Validation

↓

Automation

↓

Completion
```

Keep workflow graphics simple and sequential.

---

# Integration Illustrations

Integration visuals explain:

- APIs
- Third-party Apps
- Cloud Services
- Data Exchange
- Synchronization

Use generic integration symbols rather than vendor logos unless officially approved.

---

# Settings Illustrations

Settings pages may use illustrations to explain:

- Security
- Preferences
- Notifications
- Organization
- Integrations

Illustrations should remain secondary to settings controls.

---

# Help Center Illustrations

Help Center artwork supports:

- Tutorials
- FAQs
- Documentation
- Troubleshooting
- Learning Paths

Illustrations should simplify concepts rather than replace documentation.

---

# Success Illustrations

Used after successful actions.

Examples:

- Workspace Created
- Project Completed
- Report Generated
- AI Workflow Published
- Settings Saved

The visual should reinforce positive feedback.

---

# Visual Style

Product illustrations must follow:

- illustration-style.md
- illustration-guidelines.md

Characteristics:

- Flat
- Modern
- Minimal
- Functional
- Enterprise

---

# Composition

Recommended composition:

```text
Primary Feature

↓

Supporting Elements

↓

Minimal Background

↓

Whitespace
```

Avoid visual clutter.

---

# UI Relationship

Illustrations should support the interface—not replace it.

UI controls, forms, and data remain the primary focus.

---

# Characters

Characters are optional.

If included, they should represent:

- Users
- Teams
- Collaboration
- Productivity

Avoid exaggerated poses or emotions.

---

# Objects

Illustrations may include:

- Dashboards
- Cards
- Documents
- Charts
- AI Nodes
- Cloud
- Databases
- Workspaces
- Notifications

All objects should align with the Design System.

---

# Color Usage

Recommended balance:

| Color | Usage |
|--------|-------|
| Neutral | 70% |
| Brand Primary | 20% |
| Accent | 10% |

Maintain consistency with product UI.

---

# Typography

Avoid embedding text inside illustrations.

If labels are required:

- Use official typography
- Keep text editable
- Support localization

---

# Responsive Design

Product illustrations must work across:

- Desktop
- Laptop
- Tablet
- Mobile

Illustrations should scale gracefully without losing clarity.

---

# Accessibility

Product illustrations should:

- Maintain sufficient contrast
- Avoid color-only communication
- Include descriptive alternative text when informative
- Support responsive layouts

Decorative illustrations should use:

```html
aria-hidden="true"
```

---

# Performance

Illustrations should:

- Use optimized SVG
- Support lazy loading
- Minimize file size
- Preserve quality at all sizes

---

# AI-Assisted Creation

AI tools may assist with:

- Concept generation
- Composition ideas
- Variants
- Color exploration
- Layout suggestions

All AI-generated illustrations require human review and approval.

# Quality Checklist

Before approval:

- [ ] Supports one feature
- [ ] Brand compliant
- [ ] Accessible
- [ ] Responsive
- [ ] Optimized
- [ ] Source archived
- [ ] Metadata registered
- [ ] Export package generated
- [ ] Approved by Product Design

---

# Common Mistakes

Avoid:

- Using screenshots as illustrations
- Multiple unrelated concepts
- Decorative overload
- Inconsistent styles
- Embedded text
- Crowded layouts
- Off-brand colors
- Unoptimized assets

---

# Best Practices

- Explain one feature at a time.
- Keep visuals clean and focused.
- Reuse approved assets.
- Follow illustration standards.
- Optimize every export.
- Maintain accessibility.
- Archive source files.
- Register metadata.
- Test on all screen sizes.
- Review before release.
