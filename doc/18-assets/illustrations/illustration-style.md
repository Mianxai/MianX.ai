# Purpose

This document defines the official visual language used by every illustration throughout the Mianx.ai ecosystem.

It ensures that every illustration—whether created by an internal designer, external agency, or AI system—looks like it belongs to the same design family.

This document acts as the master visual specification for:

- Products
- Marketing
- Documentation
- Presentations
- Dashboards
- AI Workforce
- Websites
- Mobile Apps
- Enterprise Platforms

---

# Objectives

The illustration style system exists to:

- Build one recognizable visual identity
- Improve product consistency
- Simplify illustration creation
- Reduce redesign work
- Support scalable asset creation
- Enable AI-assisted illustration generation
- Improve accessibility
- Support long-term maintenance

---

# Design Philosophy

Every illustration should communicate one clear idea.

Illustrations should be:

- Clean
- Friendly
- Professional
- Modern
- Minimal
- Informative
- Trustworthy

Users should understand the illustration within a few seconds.

---

# Visual Identity

The official illustration language combines:

- Flat Design
- Minimalism
- Soft Geometry
- Enterprise Professionalism
- Human-Centered Communication

The visual language should feel:

- Intelligent
- Calm
- Modern
- Innovative
- Reliable

---

# Style Characteristics

The official illustration system follows these characteristics:

- Flat Shapes
- Rounded Corners
- Clean Outlines
- Balanced Layouts
- Soft Shadows
- Limited Gradients
- Controlled Color Palette
- Minimal Visual Noise

---

# Geometry

Illustrations should use simple geometric construction.

Preferred shapes:

- Circle
- Rounded Rectangle
- Square
- Oval
- Capsule
- Soft Polygon

Avoid:

- Random polygons
- Sharp spikes
- Irregular geometry
- Complex decorative shapes

---

# Grid System

Every illustration should align to a consistent layout grid.

Recommended grid:

```text
8px Base Grid

↓

16px Layout

↓

24px Component Alignment

↓

32px Major Sections
```

Objects should align naturally to the grid.

---

# Proportions

Maintain consistent proportions across all illustrations.

Recommended ratios:

- Human Head : Body = 1 : 6
- Icon : Object = 1 : 4
- Shadow : Object = 5–10%
- Padding = 8px multiples

Never stretch or distort illustration elements.

---

# Perspective

Approved perspectives:

- Flat
- Slight Isometric
- Soft Perspective

Choose one perspective per illustration.

Never mix perspectives.

---

# Depth

Depth should be subtle.

Methods:

- Soft Shadows
- Layering
- Elevation
- Overlapping Objects

Avoid:

- Dramatic perspective
- Heavy 3D rendering
- Excessive blur

---

# Shadows

Shadows should:

- Be soft
- Use low opacity
- Follow one light source
- Maintain consistency

Recommended opacity:

```text
8–15%
```

Avoid dark black shadows.

---

# Lighting

Official light direction:

```text
Top Left
```

All illustrations should use the same lighting direction unless a special case is documented.

---

# Color Philosophy

Color should communicate meaning.

Color hierarchy:

1. Neutral Colors
2. Brand Primary
3. Brand Secondary
4. Accent Colors

Avoid using colors purely for decoration.

---

# Color Distribution

Recommended balance:

| Color Type | Usage |
|------------|--------|
| Neutral | 70% |
| Primary | 20% |
| Accent | 10% |

This keeps illustrations clean and readable.

---

# Gradients

Gradients are optional.

If used:

- Very subtle
- Brand-approved colors only
- Maximum two colors
- No rainbow effects

Avoid glossy gradients.

---

# Stroke Style

All illustrations must use consistent strokes.

Requirements:

- Rounded Caps
- Rounded Joins
- Consistent Width
- Smooth Curves

Recommended stroke width:

```text
2px
```

Do not mix multiple stroke weights in one illustration.

---

# Corner Radius

Rounded corners improve consistency.

Recommended radius:

```text
4px

8px

12px
```

Use consistent radii throughout one illustration.

---

# Shapes

Shapes should appear:

- Balanced
- Predictable
- Soft
- Clean

Avoid decorative complexity.

---

# Characters

Character illustrations should represent:

- Employees
- Users
- Teams
- Customers
- AI Collaboration

Characters should appear:

- Friendly
- Professional
- Inclusive
- Diverse
- Neutral

---

# Facial Expressions

Preferred emotions:

- Happy
- Focused
- Curious
- Confident
- Helpful

Avoid:

- Angry
- Aggressive
- Scared
- Confused
- Exaggerated expressions

---

# Body Language

Characters should communicate:

- Collaboration
- Learning
- Building
- Creating
- Supporting
- Innovating

Avoid unrealistic poses.

---

# Clothing

Illustrated people should wear:

- Modern Business Casual
- Neutral Clothing
- Brand-Friendly Colors

Avoid:

- Fashion trends
- Loud patterns
- Brand conflicts

---

# Objects

Objects should:

- Match icon style
- Use soft geometry
- Follow grid alignment
- Maintain consistent scale

---

# Devices

Illustrated devices include:

- Desktop
- Laptop
- Tablet
- Phone
- Server
- Cloud

Devices should never imitate specific commercial products.

---

# Environment

Background environments should be minimal.

Examples:

- Workspace
- Office
- Dashboard
- Cloud
- Abstract Shapes

Avoid unnecessary scenery.

---

# Backgrounds

Preferred backgrounds:

- White
- Light Gray
- Transparent
- Soft Neutral

Illustrations should work on both light and dark interfaces.

---

# Visual Hierarchy

The eye should naturally move through:

```text
Primary Subject

↓

Supporting Objects

↓

Background Elements
```

Avoid competing focal points.

---

# Motion Language

Illustrations may imply motion using:

- Curved Lines
- Flow Arrows
- Connection Paths
- Soft Direction Indicators

Avoid comic-style motion effects.

---

# Animation Readiness

Illustrations should support future animation.

Objects should be designed as separate layers whenever possible.

---

# Empty Space

Always preserve whitespace.

Avoid filling every area with decorative objects.

Whitespace improves readability.

---

# Scalability

Illustrations should remain recognizable at:

- Small Cards
- Hero Sections
- Documentation
- Mobile
- Desktop
- Large Displays

---

# Accessibility

Illustrations must:

- Maintain contrast
- Avoid color-only communication
- Support screen readers through surrounding content
- Scale without losing clarity

Decorative illustrations should be hidden from assistive technologies.

---

# AI Generation Standards

AI-generated illustrations must follow:

- Official color palette
- Approved geometry
- Consistent perspective
- Brand identity
- Accessibility rules

AI outputs always require human review.

---

# Review Criteria

Every illustration should be reviewed for:

- Brand consistency
- Layout
- Color
- Composition
- Accessibility
- Scalability
- Performance
- Export quality

---

# Quality Checklist

Before approval:

- [ ] Matches official illustration style
- [ ] Uses approved colors
- [ ] Uses official geometry
- [ ] Perspective is consistent
- [ ] Lighting is correct
- [ ] Shadows are consistent
- [ ] Responsive
- [ ] Accessible
- [ ] Source files archived
- [ ] Approved by Design Team

---

# Common Mistakes

Avoid:

- Mixed illustration styles
- Inconsistent colors
- Multiple lighting directions
- Heavy gradients
- Random proportions
- Overly detailed artwork
- Excessive decorations
- Poor spacing
- Inconsistent characters
- Ignoring accessibility

---

# Best Practices

- Keep illustrations simple.
- Focus on communication.
- Maintain one visual language.
- Follow the design system.
- Reuse approved assets.
- Optimize for performance.
- Review every illustration.
- Archive master files.
- Document revisions.
- Maintain consistency across every product.
