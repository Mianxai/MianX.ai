# Usage Guidelines

Always:

- Use official exported files.
- Preserve proportions.
- Maintain clear space.
- Use approved colors.
- Follow the branding guide.

Never:

- Stretch the logo.
- Rotate the logo.
- Add effects.
- Change typography.
- Modify colors.
- Redraw the logo manually.

# Clear Space

Minimum clear space:

```text
1 × Logo Icon Height
```

No text, graphics, or interface elements should enter the protected area.
