# Purpose

The **logos** folder serves as the official repository for every approved logo used throughout the Mianx.ai ecosystem.

This repository provides a single source of truth for company, product, department, AI workforce, partner, and event logos.

Only assets stored in this folder should be considered official.

---

# Objectives

- Maintain a centralized logo repository.
- Protect brand identity.
- Eliminate duplicate logo versions.
- Support scalable branding.
- Enable AI-powered logo discovery.
- Preserve version history.

---

# Scope

This folder includes logos for:

- Company
- Products
- Departments
- AI Workforce
- Internal Projects
- Client Projects (where applicable)
- Events
- Partnerships
- Applications
- Mobile Apps
