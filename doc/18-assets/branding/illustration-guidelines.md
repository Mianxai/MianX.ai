# Purpose

This document defines the official illustration standards used throughout the Mianx.ai ecosystem.

It ensures visual consistency across all products, documentation, marketing materials, websites, mobile applications, presentations, AI interfaces, and enterprise solutions.

---

# Objectives

- Establish a unified illustration style.
- Maintain brand consistency.
- Support reusable illustration assets.
- Improve accessibility.
- Standardize AI-generated artwork.
- Enable scalable design systems.

---

# Scope

These guidelines apply to:

- Product Illustrations
- Marketing Graphics
- Documentation Graphics
- Blog Images
- Social Media Graphics
- Presentation Graphics
- Website Illustrations
- Landing Pages
- AI Generated Artwork
- Educational Graphics
- Infographics

---

# Illustration Philosophy

Every illustration should communicate:

- Innovation
- Intelligence
- Simplicity
- Professionalism
- Scalability
- Trust
- Automation
- Collaboration

---

# Illustration Style

Official illustrations should be:

- Modern
- Minimal
- Clean
- Flat or Semi-Flat
- Consistent
- Professional
- Technology-focused

Avoid:

- Cartoonish styles
- Excessive realism
- Overly decorative elements
- Inconsistent visual language

---

# Design Principles

Every illustration should follow:

- Simplicity
- Balance
- Consistency
- Readability
- Accessibility
- Scalability

---

# Color Usage

Illustrations must use:

- Official Brand Colors
- Approved Neutral Palette
- Semantic Colors
- Design Tokens

Avoid:

- Random colors
- Neon palettes
- Unapproved gradients

---

# Composition Rules

Illustrations should:

- Maintain visual balance
- Use consistent spacing
- Avoid unnecessary details
- Highlight the primary message
- Scale cleanly across devices

---

# Character Style

If characters are used, they should be:

- Diverse
- Professional
- Inclusive
- Technology-oriented
- Neutral in appearance

Characters should never promote stereotypes or offensive imagery.

---

# Icon Integration

Illustrations should use only approved icon libraries.

Icons must:

- Match illustration style
- Use consistent stroke width
- Follow the design system

---

# AI Generated Illustrations

AI-generated illustrations are allowed for:

- Concepts
- Drafts
- Marketing Ideas
- Internal Documentation
- Educational Content

Production use requires:

- Human Review
- Brand Compliance Check
- Quality Assurance
- Approval by the Design Team

---

# Accessibility

Illustrations should:

- Support sufficient contrast
- Avoid conveying information through color alone
- Include descriptive alternative text where appropriate
- Remain understandable at different sizes

---

# Responsive Design

Illustrations should render correctly on:

- Desktop
- Laptop
- Tablet
- Mobile
- Large Displays

---

# Supported Formats

Preferred formats:

- SVG
- PNG
- WebP
- PDF (Print)
- AI (Source)
- Figma

# Source Files

Maintain editable source files.

Examples:

- Figma
- Adobe Illustrator
- SVG Master Files

Never replace source files with exported images.

- [ ] Official typography followed (if applicable)
- [ ] Illustration style verified
- [ ] Accessibility checked
- [ ] Responsive scaling tested
- [ ] Source file archived
- [ ] Export quality verified

# Common Mistakes

Avoid:

- Pixelated exports
- Inconsistent colors
- Mixed illustration styles
- Unlicensed assets
- Low-resolution graphics
- Overly complex compositions
- Missing source files

- Quarterly
- During rebranding
- Before major product launches
- After design system updates

- Design once, reuse everywhere.
- Keep illustrations simple and meaningful.
- Use vector graphics whenever possible.
- Maintain consistent visual language.
- Preserve editable source files.
- Archive previous versions.
- Validate accessibility before release.
