# Purpose

This document defines the official logo architecture, usage standards, sizing rules, placement guidelines, export formats, and governance policies for all Mianx.ai logos.

The objective is to maintain one consistent visual identity across every platform and product.

---

# Objectives

- Standardize logo usage.
- Protect brand identity.
- Ensure consistent implementation.
- Prevent misuse.
- Support responsive digital products.
- Enable reusable branding assets.

---

# Logo Architecture

The Mianx.ai logo system consists of:

- Primary Logo
- Secondary Logo
- Icon Logo
- Wordmark
- Monochrome Logo
- Light Version
- Dark Version
- Horizontal Layout
- Vertical Layout
- Favicon

---

# Primary Logo

The primary logo is the default representation of the Mianx.ai brand.

Use it for:

- Website
- Dashboard
- Documentation
- Presentations
- Marketing
- Product Landing Pages

Status

```text
Default Brand Logo
```

---

# Secondary Logo

Used when layout constraints prevent the use of the primary logo.

Examples

- Narrow headers
- Small cards
- Mobile navigation

---

# Icon Logo

A simplified logo without the wordmark.

Used for:

- Mobile App Icon
- Browser Favicon
- AI Agent Avatar
- Notifications
- Small UI Components

---

# Wordmark

Text-only version of the brand.

Used for:

- Email Headers
- Documentation
- Presentations
- Legal Documents

---

# Monochrome Logo

Single-color version used when full color cannot be reproduced.

Examples

- Printing
- Embossing
- Laser Engraving
- Merchandise

---

# Logo Variants

Maintain approved versions only.

Examples

```text
Primary

Secondary

Dark

Light

Monochrome

Icon

Horizontal

Vertical
```

---

# Clear Space

Maintain clear space around every logo.

Minimum spacing should equal the height of the letter **M** in the logo.

No objects, text, or graphics may enter this protected area.

---

# Minimum Size

| Medium | Minimum Width |
|---------|---------------|
| Print | 25 mm |
| Website | 120 px |
| Mobile | 80 px |
| Favicon | 32 px |
| Social Media | 180 px |

---

# Background Usage

Preferred backgrounds:

- White
- Brand Primary
- Neutral Dark
- Neutral Light

Avoid:

- Busy backgrounds
- Low contrast images
- Patterned surfaces
- Complex gradients

---

# Color Usage

Only official brand colors may be used.

Never:

- Change colors
- Apply gradients
- Add textures
- Add shadows
- Add outlines
- Apply transparency

---

# Logo Scaling

Always scale proportionally.

Never:

- Stretch
- Compress
- Rotate
- Distort

---

# Logo Alignment

Recommended alignment:

- Left
- Center (limited use)

Avoid arbitrary placement.

---

# Logo Placement

Recommended locations:

- Top Left
- Navigation Header
- Documentation Cover
- Presentation Title
- Product Splash Screen

---

# Incorrect Usage

Never:

- Rotate the logo
- Change proportions
- Modify typography
- Add effects
- Use unofficial colors
- Recreate the logo manually
- Place on unreadable backgrounds
- Crop the logo

---

# File Formats

Maintain official exports in:

- SVG
- PNG
- PDF
- EPS
- AI

Preferred digital format:

```text
SVG
```

# Source Files

Always preserve original design files.

Examples

- Figma
- Adobe Illustrator
- SVG Master
- PDF Master

Generated exports must never replace source files.

# Version Control

Each logo release should include:

- Version
- Release Date
- Designer
- Reviewer
- Approval Status
- Change Notes

---

# Accessibility

Ensure:

- High contrast
- Minimum readable size
- Proper spacing
- Responsive display

---

# AI Usage

AI-generated logos are:

- Prototype only
- Never production-ready without review

Every AI-generated logo must receive human approval before official use.

---

# Maintenance

Review logo assets when:

- Rebranding occurs
- Product identity changes
- Marketing strategy changes
- New platforms are introduced

---

# Review Checklist

Before publishing:

- [ ] Correct logo variant
- [ ] Official colors
- [ ] Proper spacing
- [ ] Minimum size respected
- [ ] Correct background
- [ ] Export quality verified
- [ ] Version updated
- [ ] Source file archived
