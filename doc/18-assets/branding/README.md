# Purpose

The **branding** folder contains every asset related to the visual identity of Mianx.ai.

It acts as the single source of truth for all branding materials used across:

- Website
- SaaS Platform
- Mobile Applications
- Documentation
- Marketing
- Social Media
- Sales Material
- Presentations
- AI Interfaces
- Client Deliverables

---

# Objectives

- Maintain one official brand identity.
- Standardize branding across all products.
- Prevent inconsistent brand usage.
- Centralize reusable branding assets.
- Support enterprise scalability.

# Branding Standards

Every branding asset must:

- Follow the Branding Guide
- Use approved colors
- Use approved typography
- Be version controlled
- Have an assigned owner
