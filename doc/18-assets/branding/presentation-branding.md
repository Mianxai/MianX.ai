# Purpose

This document defines the official presentation branding standards used throughout the Mianx.ai ecosystem.

Every presentation must maintain a professional, consistent, and enterprise-grade appearance while communicating information clearly and effectively.

---

# Objectives

- Standardize presentation design.
- Maintain brand consistency.
- Improve readability.
- Create reusable presentation templates.
- Support executive, client, and internal communications.
- Ensure accessibility.

# Brand Identity

Every presentation must use:

- Official Logo
- Official Color Palette
- Approved Typography
- Official Icons
- Approved Illustrations

---

# Cover Slide

The first slide should include:

- Presentation Title
- Subtitle
- Presenter Name
- Department
- Date
- Company Logo

---

# Closing Slide

The final slide should include:

- Thank You
- Contact Information
- Website
- Email
- QR Code (Optional)

---

# Slide Layout

Maintain consistent layouts.

Recommended structure:

- Title
- Subtitle
- Content Area
- Footer

---

# Typography

Use the official typography system.

Hierarchy:

- Presentation Title
- Section Title
- Slide Heading
- Body Text
- Caption
- Footer

Avoid excessive text.

---

# Color Usage

Only approved brand colors may be used.

Use semantic colors for:

- Success
- Warning
- Error
- Information

Maintain sufficient contrast for readability.

---

# Logo Placement

Recommended locations:

- Top Left
- Bottom Right
- Cover Slide
- Closing Slide

Maintain clear space around the logo.

---

# Icons

Use only approved icon libraries.

Icons should:

- Match the design system
- Maintain consistent size
- Use official colors

---

# Images

Images should be:

- High Resolution
- Relevant
- Professional
- Properly Licensed

Avoid:

- Pixelated images
- Watermarked graphics
- Low-quality screenshots

---

# Charts & Graphs

Charts should:

- Use official color palette
- Be clearly labeled
- Avoid unnecessary decoration
- Display accurate data

Recommended charts:

- Bar
- Line
- Pie (limited use)
- Area
- KPI Cards

---

# Tables

Tables should:

- Use consistent spacing
- Follow typography hierarchy
- Be easy to read
- Avoid excessive columns

---

# Illustrations

Use approved illustrations only.

Illustrations should support the message and never distract from it.

---

# AI Generated Content

AI may assist in creating:

- Draft Slides
- Speaker Notes
- Graphics
- Diagrams
- Summaries

Every AI-generated presentation must be reviewed by a human before distribution.

---

# Speaker Notes

Speaker notes should:

- Explain key points
- Include supporting information
- Avoid reading slides verbatim

---

# Accessibility

Presentations should comply with:

- WCAG 2.2
- High Contrast
- Readable Font Sizes
- Meaningful Image Alt Text (where supported)
- Accessible Color Choices

# Common Mistakes

Avoid:

- Too much text
- Low-quality graphics
- Inconsistent layouts
- Small fonts
- Random colors
- Excessive animations
- Missing branding
- Outdated information

# Best Practices

- One key message per slide.
- Keep presentations visually clean.
- Use reusable templates.
- Maintain consistent spacing.
- Minimize animations.
- Validate all statistics before publishing.
- Archive every major presentation version.
