# Versioning Policy

Branding follows Semantic Versioning.

| Version | Meaning |
|----------|---------|
| Major (2.0.0) | Rebranding or significant visual identity changes |
| Minor (1.1.0) | New branding assets or design improvements |
| Patch (1.0.1) | Small fixes and corrections |
