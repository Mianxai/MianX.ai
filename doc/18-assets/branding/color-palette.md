# Purpose

This document defines the official color system used throughout the Mianx.ai ecosystem.

It ensures every digital product, website, mobile application, AI interface, document, presentation, and marketing asset follows a consistent visual identity.

---

# Objectives

- Establish a consistent enterprise color system.
- Improve UI consistency.
- Support accessibility standards.
- Simplify design decisions.
- Enable reusable design tokens.

---

# Usage Guidelines

Always:

- Use design tokens.
- Maintain consistency.
- Test contrast.
- Reuse existing colors.

Never:

- Invent random colors.
- Hardcode colors in production.
- Mix different color systems.
- Use low-contrast combinations.
