# Purpose

This document defines the official typography system used throughout the Mianx.ai ecosystem.

Typography creates a consistent reading experience across every digital and physical product while improving usability, accessibility, and brand recognition.

---

# Objectives

- Establish a consistent typography system.
- Improve readability.
- Support responsive interfaces.
- Ensure accessibility compliance.
- Enable reusable typography tokens.
- Maintain enterprise-level design consistency.

---

# Typography Philosophy

Typography should always be:

- Clean
- Modern
- Professional
- Readable
- Scalable
- Accessible
- Minimal
- Consistent

---

# Typography System

The typography system consists of:

- Font Families
- Font Weights
- Font Sizes
- Line Heights
- Letter Spacing
- Paragraph Spacing
- Responsive Scaling
- Design Tokens

# Body Text

Use body typography for:

- Documentation
- UI Text
- Articles
- Reports
- Descriptions

---

# Small Text

Used for:

- Labels
- Badges
- Captions
- Footnotes

---

# Code Typography

Code blocks should always use the official monospace font.

Used for:

- Source Code
- Terminal Commands
- JSON
- YAML
- SQL
- Configuration

---

# Responsive Typography

Typography should scale based on screen size.

Supported breakpoints:

- Mobile
- Tablet
- Laptop
- Desktop
- Large Display

---

# Line Height

Recommended line-height should prioritize readability.

Examples

| Type | Recommendation |
|------|----------------|
| Headings | Tight |
| Body | Comfortable |
| Code | Consistent |

---

# Letter Spacing

Letter spacing should remain subtle.

Used for:

- Headings
- Buttons
- Navigation
- Labels

---

# Paragraph Spacing

Maintain consistent spacing between paragraphs throughout all products and documentation.

---

# Text Alignment

Preferred alignment:

- Left aligned for body text.
- Center only for specific UI elements.
- Avoid justified text unless required.

---

# Text Transform

Allowed

- Sentence Case
- Title Case
- UPPERCASE (labels only)

Avoid excessive uppercase paragraphs.

---

font-weight-bold

letter-spacing-normal

# Accessibility

Typography must comply with:

- WCAG 2.2
- Minimum readable font sizes
- Proper line spacing
- High contrast
- Responsive scaling

---

# UI Components

Typography standards apply to:

- Buttons
- Forms
- Tables
- Navigation
- Cards
- Dialogs
- Tooltips
- Menus

---

# Documentation Standards

All documentation should use:

- Consistent heading hierarchy
- Standard paragraph spacing
- Readable code formatting
- Proper list formatting
- Accessible tables

---

# AI Interfaces

Typography for AI interfaces should ensure:

- Easy conversation reading
- Clear distinction between user and AI responses
- Readable code blocks
- Highlighted warnings and suggestions

---

# Multi-language Support

Typography should support:

- English
- Urdu (future support)
- Unicode characters
- Technical symbols
- Mathematical notation

---

# Performance Guidelines

- Minimize unnecessary font files.
- Prefer variable fonts where supported.
- Optimize web font loading.
- Use local fallbacks.

- Limit the number of font families.
- Ensure accessibility across all devices.
