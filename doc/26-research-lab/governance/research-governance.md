* Research task is routed to Founder and system marks it approved because no response arrived.

* Project-level Research approval is reused across unrelated Projects.
* Tenant-specific Research permission is reused for another Tenant.
* Research Program approval is treated as blanket authorization for any Dataset or Model.
* Experiment was approved using Model A but Run silently switches to Model B with different provider/Data handling.
* Research classified R1 adds external Tool side effects but risk class is never re-reviewed.
* Agent performs several A2 tasks successfully and self-promotes to A4 autonomy.
* AI Researcher generates strong conclusion and Knowledge Base labels it canonical without independent review.
* Human Researcher treats their role as permission to bypass Data or Security policy.
* parent Agent creates 50 child Agents that inherit broad Tools and no fanout governance exists.
* Agent Tool is visible in runtime and Agent interprets visibility as authorization.
* old Founder approval stored in Memory is treated as current despite scope or expiry change.
* shared Research platform causes Tenant context leakage and governance dashboard still shows compliant because Tenant IDs are populated.
* Benchmark score leads Research team to integrate Model into Product before Production review.
* Simulation succeeds and physical system is approved without real-world validation.
* Research prototype becomes customer-facing service because it technically works.
* collaborator has an NDA and Research team assumes every Dataset may therefore be shared.
* conflict-of-interest disclosure is stored but no mitigation occurs.
* Research team reviews its own high-risk Result and labels review independent.
* governance committee unanimous vote is represented as scientific proof.
* Security reviewer approves Security posture and documentation claims Founder approved whole Research Program.
* internal exception is used to override external contractual restriction.
