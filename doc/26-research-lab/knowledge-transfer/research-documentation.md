# Mianx.ai Research Lab Knowledge Transfer — Research Documentation

> **Research that cannot be traced cannot be governed reliably.**
>
> **Research that cannot be reproduced cannot be trusted at the same level as Research that can.**

* repository contains architecture document and system dashboard claims architecture implemented.
* Draft front matter is manually changed to Approved without approval Evidence.

* Founder did not respond and silence is treated as approval.
* Experiment raw JSON output is copied directly into Results section and called Research conclusion.
* hypothesis wording is repeated in Conclusion despite contradictory Results.
* negative Result is omitted because it weakens desired narrative.
* Dataset filename remains same after content changes and document says Dataset unchanged.
* Model alias remains same but provider updates Model and experiment record still claims same Model.
* Prompt file name remains same after edits and Run documentation claims exact Prompt reproduction.
* retry is documented as independent replication.
* seed is documented and system claims full determinism.
* Judge Model score is presented as objective truth.
* architecture diagram is current but runtime topology changed and no drift note exists.
* Research recommendation is written and Product system treats it as implementation mandate.
* AI drafts a citation that does not exist and document publishes it without verification.
* AI fills an unknown Experiment configuration field with a plausible default.
* external paper contains malicious instruction and Research documentation Agent treats it as internal command.
* Project A Research Result is copied into Project B document as universally applicable without validation.
* Tenant A examples are included in broad internal documentation without Data authorization.
* document says privacy reviewed because privacy section exists but no review Evidence exists.
* document says implementation verified because code file exists and test file exists, but tests were never executed.
