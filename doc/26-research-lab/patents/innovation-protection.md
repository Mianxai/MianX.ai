# 201. Negative Verification Scenarios

Containment, correction, legal routing or governance escalation should occur when:

* Researcher labels an idea "patentable" without authorized legal review.
* internal invention disclosure is published in a public repository by mistake.
* contributor list is treated as final legal inventorship list.
* AI Agent is declared legal inventor based solely on contribution logs.
* complete Git history is treated as conclusive ownership Evidence.
* contractor-developed code is assumed owned without checking agreement/assignment.
* Tenant-specific workflow is moved into shared Mianx.ai template without contract review.
* confidential label is applied but repository remains publicly accessible.
* patent search finds no similar result and team states novelty proven.
* prior-art search result is presented as legal patentability opinion.
* patent candidate is described to investors or clients as patented technology.
* application preparation draft is described as filed application.
* application filing is described as granted patent.
* granted patent is treated as proof of product-market fit.
* patent grant is treated as proof no third-party rights matter.
* defensive publication is performed without considering confidentiality/future filing implications.
* open-source dependency is treated as no-obligation because source is public.
* generated code includes third-party code whose license is not reviewed.
* Dataset is downloaded lawfully but redistribution/training rights are assumed.
* synthetic Data is described as automatically rights-free.
* hosted Model use is described as ownership of Model.
* fine-tuned adapter is described as fully owned without base-model/license review.
* Prompt is labeled proprietary and exclusive legal ownership is asserted without legal basis.
* Agent architecture is valuable and automatically described as patentable.
* security mechanism is publicly disclosed before security and protection review.
* Research paper is approved scientifically and public disclosure begins before IP triage.
* GitHub repository is technically ready and released without open-source/IP review.
* external collaborator contributes core design while foreground ownership terms are unclear.
* client-funded innovation is absorbed into core platform despite conflicting contract rights.
* external patent is found and researcher declares infringement.
* Researcher interprets patent claim as legal claim construction.
* AI-generated patent summary invents patent number or legal status.
* legal-review ticket is opened and dashboard treats issue as legally cleared.
* protection strategy is marked "trade secret" while information has already been publicly disclosed.
* patent candidate status remains unchanged after major technical redesign.
* public disclosure occurs and team deletes the webpage then records "no disclosure."
* controlled IP Pilot succeeds and system is described as legally validated or Production-ready.
