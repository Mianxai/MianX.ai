# 15. Long-Term Storage Meaning

Within Mianx.ai documentation, the phrase:

```text
LONG-TERM STORAGE
```

should mean:

> Storage mechanisms used to persist Memory whose approved lifecycle
> extends beyond transient Working or Short-Term execution state.

It does not imply one specific database technology.
