# Mianx.ai Memory Engine Project Memory

> **This document defines Project Memory as a governed Memory domain
> within the Mianx.ai Memory Engine.**
>
> **Project Memory is the persistent and temporary knowledge associated
> with one explicitly identified Project. It exists to preserve Project
> continuity across Tasks, Workflows, Sessions, Agents, Models, tools,
> teams, incidents, releases, and time without allowing one Project's
> Memory to leak into another Project.**
>
> **Project Memory may contain requirements, decisions, architecture,
> domain knowledge, technical constraints, Customer requirements,
> workflows, incidents, lessons, preferences, release history,
> operational knowledge, Episodic Memory, Semantic Memory, Agent-derived
> learning, and other approved Project-scoped information.**
>
> **Project Memory is not Organization Memory. Reusable Project knowledge
> may become Organization Memory only through governed promotion.**
>
> **Project Memory is not automatically Customer Memory. A Project may be
> Customer-bound, internally owned, shared across authorized enterprise
> purposes, or otherwise governed. Customer scope and Project scope must
> remain explicitly represented rather than inferred from naming alone.**
>
> **Project Memory is not access authority. Historical Project membership,
> historical Agent assignment, prior Tool use, old approval, or previous
> Work Envelope state stored in Memory cannot establish current
> authorization.**
>
> **Project isolation is a hard control, not a retrieval preference.
> Project A Memory must not become available to Project B merely because
> it is semantically similar, stored in the same database, indexed in the
> same platform, connected through shared Knowledge Graph entities, or
> processed by the same AI Workforce.**
>
> **This document defines target-state Project Memory semantics only.
> Project Memory runtime, Project isolation, Customer binding, Project
> retrieval, promotion, archival, deletion, monitoring, and Production
> capability remain `NOT_PROVEN` unless separate implementation Evidence
> demonstrates them.**
