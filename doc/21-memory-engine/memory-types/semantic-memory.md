# Mianx.ai Memory Engine Semantic Memory

> **This document defines Semantic Memory as a governed Memory Type within
> the Mianx.ai Memory Engine.**
>
> **Semantic Memory represents durable meaning-oriented knowledge such as
> facts, concepts, definitions, rules, classifications, relationships,
> procedures, domain knowledge, validated generalizations, and other
> structured or unstructured knowledge propositions.**
>
> **Semantic Memory is not automatically canonical truth. A semantic
> statement may be authoritative, validated, inferred, disputed,
> Customer-specific, Project-specific, historical, stale, tentative, or
> merely derived from another source. Those distinctions must remain
> explicit.**
>
> **Semantic similarity is not truth. Embedding proximity is not fact
> equivalence. Knowledge Graph connectivity is not authority. Repeated
> statements are not automatically correct. Model confidence is not
> evidence.**
>
> **Semantic Memory must preserve source provenance, authority class,
> scope, classification, temporal applicability, lifecycle, and
> contradictions where required.**
>
> **Customer-specific Semantic Memory remains Customer-scoped unless a
> governed generalization and promotion process explicitly permits broader
> use. Identical or similar knowledge across Customers does not
> automatically permit shared storage, shared retrieval, or Organization
> promotion.**
>
> **This document defines target-state Semantic Memory semantics only. It
> does not prove that Semantic Storage, Semantic Retrieval, embeddings,
> Vector indexes, Knowledge Graph integration, contradiction detection,
> knowledge promotion, canonicalization, Customer/Tenant isolation,
> monitoring, or Production Semantic Memory runtime currently exists.**

# 3. Semantic Memory Mission

The mission is:

> **Preserve reusable meaning-oriented knowledge with explicit
> provenance, authority, scope, validity, uncertainty, contradiction,
> lifecycle, Security, and Privacy boundaries so AI Agents and enterprise
> systems can reason from knowledge without turning inference,
> similarity, popularity, or historical statements into uncontrolled
> truth.**
