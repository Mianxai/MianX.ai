# Mianx.ai Memory Engine Long-Term Memory

> **This document defines Long-Term Memory as a governed Memory Type
> within the Mianx.ai Memory Engine.**
>
> **Long-Term Memory is durable Memory intentionally retained beyond
> transient execution horizons because it has approved continuing
> operational, knowledge, historical, organizational, Project, Customer,
> User, Agent, audit, learning, or governance value.**
>
> **Long-Term does not mean permanent. Retention remains controlled by
> lifecycle, purpose, Customer obligations, Privacy, Security, legal,
> operational, and governance requirements.**
>
> **Technical persistence alone does not make data approved Long-Term
> Memory. A database row, cache entry, transcript, log, vector, index,
> backup, graph projection, or archived file becomes governed Long-Term
> Memory only when its semantic role and lifecycle permit it.**
>
> **Long-Term Memory may preserve facts, decisions, preferences,
> procedures, historical Episodes, validated learning, Project knowledge,
> Organization knowledge, Agent knowledge, User knowledge, and other
> approved durable information. Different categories may have different
> authority, freshness, scope, retention, and retrieval rules.**
>
> **Long-Term Memory must not freeze historical authorization. Historical
> roles, Customer membership, approvals, Agent Tool access, or Work
> Envelopes recorded in durable Memory do not recreate current authority.**
>
> **Long-Term Memory may remain historically valid while becoming stale
> for current decision-making. Retention, factual validity, operational
> relevance, and retrieval eligibility are separate properties.**
>
> **This document defines target-state Long-Term Memory semantics only. It
> does not prove that Long-Term Memory runtime, storage, admission,
> promotion, retention, archival, deletion, revalidation, retrieval,
> Customer/Tenant isolation, monitoring, or Production capability
> currently exists.**
