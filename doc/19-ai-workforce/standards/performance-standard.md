# 8. Performance Principles

The performance system must follow:

1. Founder sovereignty;
2. qualified Human accountability;
3. evidence before score;
4. measurement before judgment;
5. baseline before target comparison;
6. context before interpretation;
7. quality before raw volume;
8. reliability before speed-only optimization;
9. Risk-aware scoring;
10. Customer and Tenant boundary preservation;
11. no unsupported target claims;
12. no hidden metric weighting;
13. no automated punitive action without governed authority;
14. metric gaming must be actively controlled;
15. Data quality must be visible;
16. confidence must be explicit;
17. score changes must be traceable;
18. improvement is preferred over opaque punishment;
19. performance must not override Security, Privacy, Ethics, or Compliance;
20. documentation must not be represented as runtime measurement.

# 10. Founder Sovereignty

The Founder retains authority where performance decisions materially affect:

- Company strategy;
- executive accountability;
- Founder-reserved positions;
- enterprise-wide priorities;
- unrestricted AI autonomy;
- major workforce restructuring;
- existential Risk;
- matters explicitly reserved to the Founder.

Performance systems must not:

- fabricate Founder targets;
- fabricate Founder performance ratings;
- infer Founder decisions from scorecards;
- automatically sanction Founder-reserved roles;
- create Company-wide strategy from metric outputs.

---

# 11. Qualified Human Accountability

Qualified Human accountability is mandatory for:

- Human employment decisions;
- hiring or termination decisions;
- executive performance determinations;
- financial incentive approvals;
- legal-performance interpretation;
- Security-performance decisions;
- Privacy-performance decisions;
- Ethics-performance decisions;
- Compliance-performance decisions;
- high-impact Agent suspension;
- Production restriction;
- Customer contractual performance interpretation.

AI Agents may:

- measure;
- aggregate;
- calculate;
- detect anomalies;
- prepare scorecards;
- recommend actions;
- identify trends.

AI Agents must not replace required Human judgment.

objective.

- closing Tasks prematurely;
- avoiding difficult Tasks;
- suppressing escalations;
- reducing quality to increase throughput;
- splitting Tasks to inflate completion count;

- hiding failures;
