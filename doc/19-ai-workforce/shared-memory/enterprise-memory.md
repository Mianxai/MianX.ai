# Mianx.ai Enterprise Memory Governance Standard

> **This document defines the governed target-state standard for preserving,
> promoting, verifying, sharing, correcting, superseding, retaining,
> suspending, and auditing Company-wide institutional knowledge across
> Mianx.ai without confusing Enterprise Memory with Founder authority,
> Governance source records, policies, standards, evidence, Customer Data,
> Tenant Data, or Production truth.**

---

This document establishes the official target-state Enterprise Memory
Governance Standard for Mianx.ai.

- Enterprise Memory authority;

This standard ensures that information does not become Enterprise Memory
merely because:

- it appears in multiple Projects;

- multiple Humans believe it;

- a Project team recommends it;
- a Tool generates it;

- it has existed for a long time;
- documentation is marked complete.

```text

↓
Mianx.ai AI Operating System
↓
Shared AI Workforce
↓
Industry Operating Systems
↓
```

- the MianX Core Platform to be represented as the whole Company;
- the AI Operating System to be represented as the Company’s legal identity;
- the Shared AI Workforce to become the source of Founder authority;
- an Industry Operating System to redefine Company strategy;

- one Project’s implementation to become Company-wide architecture
  automatically;

- one Tenant’s preference to become Product truth;
- one Agent’s memory to become institutional truth without review.

# 10. Founder Sovereignty

Founder authority is preserved for:

- Company identity;
- Company vision;
- Company mission;
- Company principles;
- enterprise philosophy;
- AI Constitution;
- enterprise hierarchy;
- Founder-reserved strategic decisions;
- major organizational direction;
- unrestricted AI autonomy;
- existential enterprise Risk;
- Company-wide Production authorization;
- matters explicitly reserved to the Founder.

Enterprise Memory may preserve Founder decisions but must not:

- fabricate a Founder decision;
- infer Founder approval from silence;
- convert a draft into Founder-approved memory;
- replace the original Founder source;

# 14. Enterprise Memory Versioning

Enterprise Memory versions should follow:

```text
MAJOR
=
Meaning, authority, source, scope, strategic direction, ownership, or
material truth-status change

MINOR
=
Material clarification, additional source, confidence change, constraint
change, assumption change, or relationship change

PATCH
=
Formatting, metadata correction, typo correction, citation correction, or
non-material annotation
```

A material source change must trigger review of dependent Enterprise Memory.
