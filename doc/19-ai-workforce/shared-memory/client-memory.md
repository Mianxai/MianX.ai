# 14. Customer ID Standard

Proposed format:

```text
CUS-{REGION}-{YEAR}-{SEQUENCE}
```

Examples:

```text
CUS-PK-2026-000001

CUS-UK-2026-000001

CUS-US-2026-000001

CUS-GLOBAL-2026-000001
```

Customer Version ID:

```text
{CUSTOMER-ID}-V{MAJOR}.{MINOR}.{PATCH}
```

Tenant ID:

```text
TEN-{CUSTOMER-ID}-{SEQUENCE}
```

Customer Memory ID:

```text
CMEM-{CUSTOMER-ID}-{CATEGORY}-{SEQUENCE}
```

Tenant Memory ID:

```text
TMEM-{TENANT-ID}-{CATEGORY}-{SEQUENCE}
```

Customer Relationship ID:

```text
CREL-{CUSTOMER-ID}-{SEQUENCE}
```


```text

```


