# Mianx.ai Project Memory Governance Standard

> **This document defines the governed target-state standard for creating,
> using, correcting, verifying, closing, archiving, and promoting
> Project-scoped memory across Human and AI Workforce operations while
> preserving Product ownership, Customer and Tenant isolation, source truth,
> decision authority, delivery evidence, and Enterprise Governance.**

# 10. Founder and Enterprise Governance Boundaries

Founder and Enterprise Governance authority is preserved for:

- Company identity;
- AI Constitution;
- enterprise hierarchy;
- Founder-reserved strategy;
- Company-wide policies;
- Company-wide standards;
- major Product portfolio decisions;
- unrestricted AI autonomy;
- major financial commitments;
- high-impact Customer commitments;
- existential Risk;
- enterprise-wide Production authorization;
- matters explicitly reserved to the Founder.

A Project must not:

- fabricate Founder sponsorship;
- infer Founder approval from Project funding;
- override Enterprise Governance;
- create Company-wide policy;
- create Enterprise Memory directly;
- redefine the Company vision;
- claim Production authorization from Project approval alone.
