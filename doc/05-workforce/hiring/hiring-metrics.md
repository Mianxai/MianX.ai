# Hiring Metrics

> This document defines the hiring metrics and Key Performance Indicators (KPIs) used by MIANX to measure, analyze, and continuously improve recruitment performance. Hiring metrics provide visibility into recruitment efficiency, hiring quality, candidate experience, and workforce planning.

Hiring metrics should support data-driven decision making rather than replacing professional judgment.

---

# Purpose

The purpose of Hiring Metrics is to establish a standardized framework for measuring recruitment effectiveness across the entire hiring lifecycle.

---

# Objectives

The hiring metrics framework aims to:

- Measure hiring efficiency
- Improve recruitment quality
- Optimize hiring costs
- Support workforce planning
- Enhance candidate experience
- Increase hiring consistency
- Reduce recruitment bottlenecks
- Improve decision making
- Monitor hiring performance
- Drive continuous improvement

---

# Metric Categories

Hiring metrics are grouped into:

- Recruitment Efficiency
- Candidate Pipeline
- Hiring Quality
- Candidate Experience
- Financial Metrics
- Diversity Metrics
- Workforce Planning
- Hiring Performance

---

# Recruitment Efficiency Metrics

## Time to Hire

Measures the time from a candidate's application to offer acceptance.

Formula:

```text
Offer Acceptance Date
−
Application Date
```

Lower values generally indicate a more efficient hiring process.

---

## Time to Fill

Measures the time required to fill an approved position.

Formula:

```text
Position Filled Date
−
Job Approval Date
```

This metric reflects recruitment planning efficiency.

---

## Hiring Velocity

Measures how quickly hiring objectives are completed.

Example:

```text
25 hires / quarter
```

Hiring velocity should align with workforce planning goals.

---

# Candidate Pipeline Metrics

Monitor:

- Applications Received
- Qualified Candidates
- Screened Candidates
- Interviewed Candidates
- Finalists
- Offers Extended
- Offers Accepted
- Hires Completed

Pipeline metrics help identify recruitment bottlenecks.

---

# Funnel Conversion Metrics

Track conversion rates between hiring stages.

Example:

| Stage | Conversion Rate |
|---------|----------------:|
| Application → Screening | 72% |
| Screening → Interview | 58% |
| Interview → Assessment | 74% |
| Assessment → Offer | 39% |
| Offer → Acceptance | 87% |

Significant drops should be investigated.

---

# Hiring Quality Metrics

Recommended indicators:

- New Hire Performance
- Manager Satisfaction
- Employee Productivity
- Probation Success Rate
- Promotion Rate
- Employee Retention
- Internal Mobility
- Training Completion

Hiring quality is more important than hiring speed.

---

# Candidate Experience Metrics

Measure:

- Candidate Satisfaction Score
- Communication Response Time
- Interview Experience
- Offer Experience
- Application Completion Rate
- Candidate Feedback Score

A positive hiring experience strengthens employer reputation.

---

# Financial Metrics

Track:

| Metric | Description |
|----------|-------------|
| Cost per Hire | Total recruitment cost per employee |
| Recruitment Budget | Planned hiring expenditure |
| Agency Costs | External recruitment spending |
| Advertising Cost | Job promotion expenses |
| Interview Cost | Internal interview expenses |
| Onboarding Cost | Initial employee setup cost |

Financial metrics support budgeting and workforce planning.

---

# Diversity Metrics

Where legally appropriate, organizations may monitor:

- Candidate source diversity
- Hiring channel effectiveness
- Department diversity trends
- Inclusive recruitment practices

These metrics should support fair and equitable recruitment without influencing individual hiring decisions.

---

# Workforce Planning Metrics

Track:

- Approved Headcount
- Filled Positions
- Open Positions
- Hiring Forecast Accuracy
- Workforce Growth
- Department Capacity
- Vacancy Rate
- Hiring Demand

These metrics help align recruitment with business objectives.

---

# Recruiter Performance Metrics

Recruitment teams may monitor:

- Positions Filled
- Time to Hire
- Candidate Satisfaction
- Offer Acceptance Rate
- Hiring Quality
- Interview Scheduling Efficiency
- Pipeline Growth
- Hiring Accuracy

Performance metrics should encourage improvement rather than unhealthy competition.

# Data Sources

Hiring metrics may be collected from:

- Applicant Tracking System (ATS)
- HR Management System (HRMS)
- Interview Scorecards
- Recruitment Dashboards
- Candidate Surveys
- Onboarding Records
- Performance Reviews
- Finance Systems

Data should be validated before reporting.

---

# Data Quality

Hiring metrics should be:

- Accurate
- Complete
- Timely
- Consistent
- Secure
- Auditable
- Version controlled

Reliable data is essential for effective workforce planning.

---

# Best Practices

Recommended:

- Define standardized KPIs
- Automate data collection where possible
- Review metrics regularly
- Investigate unusual trends
- Share insights with leadership
- Use metrics to improve—not punish
- Align metrics with business objectives
- Continuously refine measurement methods

---

# Anti-Patterns

Avoid:

- Measuring only hiring speed
- Ignoring hiring quality
- Using inconsistent definitions
- Collecting unnecessary data
- Making decisions without context
- Focusing on vanity metrics
- Delaying reporting
- Ignoring candidate feedback
