# UI Designer

> This document defines the responsibilities, authority, expectations, and performance standards of the UI Designer at MIANX.

The UI Designer is responsible for designing visually appealing, intuitive, and accessible user interfaces across MIANX products. The role transforms UX concepts into polished interface designs that align with the MIANX Design System while ensuring consistency, usability, responsiveness, and brand identity.

The UI Designer reports directly to the Head of Design.

---

# Purpose

The purpose of the UI Designer role is to create high-quality user interfaces that enhance customer experience while maintaining consistency across all digital products.

---

# Mission

The UI Designer exists to:

- Create intuitive interfaces
- Improve visual consistency
- Enhance usability
- Support product development
- Maintain design standards
- Promote accessibility
- Strengthen brand identity
- Continuously improve user interfaces

---

# Role Summary

The UI Designer contributes to:

- User Interface Design
- Design Systems
- Visual Design
- Responsive Design
- Component Libraries
- Accessibility
- Product Design
- Design Documentation
- Design Reviews
- Cross-functional Collaboration

---

# Primary Responsibilities

The UI Designer is responsible for:

- Designing user interfaces
- Creating responsive layouts
- Building reusable UI components
- Maintaining design consistency
- Applying brand guidelines
- Producing design assets
- Supporting usability improvements
- Updating design documentation
- Participating in design reviews
- Collaborating with development teams

---

# User Interface Responsibilities

The UI Designer designs:

- Application Interfaces
- Web Pages
- Mobile Screens
- Dashboards
- Admin Panels
- Customer Portals
- Landing Pages
- Interactive Components

Interfaces should be visually consistent, intuitive, and accessible.

---

# Visual Design Responsibilities

The UI Designer creates:

- High-Fidelity Mockups
- Icons
- Typography Systems
- Color Palettes
- Layout Grids
- Interface States
- Visual Assets
- Component Variations

Visual design should reinforce usability and brand consistency.

---

# Design System Responsibilities

The UI Designer contributes to:

- Component Libraries
- Design Tokens
- Style Guides
- UI Standards
- Reusable Components
- Pattern Libraries
- Visual Documentation
- Component Specifications

The design system should remain scalable and consistent across products.

---

# Accessibility Responsibilities

The UI Designer ensures:

- Accessible Color Contrast
- Readable Typography
- Keyboard Accessibility
- Responsive Interfaces
- WCAG Compliance
- Consistent Navigation
- Clear Visual Hierarchy
- Inclusive Design

Accessibility should be considered throughout the design process.

---

# Collaboration

The UI Designer collaborates with:

- UX Architect
- UX Researchers
- Product Designers
- Senior Product Designers
- Product Managers
- Software Engineers
- QA Engineers
- Marketing Teams
- Brand Team
- Customer Success

Effective collaboration ensures seamless implementation of product designs.

---

# Decision Authority

The UI Designer may approve:

- UI Mockups
- Visual Assets
- Component Styling
- Layout Improvements
- Responsive Adjustments
- Icon Updates
- Design Documentation
- Minor Interface Enhancements

Major design decisions require approval from the Senior Product Designer or Head of Design.

The UI Designer should demonstrate expertise in:

- Color Theory

- Accessibility

The UI Designer is expected to:

- Deliver visually polished interfaces
- Maintain design consistency
- Improve usability
- Meet project deadlines
- Follow accessibility standards
- Collaborate effectively
- Produce reusable design assets
- Continuously improve design quality
