# Product Designer

> This document defines the responsibilities, authority, expectations, and performance standards of the Product Designer at MIANX.

The Product Designer is responsible for designing intuitive, accessible, and visually consistent digital products that solve customer problems and support business objectives. The Product Designer collaborates closely with Product Managers, Engineers, UX Researchers, QA Engineers, and Design Leadership throughout the entire product lifecycle.

The Product Designer reports directly to the Head of Design.

---

# Purpose

The purpose of the Product Designer role is to transform product requirements into user-centered experiences that are functional, engaging, accessible, and aligned with the MIANX Design System.

---

# Mission

The Product Designer exists to:

- Design exceptional user experiences
- Solve customer problems
- Improve usability
- Maintain design consistency
- Support product delivery
- Promote accessibility
- Collaborate across teams
- Continuously improve products

---

# Role Summary

The Product Designer contributes to:

- Product Design
- UX Design
- UI Design
- User Research
- Wireframing
- Interactive Prototyping
- Design Systems
- Accessibility
- Usability Testing
- Design Documentation

---

# Primary Responsibilities

The Product Designer is responsible for:

- Designing product interfaces
- Creating wireframes
- Building prototypes
- Producing high-fidelity UI designs
- Improving user journeys
- Conducting design iterations
- Supporting usability testing
- Maintaining design documentation
- Following design standards
- Collaborating with cross-functional teams

---

# Product Design Responsibilities

The Product Designer designs:

- Web Applications
- Mobile Applications
- SaaS Platforms
- Dashboards
- Admin Panels
- Customer Portals
- Enterprise Applications
- New Product Features

Every design should balance customer needs, technical feasibility, and business goals.

---

# User Experience Responsibilities

The Product Designer develops:

- User Flows
- Customer Journeys
- Wireframes
- Interactive Prototypes
- Information Architecture
- Task Flows
- Screen Layouts
- Interaction Patterns

UX decisions should minimize friction and maximize user satisfaction.

---

# User Interface Responsibilities

The Product Designer creates:

- High-Fidelity Mockups
- Responsive Layouts
- UI Components
- Icons
- Interface States
- Design Tokens
- Visual Hierarchy
- Component Variations

UI designs should remain consistent with the MIANX Design System.

---

# Design System Responsibilities

The Product Designer contributes to:

- Component Libraries
- Design Tokens
- Style Guides
- Reusable Components
- Documentation
- UI Standards
- Interaction Patterns
- Visual Consistency

Reusable components should reduce design and development effort.

---

# Research Responsibilities

The Product Designer participates in:

- User Interviews
- Usability Testing
- Prototype Validation
- Customer Feedback Analysis
- Competitor Analysis
- UX Workshops
- Design Reviews
- Product Discovery

Research findings should influence future design improvements.

---

# Collaboration

The Product Designer collaborates with:

- Senior Product Designers
- UX Architect
- UX Researchers
- UI Designers
- Product Managers
- Product Owners
- Software Engineers
- QA Engineers
- Marketing Teams
- Customer Success

Cross-functional collaboration ensures successful product delivery.

---

# Decision Authority

The Product Designer may approve:

- Wireframes
- UI Mockups
- Prototype Updates
- Minor UX Improvements
- Design Documentation
- Component Usage
- Visual Refinements
- Design Assets

Major design decisions require approval from the Senior Product Designer or Head of Design.

---

# Core Competencies

The Product Designer should demonstrate expertise in:

- Product Design
- User Experience Design
- User Interface Design
- Wireframing
- Prototyping
- Accessibility
- Visual Design
- Design Systems
- Design Thinking
- Communication

# Performance Expectations

The Product Designer is expected to:

- Deliver high-quality product designs
- Improve usability
- Maintain visual consistency
- Follow design standards
- Meet project deadlines
- Collaborate effectively
- Support product innovation
- Continuously improve design skills
