# Mobile Architect

> This document defines the responsibilities, authority, expectations, and performance standards of the Mobile Architect at MIANX.

The Mobile Architect is responsible for designing, governing, and evolving the mobile application architecture across all MIANX mobile platforms. This role establishes technical standards, ensures consistency across Android and iOS applications, and enables engineering teams to deliver secure, scalable, maintainable, and high-performance mobile experiences.

Unlike a Mobile Technical Lead, the Mobile Architect focuses on organization-wide architectural direction rather than feature implementation for individual applications.

---

# Purpose

The purpose of the Mobile Architect role is to establish a scalable and maintainable mobile architecture that enables rapid product development while delivering outstanding user experiences across Android and iOS.

---

The Mobile Architect exists to:

- Design enterprise mobile architecture
- Standardize mobile development
- Improve application performance
