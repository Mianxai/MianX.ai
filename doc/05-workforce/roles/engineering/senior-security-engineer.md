# Senior Security Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Senior Security Engineer at MIANX.

A Senior Security Engineer is a senior Individual Contributor (IC) responsible for designing, implementing, maintaining, and continuously improving the organization's technical security controls across applications, cloud infrastructure, platforms, networks, identities, endpoints, and production systems.

Senior Security Engineers provide technical leadership, mentor engineers, improve security maturity, reduce organizational risk, and ensure engineering teams adopt secure-by-design practices.

---

# Purpose

The purpose of the Senior Security Engineer role is to build secure engineering systems by implementing enterprise security controls, automating security operations, and enabling engineering teams to deliver software safely.

---

# Mission

The Senior Security Engineer exists to:

- Protect enterprise systems
- Reduce security risks
- Improve security automation
- Secure cloud infrastructure
- Strengthen application security
- Mentor security engineers
- Improve incident readiness
- Enable secure software delivery
