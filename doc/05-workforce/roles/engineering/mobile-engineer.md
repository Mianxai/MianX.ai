# Mobile Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Mobile Engineer at MIANX.

A Mobile Engineer is responsible for developing, maintaining, testing, and improving mobile applications across Android, iOS, and approved cross-platform technologies. Mobile Engineers transform product requirements into reliable, secure, high-performance mobile applications that deliver exceptional user experiences.

The role collaborates closely with designers, backend engineers, QA engineers, DevOps engineers, and product managers to ensure successful delivery of mobile products.

---

# Purpose

The purpose of the Mobile Engineer role is to build reliable, maintainable, secure, and scalable mobile applications that support MIANX products and business objectives.

---

# Mission

The Mobile Engineer exists to:

- Build modern mobile applications
- Deliver excellent user experiences
- Improve application performance
- Maintain platform quality
- Develop reusable components
- Support product delivery
- Improve software quality
- Continuously enhance engineering practices
