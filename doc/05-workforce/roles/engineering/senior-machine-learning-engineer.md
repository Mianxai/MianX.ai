# Senior Machine Learning Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Senior Machine Learning Engineer at MIANX.

A Senior Machine Learning Engineer is a senior Individual Contributor (IC) responsible for designing, developing, deploying, optimizing, and maintaining production-grade machine learning systems that enable predictive analytics, intelligent automation, recommendation engines, computer vision, natural language processing, forecasting, and AI-powered business capabilities.

Senior Machine Learning Engineers provide technical leadership, mentor ML engineers, improve engineering standards, and ensure machine learning systems are scalable, reproducible, secure, observable, and aligned with business objectives.

---

# Purpose

The purpose of the Senior Machine Learning Engineer role is to build reliable, production-ready machine learning solutions that create measurable business value through predictive intelligence and advanced analytics.

---

# Mission

The Senior Machine Learning Engineer exists to:

- Build production ML systems
- Improve model performance
- Optimize ML infrastructure
- Mentor engineering teams
- Advance MLOps maturity
- Improve model reliability
- Support responsible AI
- Deliver business impact
