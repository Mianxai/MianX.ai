# Software Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Software Engineer at MIANX.

A Software Engineer is responsible for designing, developing, testing, deploying, maintaining, and improving software systems that power MIANX products and internal platforms.

Software Engineers are expected to deliver high-quality solutions while continuously improving their technical skills and contributing to engineering excellence.

---

# Purpose

The purpose of the Software Engineer role is to build reliable, secure, scalable, and maintainable software that delivers value to customers and supports MIANX's long-term vision.

---

# Mission

The Software Engineer exists to:

- Build quality software
- Deliver customer value
- Solve engineering problems
- Improve code quality
- Learn continuously
- Collaborate effectively
- Support innovation
- Contribute to engineering excellence

---

# Role Summary

Software Engineers work as core members of engineering teams.

They are responsible for:

- Building software features
- Fixing defects
- Writing tests
- Participating in code reviews
- Maintaining documentation
- Supporting deployments
- Improving engineering quality

The role requires both technical capability and strong collaboration.

---

# Primary Responsibilities

The Software Engineer is responsible for:

- Software Development
- Bug Fixing
- Code Reviews
- Unit Testing
- Integration Testing
- Documentation
- Deployment Support
- Performance Improvements
- Collaboration
- Continuous Learning

---

# Software Development Responsibilities

The Software Engineer develops:

- Backend Services
- Frontend Features
- REST APIs
- Internal Tools
- Shared Components
- Automation Scripts
- Platform Integrations
- AI-enabled Features *(where applicable)*

Every implementation should prioritize readability, maintainability, and performance.

---

# Technical Responsibilities

The Software Engineer contributes to:

- Feature Design
- Database Queries
- API Development
- System Integration
- Performance Improvements
- Error Handling
- Logging
- Monitoring Support

Engineers should understand the systems they build and the business problems they solve.

---

# Code Quality Responsibilities

The Software Engineer ensures:

- Clean code
- Consistent style
- Automated tests
- Secure coding
- Peer-reviewed changes
- Meaningful documentation
- Reliable deployments
- Minimal defects

Quality is everyone's responsibility.

---

# Testing Responsibilities

The Software Engineer is responsible for:

- Unit Tests
- Integration Tests
- Regression Testing
- Manual Verification
- Bug Reproduction
- Test Maintenance

Testing should be integrated into everyday development rather than treated as a final step.

---

# Collaboration Responsibilities

The Software Engineer collaborates with:

- Engineering Manager
- Technical Lead
- Senior Software Engineers
- Product Managers
- UX Designers
- QA Engineers
- DevOps Engineers
- Platform Engineers
- Security Engineers

Successful products are built through collaboration.

---

# Decision Authority

The Software Engineer has authority over:

- Implementation details
- Code improvements
- Refactoring suggestions
- Test implementation
- Development tooling recommendations
- Documentation improvements

Architectural decisions require Technical Lead or Senior Engineer review.

---

# Engineering Principles

The Software Engineer follows:

- Simplicity
- Reliability
- Security
- Maintainability
- Performance
- Documentation
- Automation
- Ownership
- Collaboration
- Continuous Improvement

Every code change should improve the system.

---

# Core Competencies

The Software Engineer should demonstrate knowledge of:

- Programming Languages
- Object-Oriented Programming
- Data Structures
- Algorithms
- REST APIs
- Databases
- Git
- Testing
- Debugging
- Software Design Fundamentals

---

# Performance Expectations

The Software Engineer is expected to:

- Deliver assigned work on time
- Write maintainable code
- Improve software quality
- Participate in code reviews
- Learn continuously
- Collaborate effectively
- Support engineering standards
- Contribute to team success
