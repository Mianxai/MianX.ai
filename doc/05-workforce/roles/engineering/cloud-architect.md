# Cloud Architect

> This document defines the responsibilities, authority, expectations, and performance standards of the Cloud Architect at MIANX.

The Cloud Architect is responsible for designing, governing, and evolving the organization's cloud architecture, multi-cloud strategy, cloud security, networking, scalability, disaster recovery, cost optimization, and cloud governance.

Unlike a DevOps Architect who focuses on software delivery pipelines and operational automation, the Cloud Architect focuses on enterprise cloud infrastructure, cloud-native architecture, networking, identity, resilience, and long-term cloud strategy.

---

# Purpose

The purpose of the Cloud Architect role is to establish secure, scalable, resilient, and cost-efficient cloud platforms that support enterprise applications and long-term organizational growth.

---

# Mission

The Cloud Architect exists to:

- Design enterprise cloud architecture
- Build cloud-native platforms
- Improve cloud reliability
- Strengthen cloud security
- Optimize cloud costs
- Standardize cloud infrastructure
- Support engineering teams
- Enable organizational scalability

# Cloud Architecture Responsibilities

The Cloud Architect designs:

- AWS Architectures
- Microsoft Azure Architectures
- Google Cloud Architectures
- Hybrid Cloud Platforms
- Multi-cloud Platforms
- Serverless Architectures
- Cloud-native Applications
- Edge Computing Solutions

Cloud architectures should be scalable, secure, resilient, and maintainable.

---

# Infrastructure Responsibilities

The Cloud Architect governs:

- Compute Services
- Virtual Networks
- Storage Services
- Load Balancers
- Kubernetes Platforms
- Managed Databases
- Identity Services
- Shared Cloud Infrastructure

Infrastructure should support enterprise availability and operational excellence.

---

# Networking Responsibilities

The Cloud Architect designs:

- Virtual Private Clouds (VPCs)
- Network Segmentation
- VPN Connectivity
- Direct Connectivity
- DNS Architecture
- Traffic Routing
- Network Security
- Global Networking

Networking should provide secure, low-latency, and resilient communication.

---

# Security Responsibilities

The Cloud Architect establishes standards for:

- Identity & Access Management (IAM)
- Zero Trust Architecture
- Secrets Management
- Key Management
- Encryption
- Compliance Controls
- Cloud Security Monitoring
- Security Automation

Security should be integrated into every cloud architecture decision.

---

# Disaster Recovery Responsibilities

The Cloud Architect designs:

- Backup Strategies
- Multi-region Deployments
- Failover Architecture
- High Availability
- Recovery Procedures
- Disaster Recovery Testing
- Business Continuity
- Data Replication

Recovery capabilities should meet defined Recovery Time Objectives (RTO) and Recovery Point Objectives (RPO).

---

# Cost Optimization Responsibilities

The Cloud Architect develops strategies for:

- Resource Optimization
- Reserved Capacity Planning
- Auto Scaling
- Storage Optimization
- Compute Optimization
- Cost Monitoring
- Budget Governance
- Capacity Planning

Cloud spending should align with business objectives while maximizing efficiency.

- Cloud Standards
- Resource Policies
- Naming Conventions

- Identity Policies
- Compliance Frameworks
