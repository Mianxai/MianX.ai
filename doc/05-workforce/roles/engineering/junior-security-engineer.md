# Junior Security Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Junior Security Engineer at MIANX.

A Junior Security Engineer is an entry-level engineering professional responsible for assisting in protecting applications, infrastructure, cloud environments, production systems, and organizational assets while learning modern cybersecurity and secure engineering practices.

The role focuses on developing practical skills in cloud security, infrastructure security, application security, vulnerability management, identity management, security monitoring, incident response, and security automation under the guidance of senior security engineers.

---

# Purpose

The purpose of the Junior Security Engineer role is to develop skilled security engineers through structured mentorship, hands-on engineering experience, and continuous learning while supporting the organization's cybersecurity initiatives.

---

# Mission

The Junior Security Engineer exists to:

- Learn cybersecurity engineering
- Support enterprise security
- Reduce security risks
- Assist security operations
- Improve monitoring
- Support secure software delivery
- Follow security standards
- Prepare for the Security Engineer role

---

# Role Summary

Junior Security Engineers contribute to day-to-day security operations while working under the supervision of Security Engineers and Senior Security Engineers.

Typical work includes:

- Security monitoring

- Incident support

- Continuous learning
