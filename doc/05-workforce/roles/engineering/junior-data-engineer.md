# Junior Data Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Junior Data Engineer at MIANX.

A Junior Data Engineer is an entry-level engineering professional responsible for assisting in the development, maintenance, and operation of enterprise data pipelines, data warehouses, data integrations, and analytics platforms while learning modern data engineering practices.

The role focuses on developing practical experience in SQL, Python, ETL/ELT development, cloud data platforms, data quality, automation, monitoring, and enterprise data governance under the guidance of senior data engineers.

---

# Purpose

The purpose of the Junior Data Engineer role is to develop skilled data engineers through structured mentorship, hands-on engineering experience, and continuous learning while supporting reliable enterprise data platforms.

---

# Mission

The Junior Data Engineer exists to:

- Learn data engineering
- Support enterprise data platforms
- Improve data quality
- Assist analytics initiatives
- Build reliable pipelines
- Automate routine processes
- Follow engineering standards
- Prepare for the Data Engineer role
