# Senior Data Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Senior Data Engineer at MIANX.

A Senior Data Engineer is a senior Individual Contributor (IC) responsible for designing, building, optimizing, and maintaining scalable data platforms, pipelines, and processing systems that support business operations, analytics, reporting, artificial intelligence, and machine learning initiatives.

Senior Data Engineers provide technical leadership, mentor engineering teams, improve platform reliability, and ensure enterprise data is accurate, secure, available, and scalable.

---

# Purpose

The purpose of the Senior Data Engineer role is to develop reliable and scalable data infrastructure that enables trusted business intelligence, advanced analytics, and AI-driven decision making.

---

# Mission

The Senior Data Engineer exists to:

- Build scalable data platforms
- Improve data reliability
- Enable analytics and AI
- Optimize data pipelines
- Improve data quality
- Automate data operations
- Mentor engineering teams
- Strengthen data governance

---

# Data Pipeline Responsibilities

The Senior Data Engineer designs and maintains:

- ETL Pipelines
- ELT Pipelines
- Batch Processing
- Streaming Pipelines
- Data Synchronization
- Data Transformation
- Data Validation
- Pipeline Monitoring

Pipelines should be reliable, observable, scalable, and fault tolerant.

- Enterprise Data Warehouses

Warehouse solutions should provide accurate and efficient analytical capabilities.

# Streaming Data Responsibilities

The Senior Data Engineer builds:

- Real-Time Processing
- Message Queue Integrations

- Event Producers
- Stream Validation
- Event Monitoring
- Recovery Procedures

Streaming platforms should support low-latency, high-throughput processing.
