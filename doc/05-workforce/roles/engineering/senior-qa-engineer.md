# Senior QA Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Senior QA Engineer at MIANX.

A Senior QA Engineer is a senior Individual Contributor (IC) responsible for leading software quality initiatives, designing and maintaining automated testing solutions, improving testing processes, mentoring QA engineers, and ensuring high-quality software releases across all engineering teams.

Senior QA Engineers drive quality engineering practices by integrating testing throughout the Software Development Life Cycle (SDLC) and promoting automation-first testing strategies.

---

# Purpose

The purpose of the Senior QA Engineer role is to ensure software quality through comprehensive testing, automation, continuous improvement, and technical leadership while enabling rapid and reliable software delivery.

---

# Mission

The Senior QA Engineer exists to:

- Improve software quality
- Reduce production defects
- Increase test automation
- Strengthen release confidence
- Improve engineering efficiency
- Mentor QA engineers
- Enhance testing practices
- Drive continuous quality improvement
