# Frontend Architect

> This document defines the responsibilities, authority, expectations, and performance standards of the Frontend Architect at MIANX.

The Frontend Architect is responsible for defining, governing, and evolving the frontend architecture of MIANX products. This role establishes standards for user interfaces, frontend infrastructure, design systems, accessibility, performance, security, and developer experience across all frontend applications.

Unlike a Frontend Technical Lead, the Frontend Architect focuses on long-term architectural direction across multiple engineering teams rather than day-to-day feature delivery.

---

# Purpose

The purpose of the Frontend Architect role is to establish scalable, maintainable, accessible, secure, and high-performance frontend architectures that enable rapid product development and exceptional user experiences.

---

# Mission

The Frontend Architect exists to:

- Design scalable frontend architectures
- Establish engineering standards
- Improve developer experience
- Enhance application performance
- Ensure accessibility compliance
- Promote reusable UI systems
- Support engineering teams
- Drive frontend innovation

- Multi-Page Applications (MPA)

# Performance Responsibilities

The Frontend Architect drives improvements in:

- Initial Page Load
- Largest Contentful Paint (LCP)
- First Input Delay (FID)
- Interaction to Next Paint (INP)
- Bundle Size

- Rendering Performance
