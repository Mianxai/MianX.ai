# Machine Learning Architect

> This document defines the responsibilities, authority, expectations, and performance standards of the Machine Learning Architect at MIANX.

The Machine Learning Architect is responsible for designing, governing, and evolving the organization's machine learning architecture, ensuring ML systems are scalable, secure, reliable, explainable, observable, and aligned with business objectives.

Unlike Machine Learning Engineers who develop and deploy ML models, the Machine Learning Architect defines enterprise ML architecture, feature engineering standards, model lifecycle strategy, MLOps architecture, inference infrastructure, governance policies, and long-term machine learning strategy.

---

# Purpose

The purpose of the Machine Learning Architect role is to establish a scalable, production-ready machine learning ecosystem that enables predictive intelligence, intelligent automation, and data-driven innovation across the organization.

---

The Machine Learning Architect exists to:

- Build enterprise ML architecture
