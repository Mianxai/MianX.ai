# Backend Architect

> This document defines the responsibilities, authority, expectations, and performance standards of the Backend Architect at MIANX.

The Backend Architect is responsible for designing, governing, and evolving backend systems that power MIANX products and platforms. This role establishes architectural standards, ensures scalability, reliability, and security, and guides engineering teams in implementing enterprise-grade backend solutions.

Unlike a Technical Lead, the Backend Architect focuses on **system architecture across multiple teams rather than feature delivery for a single team**.

---

# Purpose

The purpose of the Backend Architect role is to establish a scalable, resilient, secure, and maintainable backend architecture capable of supporting long-term business growth.

---

# Mission

The Backend Architect exists to:

- Design scalable backend systems
- Define architectural standards
- Improve system reliability
- Enable engineering productivity
- Reduce technical complexity
- Improve system performance
- Guide backend engineering teams
- Support business scalability
