# Senior Software Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Senior Software Engineer at MIANX.

A Senior Software Engineer is a highly experienced Individual Contributor (IC) responsible for designing, building, reviewing, and maintaining high-quality software while mentoring engineers and contributing to the long-term technical success of the organization.

Senior Software Engineers lead through technical expertise, ownership, and execution.

---

# Purpose

The purpose of the Senior Software Engineer role is to deliver reliable, scalable, secure, and maintainable software while improving engineering quality across teams.

---

# Mission

The Senior Software Engineer exists to:

- Build high-quality software
- Solve complex engineering problems
- Improve engineering practices
- Mentor software engineers
- Reduce technical debt
- Improve software reliability
- Drive engineering excellence
- Deliver customer value

---

# Role Summary

Senior Software Engineers work on complex features and systems that require deep technical knowledge.

They are expected to:

- Lead implementation efforts
- Review architecture
- Improve code quality
- Mentor engineers
- Resolve production issues
- Participate in technical planning
- Improve engineering standards

They influence engineering through technical expertise rather than organizational authority.

---

# Primary Responsibilities

The Senior Software Engineer is responsible for:

- Software Development
- System Design
- Code Reviews
- Technical Mentorship
- Feature Delivery
- Performance Optimization
- Debugging
- Technical Documentation
- Engineering Collaboration
- Continuous Improvement

---

# Software Development Responsibilities

The Senior Software Engineer develops:

- Backend Services
- APIs
- Frontend Features
- Shared Libraries
- Internal Tools
- Automation Scripts
- Platform Components
- AI-enabled Features *(where applicable)*

Solutions should prioritize scalability, maintainability, and reliability.

---

# Technical Responsibilities

The Senior Software Engineer contributes to:

- System Design
- Architecture Discussions
- Database Design
- API Design
- Performance Optimization
- Security Improvements
- Infrastructure Awareness
- Scalability Planning

Technical decisions should support long-term product evolution.

---

# Code Quality Responsibilities

The Senior Software Engineer ensures:

- Clean code
- Consistent coding standards
- Automated testing
- Secure development
- Peer code reviews
- Maintainable architecture
- Reliable deployments
- Minimal technical debt

Code should always be easier to maintain after each change.

---

# Mentorship Responsibilities

The Senior Software Engineer mentors:

- Software Engineers
- Associate Software Engineers
- Junior Software Engineers
- Engineering Interns

Mentorship includes:

- Pair programming
- Technical coaching
- Code reviews
- Design discussions
- Knowledge sharing
- Career guidance

Mentorship is an expected responsibility, not an optional activity.

---

# Collaboration Responsibilities

The Senior Software Engineer works closely with:

- Engineering Managers
- Technical Leads
- Staff Engineers
- Principal Engineers
- Product Managers
- Designers
- QA Engineers
- DevOps Engineers
- Platform Engineers
- Security Engineers

Strong collaboration leads to better software outcomes.

---

# Decision Authority

The Senior Software Engineer has authority over:

- Implementation approaches
- Code review approvals
- Technical recommendations
- Refactoring decisions
- Testing strategies
- Development tooling recommendations
- Performance improvements
- Feature implementation details

Major architectural decisions should be reviewed with the Technical Lead or Staff Engineer.

---

# Engineering Principles

The Senior Software Engineer promotes:

- Simplicity
- Reliability
- Security
- Scalability
- Performance
- Automation
- Documentation
- Ownership
- Collaboration
- Continuous Learning

Engineering quality should never be sacrificed for short-term speed.

The Senior Software Engineer should demonstrate expertise in:

- REST & API Design
- Databases
- Cloud Fundamentals
- Git Workflows
- Testing Strategies

- Technical Communication

# Performance Expectations

The Senior Software Engineer is expected to:

- Deliver reliable software
- Reduce production defects
- Improve engineering quality
- Mentor engineers
- Improve development velocity
- Contribute to architectural improvements
- Strengthen documentation
- Promote engineering best practices
