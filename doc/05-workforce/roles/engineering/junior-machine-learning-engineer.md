# Junior Machine Learning Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Junior Machine Learning Engineer at MIANX.

A Junior Machine Learning Engineer is an entry-level engineering professional responsible for assisting in the development, testing, deployment, monitoring, and maintenance of machine learning models and supporting infrastructure while learning modern machine learning engineering practices.

The role focuses on developing practical experience in Python, machine learning frameworks, feature engineering, data preprocessing, model evaluation, MLOps, cloud platforms, and responsible AI under the guidance of senior engineering staff.

---

# Purpose

The purpose of the Junior Machine Learning Engineer role is to develop skilled machine learning engineers through structured mentorship, hands-on engineering experience, and continuous learning while supporting reliable enterprise machine learning systems.

---

# Mission

The Junior Machine Learning Engineer exists to:

- Learn machine learning engineering
- Build ML solutions
- Support production ML systems
- Improve model quality
- Assist MLOps initiatives
- Follow engineering standards
- Maintain technical documentation
- Prepare for the Machine Learning Engineer role
