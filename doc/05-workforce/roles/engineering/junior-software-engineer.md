# Junior Software Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Junior Software Engineer at MIANX.

A Junior Software Engineer is an early-career engineer responsible for learning professional software development while contributing to production systems under the guidance of experienced engineers.

The role emphasizes continuous learning, engineering discipline, and building a strong technical foundation.

---

# Purpose

The purpose of this role is to develop competent software engineers by providing hands-on experience, structured mentorship, and exposure to real-world software engineering practices.

---

# Mission

The Junior Software Engineer exists to:

- Learn professional software engineering
- Build reliable software
- Improve programming skills
- Follow engineering standards
- Deliver assigned tasks
- Collaborate with teammates
- Develop problem-solving abilities
- Prepare for greater engineering responsibilities

---

# Role Summary

Junior Software Engineers primarily work on well-defined tasks while receiving guidance from senior team members.

Typical responsibilities include:

- Implementing small features
- Fixing bugs
- Writing tests
- Updating documentation
- Participating in code reviews
- Learning development workflows
- Supporting software maintenance

---

# Primary Responsibilities

The Junior Software Engineer is responsible for:

- Software Development
- Bug Fixing
- Unit Testing
- Documentation
- Learning
- Debugging
- Team Collaboration
- Development Process Compliance
- Code Reviews
- Continuous Improvement

---

# Software Development Responsibilities

The Junior Software Engineer develops:

- Small product features
- UI components
- Backend endpoints
- API integrations
- Database queries
- Internal tools
- Utility functions
- Bug fixes

Work should prioritize correctness, readability, and maintainability.

---

# Technical Responsibilities

The Junior Software Engineer contributes to:

- Feature implementation
- Bug investigation
- Unit testing
- Debugging
- Logging improvements
- Monitoring support
- Documentation updates

Complex technical decisions should always be reviewed with experienced engineers.

---

# Learning Responsibilities

The Junior Software Engineer is expected to continuously learn:

- Programming languages
- Frameworks
- Company architecture
- Development tools
- Git workflows
- Testing strategies
- Secure coding
- Engineering best practices

Learning is considered part of normal work responsibilities.

---

# Code Quality Responsibilities

The Junior Software Engineer ensures:

- Readable code
- Coding standards compliance
- Proper formatting
- Automated tests
- Documentation updates
- Secure development practices
- Reliable implementations

Quality habits should be developed from the beginning of an engineering career.

---

# Testing Responsibilities

The Junior Software Engineer participates in:

- Unit Testing
- Integration Testing
- Manual Testing
- Regression Verification
- Bug Reproduction
- Test Maintenance

Every code change should be appropriately tested before submission.

---

# Collaboration Responsibilities

The Junior Software Engineer collaborates with:

- Engineering Manager
- Technical Lead
- Senior Software Engineers
- Software Engineers
- Associate Software Engineers
- QA Engineers
- Product Managers
- DevOps Engineers

Professional communication and willingness to learn are essential.

---

# Decision Authority

The Junior Software Engineer may independently decide:

- Implementation details for assigned tasks
- Small refactoring improvements
- Unit test implementation
- Documentation updates

Architecture, infrastructure, and major design decisions require review by senior engineers.

---

# Engineering Principles

The Junior Software Engineer follows:

- Simplicity
- Reliability
- Security
- Documentation
- Collaboration
- Learning
- Ownership
- Professionalism
- Continuous Improvement
- Respect for Engineering Standards

---

# Core Competencies

The Junior Software Engineer should demonstrate knowledge of:

- Programming Fundamentals
- Object-Oriented Programming
- Data Structures
- Algorithms
- Version Control (Git)
- SQL Basics
- REST APIs
- Debugging
- Testing Fundamentals
- Software Development Lifecycle

---

# Performance Expectations

The Junior Software Engineer is expected to:

- Complete assigned tasks on time
- Follow engineering standards
- Learn continuously
- Write clean code
- Improve technical skills
- Participate in code reviews
- Ask thoughtful questions
- Take ownership of assigned work
