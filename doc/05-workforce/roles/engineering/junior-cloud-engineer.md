# Junior Cloud Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Junior Cloud Engineer at MIANX.

A Junior Cloud Engineer is an entry-level engineering professional responsible for assisting in the deployment, maintenance, monitoring, automation, and support of enterprise cloud infrastructure while learning modern cloud engineering practices.

The role focuses on developing expertise in cloud platforms, Linux administration, Infrastructure as Code (IaC), networking, Kubernetes, cloud security, automation, and operational excellence under the guidance of senior engineers.

---

# Purpose

The purpose of the Junior Cloud Engineer role is to develop capable cloud engineers through structured mentorship, practical experience, and continuous technical learning while supporting enterprise cloud operations.

---

# Mission

The Junior Cloud Engineer exists to:

- Learn cloud engineering
- Support cloud infrastructure
- Improve operational reliability
- Assist with automation
- Maintain cloud services
- Follow engineering standards
- Collaborate across teams
- Prepare for the Cloud Engineer role

---

# Role Summary

Junior Cloud Engineers contribute to day-to-day cloud operations while working under the supervision of Cloud Engineers and Senior Cloud Engineers.

Typical work includes:

- Cloud infrastructure support
- Resource provisioning

- Infrastructure automation
- Documentation
- Incident support
- Operational maintenance
- Continuous learning
