# Senior Mobile Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Senior Mobile Engineer at MIANX.

A Senior Mobile Engineer is a senior Individual Contributor (IC) responsible for designing, developing, optimizing, and maintaining enterprise-grade mobile applications across Android, iOS, and cross-platform technologies.

Senior Mobile Engineers provide technical leadership, mentor engineers, improve engineering standards, and ensure mobile applications remain secure, scalable, maintainable, and performant.

---

# Purpose

The purpose of the Senior Mobile Engineer role is to build reliable, high-quality mobile applications while improving engineering excellence, mentoring engineers, and supporting the long-term mobile architecture of MIANX.

---

# Mission

The Senior Mobile Engineer exists to:

- Build scalable mobile applications
- Deliver exceptional user experiences
- Improve application performance
- Maintain platform quality
- Mentor mobile engineers
- Improve engineering practices
- Support architectural evolution
- Deliver business value

The Senior Mobile Engineer designs and implements:

- Offline Databases

The Senior Mobile Engineer optimizes:
