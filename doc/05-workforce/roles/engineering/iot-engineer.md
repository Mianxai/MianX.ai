# IoT Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the IoT Engineer at MIANX.

An IoT Engineer is responsible for designing, developing, testing, deploying, maintaining, and supporting Internet of Things (IoT) platforms, connected devices, edge applications, telemetry pipelines, cloud integrations, and device lifecycle management systems.

IoT Engineers collaborate with Embedded Engineers, Cloud Engineers, Platform Engineers, Security Engineers, Data Engineers, AI Engineers, DevOps Engineers, QA Engineers, and Product Managers to build secure, scalable, and production-ready connected solutions.

---

# Purpose

The purpose of the IoT Engineer role is to build secure, reliable, and scalable IoT systems that connect physical devices with enterprise platforms to enable monitoring, automation, analytics, and intelligent decision-making.

---

# Mission

The IoT Engineer exists to:

- Build IoT platforms
- Connect intelligent devices
- Develop edge applications
- Maintain telemetry systems
- Improve platform reliability
- Strengthen IoT security
- Deliver high-quality engineering solutions
- Continuously improve connected systems
