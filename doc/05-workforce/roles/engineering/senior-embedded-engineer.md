# Senior Embedded Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Senior Embedded Engineer at MIANX.

A Senior Embedded Engineer is a senior Individual Contributor (IC) responsible for designing, developing, testing, optimizing, deploying, and maintaining embedded software, firmware, device drivers, and real-time systems for enterprise hardware products.

Senior Embedded Engineers provide technical leadership for embedded engineering initiatives while ensuring firmware quality, system reliability, hardware compatibility, security, and production readiness.

---

# Purpose

The purpose of the Senior Embedded Engineer role is to build reliable, secure, and scalable embedded software platforms that power intelligent devices, edge systems, industrial products, and connected hardware solutions.

---

# Mission

The Senior Embedded Engineer exists to:

- Develop embedded platforms
- Build reliable firmware
- Improve hardware integration
- Optimize system performance
- Strengthen embedded security
- Mentor engineering teams
- Deliver production-quality software
- Drive continuous engineering improvement

# Firmware Development Responsibilities

The Senior Embedded Engineer develops:

- Firmware Platforms
- Bootloaders
- Hardware Abstraction Layers (HAL)
- Device Drivers
- Embedded Libraries
- Board Support Packages (BSP)
- Firmware Update Systems
- Diagnostic Software

Firmware should remain modular, maintainable, secure, and production-ready.

---

# Embedded Software Responsibilities

The Senior Embedded Engineer develops:

- Embedded Applications
- Embedded Linux Software
- Bare-Metal Systems
- Middleware
- Sensor Interfaces
- Peripheral Controllers
- Industrial Control Logic
- Edge Computing Services

Solutions should follow organizational architecture and engineering standards.

---

# RTOS Responsibilities

The Senior Embedded Engineer designs and implements:

- Task Scheduling
- Interrupt Management
- Thread Synchronization
- Resource Management
- Real-Time Communication
- Memory Allocation
- Timing Optimization
- Deterministic Execution

Real-time systems should consistently satisfy performance and timing requirements.

---

# Hardware Integration Responsibilities

The Senior Embedded Engineer integrates software with:

- ARM Processors
- Microcontrollers
- Sensors
- Actuators
- Communication Modules
- Displays
- Industrial Interfaces
- Peripheral Devices

Hardware integration should ensure stable and reliable operation across supported platforms.

---

# Device Driver Responsibilities

The Senior Embedded Engineer develops and maintains:

- GPIO Drivers
- UART Drivers
- SPI Drivers
- I2C Drivers
- CAN Drivers
- Ethernet Drivers
- USB Drivers
- Custom Peripheral Drivers

Drivers should provide stable interfaces with optimized performance.

The Senior Embedded Engineer optimizes:

- CPU Utilization
- Memory Usage

- Power Consumption
- Boot Time

Optimization should improve efficiency while maintaining stability and reliability.

Security controls should protect firmware, devices, and connected systems.
