# Senior DevOps Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Senior DevOps Engineer at MIANX.

A Senior DevOps Engineer is a senior Individual Contributor (IC) responsible for designing, implementing, automating, securing, and maintaining enterprise infrastructure, cloud platforms, CI/CD pipelines, observability systems, and deployment automation.

Senior DevOps Engineers provide technical leadership, mentor engineers, improve platform reliability, and ensure infrastructure supports secure, scalable, and highly available software delivery.

---

# Purpose

The purpose of the Senior DevOps Engineer role is to build reliable, automated, and scalable infrastructure while improving operational excellence, mentoring engineers, and supporting the organization's DevOps architecture.

---

# Mission

The Senior DevOps Engineer exists to:

- Build reliable infrastructure
- Automate engineering workflows
- Improve deployment reliability
- Strengthen platform security
- Optimize cloud resources
- Mentor DevOps engineers
- Improve operational excellence
- Deliver business value

---

# Role Summary

Senior DevOps Engineers lead implementation of complex infrastructure and platform initiatives.

- Cloud Infrastructure

# Infrastructure Responsibilities

The Senior DevOps Engineer designs and maintains:

- Cloud Networks
- Storage Systems
- Load Balancers
- Compute Resources
- DNS Infrastructure
- Platform Services

Infrastructure should remain resilient, scalable, and highly available.

# Cloud Engineering Responsibilities

The Senior DevOps Engineer manages:

- AWS Services
- Microsoft Azure
- Google Cloud Platform
- Hybrid Cloud Deployments
- Cloud Networking
- Identity & Access Management
- Cloud Storage

Cloud environments should follow organizational governance and security standards.

# CI/CD Responsibilities

The Senior DevOps Engineer builds and maintains:

- Build Pipelines
- Deployment Pipelines
- GitOps Workflows
- Automated Testing Pipelines
- Release Automation
- Rollback Automation
- Artifact Repositories
- Deployment Strategies

CI/CD pipelines should enable fast, reliable, and repeatable software delivery.

# Infrastructure as Code Responsibilities

The Senior DevOps Engineer develops infrastructure using:

- Terraform
- OpenTofu
- Ansible
- Helm
- Kubernetes Manifests
- Pulumi *(where applicable)*
- CloudFormation *(where applicable)*

Infrastructure should be fully version-controlled and reproducible.

# Kubernetes Responsibilities

The Senior DevOps Engineer administers:

- Kubernetes Clusters
- Namespaces
- Ingress Controllers
- Operators
- Service Mesh *(where applicable)*
- Persistent Storage
- Cluster Networking
- Cluster Security

Clusters should support production-grade reliability and scalability.

- Alerting
