# Data Architect

> This document defines the responsibilities, authority, expectations, and performance standards of the Data Architect at MIANX.

The Data Architect is responsible for designing, governing, and evolving the organization's enterprise data architecture, ensuring that data is accurate, secure, scalable, governed, and accessible across operational, analytical, and AI systems.

Unlike Data Engineers who build data pipelines, the Data Architect defines enterprise-wide data models, storage strategies, governance standards, platform architecture, metadata management, and long-term data strategy.

---

# Purpose

The purpose of the Data Architect role is to establish a scalable, secure, and reliable data ecosystem that enables business intelligence, operational excellence, machine learning, and informed decision-making.

---

# Mission

The Data Architect exists to:

- Build enterprise data architecture
- Enable trusted data
- Improve data quality
- Establish governance standards
- Design scalable platforms
- Support analytics and AI
- Reduce data complexity
- Enable business growth

# Data Architecture Responsibilities

The Data Architect designs:

- Enterprise Data Models
- Canonical Data Models
- Domain Data Models
- Data Platform Architecture
- Warehouse Architecture
- Lakehouse Architecture
- Data Pipelines Architecture
- Enterprise Integration Models

Architecture should support long-term scalability, reliability, and interoperability.

---

# Data Modeling Responsibilities

The Data Architect defines standards for:

- Conceptual Models
- Logical Models
- Physical Models
- Dimensional Models
- Star Schemas
- Snowflake Schemas
- Normalization
- Denormalization

Data models should balance performance, consistency, and maintainability.

---

# Data Platform Responsibilities

The Data Architect establishes standards for:

- Data Warehouses
- Data Lakes
- Lakehouse Platforms
- Streaming Platforms
- ETL/ELT Pipelines
- Data Catalogs
- Metadata Platforms
- Data Integration Services

Platforms should support both operational and analytical workloads.

# Data Governance Responsibilities

The Data Architect governs:

- Data Ownership
- Data Classification
- Data Lineage
- Metadata Standards
- Data Retention
- Data Lifecycle
- Governance Policies
- Stewardship Processes

Governance should ensure trusted, compliant, and well-managed enterprise data.

# Data Security Responsibilities

The Data Architect defines:

- Data Encryption Standards
- Access Control Models
- Data Masking
- Data Tokenization
- Privacy Controls
- Regulatory Compliance
- Audit Requirements
- Backup Strategies

Data protection should comply with organizational and regulatory requirements.

---

# Data Quality Responsibilities

The Data Architect establishes:

- Data Validation Rules
- Data Quality Standards
- Duplicate Detection
- Data Integrity Checks
- Data Cleansing Processes
- Quality Monitoring
- Data Profiling
- Quality Metrics

Data quality should be continuously measured and improved.

- Enterprise data architecture

- Metadata standards
