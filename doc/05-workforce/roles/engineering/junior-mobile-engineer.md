# Junior Mobile Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Junior Mobile Engineer at MIANX.

A Junior Mobile Engineer is an entry-level software engineer responsible for developing, testing, maintaining, and improving mobile applications while learning professional mobile engineering practices under the guidance of experienced engineers.

The role focuses on building a strong foundation in Android, iOS, cross-platform development, mobile architecture, application security, performance optimization, and software engineering best practices.

---

# Purpose

The purpose of the Junior Mobile Engineer role is to develop skilled mobile engineers through practical experience, structured mentorship, and exposure to production-grade mobile systems.

---

# Mission

The Junior Mobile Engineer exists to:

- Learn mobile engineering
- Build reliable mobile applications
- Improve application quality
- Develop reusable components
- Follow engineering standards
- Deliver assigned tasks
- Collaborate with engineering teams
- Prepare for the Mobile Engineer role
