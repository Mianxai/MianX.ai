# Senior Backend Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Senior Backend Engineer at MIANX.

A Senior Backend Engineer is a senior Individual Contributor (IC) responsible for designing, developing, optimizing, and maintaining backend services that power MIANX products and internal platforms.

Senior Backend Engineers provide technical leadership within backend teams, mentor engineers, and ensure backend systems remain scalable, secure, reliable, and maintainable.

---

# Purpose

The purpose of the Senior Backend Engineer role is to build enterprise-grade backend systems while improving engineering quality, mentoring engineers, and supporting the long-term technical vision of MIANX.

---

# Mission

The Senior Backend Engineer exists to:

- Build scalable backend systems
- Design reliable APIs
- Improve system performance
- Reduce technical debt
- Mentor backend engineers
- Improve engineering standards
- Support architecture evolution
- Deliver business value

# Backend Development Responsibilities

- Microservices

- Internal Services

# API Responsibilities

The Senior Backend Engineer designs and implements:

- GraphQL APIs
- gRPC Services

- Authorization Services
