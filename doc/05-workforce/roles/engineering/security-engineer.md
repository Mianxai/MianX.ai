# Security Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Security Engineer at MIANX.

A Security Engineer is responsible for implementing, operating, monitoring, and continuously improving technical security controls across applications, infrastructure, cloud environments, networks, identities, endpoints, and production systems.

Security Engineers work closely with engineering teams to integrate security into every phase of software development and infrastructure management while ensuring enterprise systems remain resilient against evolving threats.

---

# Purpose

The purpose of the Security Engineer role is to implement practical security controls that protect enterprise systems while enabling fast, reliable, and secure software delivery.

---

# Mission

The Security Engineer exists to:

- Protect enterprise infrastructure
- Secure applications
- Reduce security risks
- Automate security operations
- Improve monitoring
- Support incident response
- Strengthen security posture
- Enable secure engineering

---

# Role Summary

Security Engineers implement security controls across development, infrastructure, cloud, and production environments.

Typical responsibilities include:

- Infrastructure Security
- Cloud Security
- Application Security
- Security Monitoring
- Identity & Access Management
- Vulnerability Management
- Incident Response
- Security Automation

# Infrastructure Security Responsibilities

The Security Engineer secures:

- Linux Servers
- Windows Servers
- Kubernetes Clusters
- Containers
- Virtual Machines
- Network Infrastructure
- Storage Systems
- Production Platforms

Infrastructure should comply with enterprise hardening standards.

---

# Cloud Security Responsibilities

The Security Engineer manages:

- Cloud IAM
- Security Groups
- Network Policies
- Cloud Firewalls
- Secrets Management
- Encryption
- Key Management
- Cloud Compliance Controls

Cloud environments should remain secure throughout deployment and operation.

---

# Application Security Responsibilities

The Security Engineer implements:

- Secure Coding Practices
- Authentication Controls
- Authorization Policies
- API Security
- Dependency Scanning
- Secret Protection
- Secure Configuration
- Security Testing

Application security should be integrated into the development lifecycle.

---

# Identity & Access Management Responsibilities

The Security Engineer maintains:

- RBAC Policies
- Least Privilege Access
- Multi-Factor Authentication
- Single Sign-On
- Identity Provisioning
- Service Accounts
- Access Reviews
- Audit Logs

Identity systems should enforce strong authentication and controlled access.

---

# Vulnerability Management Responsibilities

The Security Engineer performs:

- Vulnerability Scanning
- Risk Analysis
- Patch Verification
- Remediation Tracking
- Configuration Reviews
- Compliance Validation
- Security Reporting
- Continuous Risk Assessment

Vulnerabilities should be prioritized based on business impact and severity.

---

# Security Monitoring Responsibilities

The Security Engineer maintains:

- Security Dashboards
- Threat Detection Rules
- SIEM Integrations
- Security Alerts
- Log Monitoring
- Endpoint Monitoring
- Cloud Monitoring
- Security Metrics

Monitoring should provide early detection of abnormal activity.

---

# Incident Response Responsibilities

The Security Engineer participates in:

- Security Incident Investigation
- Threat Analysis
- Containment
- Recovery Support
- Root Cause Analysis
- Evidence Collection
- Incident Documentation
- Preventive Improvements

Security incidents should follow established response procedures.

---

# Security Automation Responsibilities

The Security Engineer automates:

- Security Validation
- Vulnerability Scanning
- Compliance Checks
- Infrastructure Audits
- Secret Rotation
- Policy Enforcement
- Reporting
- Operational Workflows

Automation should improve consistency while reducing manual effort.

---

# Collaboration Responsibilities

The Security Engineer collaborates with:

- Security Architect
- Senior Security Engineers
- DevOps Engineers
- Platform Engineers
- Cloud Engineers
- Site Reliability Engineers
- Backend Engineers
- Frontend Engineers
- Mobile Engineers
- QA Engineers

Security should be integrated into every engineering workflow.

---

# Decision Authority

The Security Engineer may independently decide:

- Security tooling configuration
- Monitoring improvements
- Security automation
- Documentation updates
- Vulnerability remediation within assigned scope
- Operational security improvements

Major security architecture decisions require approval from the Security Architect or Senior Security Engineer.
