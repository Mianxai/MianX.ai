# Junior Frontend Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Junior Frontend Engineer at MIANX.

A Junior Frontend Engineer is an entry-level software engineer responsible for building, testing, maintaining, and improving frontend applications while learning professional frontend engineering practices under the guidance of experienced engineers.

The role focuses on building a strong foundation in modern web technologies, user interface development, accessibility, performance optimization, and engineering best practices.

---

# Purpose

The purpose of the Junior Frontend Engineer role is to develop capable frontend engineers through structured mentorship, practical experience, and exposure to production-grade frontend systems.

---

# Mission

The Junior Frontend Engineer exists to:

- Learn frontend engineering
- Build responsive user interfaces
- Develop reusable components
- Improve frontend performance
- Follow engineering standards
- Deliver assigned tasks
- Collaborate with teammates
- Prepare for the Frontend Engineer role

---

# Role Summary

Junior Frontend Engineers contribute to frontend development while working closely with experienced frontend engineers.

Typical work includes:

- UI implementation
- Component development
- API integration
- Bug fixing
- Unit testing
- Documentation updates
- Learning frontend architecture

- Keyboard Navigation
- Screen Reader Compatibility
- Accessible Forms

- Focus Management

# Security Responsibilities

The Junior Frontend Engineer follows secure frontend development practices including:

- XSS Prevention
- Input Validation
- Secure Authentication
- Token Protection
- Safe API Consumption
- Secure Browser Storage
- Dependency Updates
- Secure Coding Standards

Security should be incorporated into every frontend feature.
