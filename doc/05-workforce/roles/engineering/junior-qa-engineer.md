# Junior QA Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Junior QA Engineer at MIANX.

A Junior QA Engineer is an entry-level engineering professional responsible for assisting in software quality assurance activities by executing manual tests, supporting automated testing, identifying defects, validating software functionality, and learning quality engineering best practices under the guidance of senior QA professionals.

The role focuses on developing practical experience in software testing, automation, API validation, regression testing, defect management, documentation, and quality assurance processes.

---

# Purpose

The purpose of the Junior QA Engineer role is to develop skilled quality engineers through structured mentorship, practical testing experience, and continuous learning while supporting the delivery of reliable, secure, and high-quality software.

---

# Mission

The Junior QA Engineer exists to:

- Learn quality engineering
- Support software testing
- Improve product quality
- Detect defects early
- Assist test automation
- Maintain testing documentation
- Follow QA standards
- Prepare for the QA Engineer role

---

# Role Summary

Junior QA Engineers contribute to daily quality assurance activities while working under the supervision of QA Engineers and Senior QA Engineers.

- Bug Reporting
- Documentation
- Continuous Learning

# Functional Testing Responsibilities

The Junior QA Engineer performs:

- User Workflow Testing
- Acceptance Criteria Verification

# Manual Testing Responsibilities

The Junior QA Engineer executes:

- Test Cases
- Smoke Tests
- Sanity Tests
- Regression Tests
- Cross-browser Testing
- Device Testing
- User Acceptance Support
- Exploratory Testing

Manual testing should identify defects before production deployment.

# Automation Support Responsibilities

The Junior QA Engineer assists with:

- Automated Test Execution
- Test Script Maintenance
- Regression Automation
- CI/CD Test Validation
- Test Data Preparation
- Test Environment Verification
- Automation Reporting

Automation work should support efficient and repeatable testing.

# API Testing Responsibilities

The Junior QA Engineer assists with:

- API Request Validation
- Response Verification
- Authentication Testing
- Authorization Validation
- Error Response Testing
- Basic API Regression

- Test Data Validation
