# Engineering Intern

> This document defines the responsibilities, expectations, learning objectives, and performance standards for Engineering Interns at MIANX.

An Engineering Intern is an entry-level member of the engineering organization who participates in real software development while learning professional engineering practices under close mentorship.

The internship is designed to bridge academic knowledge with practical industry experience.

---

# Purpose

The purpose of the Engineering Internship Program is to develop future software engineers by providing structured learning, hands-on project experience, mentorship, and exposure to modern software engineering practices.

---

# Mission

The Engineering Intern exists to:

- Learn professional software engineering
- Contribute to real projects
- Develop technical skills
- Understand engineering workflows
- Practice teamwork
- Improve problem-solving abilities
- Build engineering discipline
- Prepare for a full-time engineering career

---

# Role Summary

Engineering Interns participate in day-to-day engineering activities while receiving continuous guidance from experienced engineers.

Typical work includes:

- Small feature implementation
- Bug fixing
- Writing automated tests
- Documentation updates
- Code reviews
- Learning development tools
- Participating in engineering meetings

The internship focuses on learning first, productivity second.

---

# Internship Objectives

During the internship, interns should:

- Understand the MIANX engineering process
- Learn software development workflows
- Gain experience with Git and version control
- Build production-quality code
- Write automated tests
- Improve debugging skills
- Practice documentation
- Develop collaboration skills

---

# Primary Responsibilities

The Engineering Intern is responsible for:

- Learning engineering practices
- Completing assigned tasks
- Writing clean code
- Fixing simple bugs
- Writing tests
- Updating documentation
- Participating in code reviews
- Attending technical sessions
- Asking questions
- Continuous improvement

---

# Software Development Responsibilities

Engineering Interns may contribute to:

- Small product features
- UI improvements
- Backend endpoints
- Internal tools
- Automation scripts
- Test cases
- Documentation
- Bug fixes

Tasks are selected based on learning value and appropriate complexity.

---

# Learning Responsibilities

Engineering Interns are expected to learn:

- Programming languages used at MIANX
- Software architecture basics
- Git workflows
- Code review practices
- Testing methodologies
- CI/CD fundamentals
- Secure coding practices
- Engineering documentation

Learning is the primary objective of the internship.

---

# Code Quality Responsibilities

Engineering Interns should:

- Follow coding standards
- Write readable code
- Add meaningful comments when appropriate
- Write automated tests
- Update documentation
- Apply feedback from reviews
- Follow secure coding practices

Quality habits should be developed from the beginning.

---

# Testing Responsibilities

Engineering Interns participate in:

- Unit testing
- Manual testing
- Bug verification
- Regression testing
- Test maintenance

Testing is considered part of software development, not a separate activity.

---

# Collaboration Responsibilities

Engineering Interns collaborate with:

- Engineering Manager
- Technical Lead
- Senior Software Engineers
- Software Engineers
- Associate Software Engineers
- Junior Software Engineers
- QA Engineers
- Product Managers

Professional communication and curiosity are encouraged.

---

# Mentorship

Each Engineering Intern is assigned a mentor.

The mentor provides:

- Technical guidance
- Code review feedback
- Career advice
- Learning resources
- Project support
- Weekly check-ins
- Progress evaluations

Mentorship is a core component of the internship program.

---

# Decision Authority

Engineering Interns may independently decide:

- Implementation details for assigned learning tasks
- Test implementation
- Documentation improvements
- Small refactoring within assigned work

Major technical decisions require mentor or Technical Lead approval.

---

# Engineering Principles

Engineering Interns are expected to follow:

- Simplicity
- Reliability
- Security
- Documentation
- Collaboration
- Ownership
- Professionalism
- Curiosity
- Respect
- Continuous Learning

Learning should always be accompanied by responsible engineering practices.

---

# Core Competencies

Engineering Interns should develop knowledge of:

- Programming Fundamentals
- Object-Oriented Programming
- Data Structures
- Algorithms
- Git
- REST APIs
- SQL Basics
- Debugging
- Testing
- Software Development Lifecycle

Competency is measured by growth throughout the internship.

---

# Performance Expectations

Engineering Interns are expected to:

- Complete assigned learning objectives
- Deliver assigned tasks on time
- Demonstrate technical improvement
- Accept constructive feedback
- Participate actively in discussions
- Follow engineering standards
- Collaborate professionally
- Show initiative in learning

---

# Key Performance Indicators (KPIs)

| KPI | Objective |
|------|-----------|
| Learning Progress | Continuous skill development |
| Task Completion | Reliable execution |
| Code Quality | Follow engineering standards |
| Test Participation | Build reliable software |
| Documentation | Maintain accurate project knowledge |
| Code Review Participation | Learn engineering practices |
| Mentor Feedback | Demonstrate growth |
| Team Collaboration | Professional communication |
| Attendance | Consistent participation |
| Professional Development | Readiness for full-time roles |

Intern evaluations prioritize learning, improvement, and professionalism over feature velocity.

---

# Reporting Structure

```text
Engineering Manager

↓

Technical Lead

↓

Mentor

↓

Engineering Intern
```

Engineering Interns work under direct mentorship and gradually increase their independence throughout the internship.

---

# Internship Deliverables

By the end of the internship, interns should have completed:

- Assigned engineering tasks
- At least one production-ready feature
- Multiple bug fixes
- Automated tests
- Technical documentation
- Code review participation
- Final project presentation *(where applicable)*

---

# Governance Responsibilities

Engineering Interns ensure:

- Compliance with coding standards
- Secure development practices
- Proper version control usage
- Documentation updates
- Testing requirements
- Engineering policy compliance

---

# Documentation Ownership

Engineering Interns contribute to:

- Feature Documentation
- Code Comments
- Bug Reports
- Test Documentation
- Knowledge Base Articles
- Technical Notes
- User Documentation *(where applicable)*

---

# Success Criteria

A successful Engineering Intern:

- Demonstrates continuous learning
- Writes clean, maintainable code
- Completes assigned work responsibly
- Accepts and applies feedback
- Collaborates effectively
- Follows engineering standards
- Shows professionalism
- Is prepared for a Junior Software Engineer role
