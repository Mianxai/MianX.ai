# Performance Manager

> This document defines the responsibilities, authority, expectations, and performance standards of the Performance Manager at MIANX.

The Performance Manager is responsible for designing, implementing, and continuously improving MIANX's performance management framework by overseeing goal management, performance evaluations, employee development planning, manager coaching, performance analytics, and continuous performance improvement initiatives.

The Performance Manager reports directly to the Head of Human Resources.

---

# Purpose

The purpose of the Performance Manager role is to build a fair, transparent, and high-performing performance management system that aligns employee performance with MIANX's strategic objectives while supporting continuous employee growth.

---

# Mission

The Performance Manager exists to:

- Improve organizational performance
- Develop high-performing employees
- Align goals with strategy
- Build accountability
- Support continuous feedback
- Improve manager effectiveness
- Strengthen performance culture
- Drive continuous improvement

---

# Role Summary

The Performance Manager oversees:

- Performance Management Framework
- Goal Setting (OKRs/KPIs)
- Performance Reviews
- Continuous Feedback
- Individual Development Plans (IDPs)
- Performance Improvement Plans (PIPs)
- Performance Analytics
- Talent Reviews
- Manager Coaching
- Performance Policies
- Employee Recognition
- Performance Systems

---

# Primary Responsibilities

The Performance Manager is responsible for:

- Managing the performance management framework
- Coordinating annual and quarterly performance reviews
- Supporting managers with performance coaching
- Developing goal-setting methodologies
- Monitoring employee performance metrics
- Managing performance improvement programs
- Conducting performance analytics
- Supporting talent reviews
- Improving employee accountability
- Maintaining performance documentation
- Driving continuous performance improvement
- Escalating strategic workforce concerns

---

# Performance Management Responsibilities

The Performance Manager manages:

- Goal Planning
- Performance Review Cycles
- Performance Calibration
- Performance Improvement Plans
- Individual Development Plans
- Continuous Feedback Programs
- Employee Recognition Programs
- Talent Review Meetings
- Performance Dashboards
- Performance Analytics

Performance initiatives should improve individual productivity while supporting MIANX's long-term organizational success.

# Governance Responsibilities

- Manager Evaluation Standards

- Employee Recognition Standards

Governance ensures performance evaluations remain objective, consistent, measurable, and aligned with organizational values.

# Risk Management Responsibilities

The Performance Manager monitors:

- Low Performance Risks
- Inconsistent Evaluations
- Employee Development Risks
- Performance Bias Risks
- Compliance Risks

- Leadership Effectiveness Risks

- Organizational Risks

Critical performance issues must be escalated to the Head of Human Resources.

# Decision Authority

The Performance Manager may independently approve:

- Performance review schedules
- Goal-setting templates
- Manager coaching sessions
- Performance reports
- Employee recognition recommendations
- Development planning guidance
- Performance analytics
- Process improvement recommendations

Performance rating appeals, executive performance reviews, major policy changes, executive development plans, and organization-wide performance framework revisions require approval from the Head of Human Resources or HR Director.
