# Information Security Manager

> This document defines the responsibilities, authority, expectations, and performance standards of the Information Security Manager at MIANX.

The Information Security Manager is responsible for establishing, implementing, operating, monitoring, and continuously improving MIANX's enterprise information security program. The role ensures the confidentiality, integrity, and availability of organizational information assets while maintaining compliance with applicable laws, regulations, industry standards, and internal security policies.

The Information Security Manager reports directly to the Head of Information Technology.

---

# Purpose

The purpose of the Information Security Manager role is to protect MIANX's digital assets, technology infrastructure, business operations, customer information, and intellectual property through effective cybersecurity governance, risk management, and operational security.

---

# Mission

The Information Security Manager exists to:

- Protect organizational information assets
- Reduce cybersecurity risks
- Strengthen security governance
- Maintain regulatory compliance
- Improve cyber resilience
- Build security awareness
- Enable secure business growth
- Continuously mature security capabilities

# Decision Authority

The Information Security Manager may independently approve:

- Security procedures
- Security awareness initiatives
- Vulnerability remediation priorities
- Security monitoring configurations
- Incident response activities
- Security assessments
