# Software Architect

> This document defines the responsibilities, authority, expectations, and performance standards of the Software Architect at MIANX.

The Software Architect is responsible for designing the technical architecture of enterprise software platforms, defining engineering standards, evaluating technologies, ensuring scalability, security, reliability, and maintainability of software systems, and guiding engineering teams in implementing high-quality technical solutions aligned with MIANX's technology strategy.

The Software Architect reports directly to the Engineering Manager.

---

# Purpose

The purpose of the Software Architect role is to establish a robust architectural foundation that enables the delivery of scalable, secure, maintainable, and high-performing software solutions supporting MIANX's long-term business objectives.

---

The Software Architect exists to:

- Design enterprise software architecture
- Define technical standards
- Ensure scalable system design
- Promote engineering excellence
- Reduce technical debt
- Improve software quality
- Support innovation
- Enable sustainable technology growth
