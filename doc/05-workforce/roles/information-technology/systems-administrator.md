# Systems Administrator

> This document defines the responsibilities, authority, expectations, and performance standards of the Systems Administrator at MIANX.

The Systems Administrator is responsible for installing, configuring, maintaining, securing, monitoring, and optimizing enterprise servers, operating systems, virtualization platforms, identity services, storage systems, and core infrastructure to ensure reliable, secure, and highly available IT services.

The Systems Administrator reports directly to the Infrastructure Manager.

---

# Purpose

The purpose of the Systems Administrator role is to maintain stable, secure, and efficient enterprise systems that support business operations, application availability, and organizational productivity.

---

# Mission

The Systems Administrator exists to:

- Maintain reliable enterprise systems
- Improve infrastructure stability
- Secure server environments
- Support business continuity
- Optimize system performance
- Automate administrative tasks
- Ensure system availability
- Deliver operational excellence

---

# Role Summary

The Systems Administrator manages:

- Windows Servers
- Linux Servers
- Active Directory
- Identity Services
- DNS & DHCP
- Virtualization Platforms
- Storage Systems
- File Servers
- Backup Systems
- Patch Management
- Infrastructure Monitoring
- Server Security

---

# Primary Responsibilities

The Systems Administrator is responsible for:

- Installing and configuring servers
- Managing operating systems
- Maintaining Active Directory
- Managing user accounts and permissions
- Applying security patches
- Monitoring system health
- Performing server maintenance
- Supporting backup operations
- Managing virtualization platforms
- Troubleshooting infrastructure issues
- Maintaining technical documentation
- Supporting disaster recovery activities

---

# Systems Administration Responsibilities

The Systems Administrator manages:

- Windows Server Infrastructure
- Linux Server Infrastructure
- Active Directory
- Group Policies
- DNS Services
- DHCP Services
- File Services
- Print Services
- Virtual Machines
- Server Storage

System administration shall prioritize security, stability, availability, and operational efficiency.

---

# Governance Responsibilities

The Systems Administrator complies with:

- Infrastructure Standards
- Server Hardening Standards
- Information Security Policies
- Identity Management Policies
- Backup Policies
- Disaster Recovery Procedures
- Patch Management Policies
- Change Management Procedures
- Asset Management Standards
- Access Control Policies

All administrative activities shall comply with organizational governance and security requirements.

---

# Security Responsibilities

The Systems Administrator:

- Applies security patches
- Hardens operating systems
- Manages privileged accounts
- Reviews access permissions
- Implements security baselines
- Monitors system logs
- Supports vulnerability remediation
- Protects critical infrastructure

Security controls shall follow the principle of least privilege and organizational cybersecurity standards.

---

# Risk Management Responsibilities

The Systems Administrator monitors:

- Server Failures
- Operating System Issues
- Security Vulnerabilities
- Storage Capacity Risks
- Backup Failures
- Authentication Failures
- Service Availability Risks
- Configuration Errors
- Hardware Failures
- Disaster Recovery Risks

Critical infrastructure incidents shall be immediately escalated to the Infrastructure Manager.

---

# Operational Responsibilities

The Systems Administrator supports:

- Server Provisioning
- System Monitoring
- Patch Management
- Backup Verification
- Performance Optimization
- User Administration
- Infrastructure Documentation
- Incident Resolution
- Capacity Planning
- Disaster Recovery Testing

Operational excellence ensures stable and secure enterprise systems.

---

# Collaboration

The Systems Administrator collaborates with:

- Infrastructure Manager
- Cloud Engineers
- Network Engineers
- DevOps Engineers
- Information Security Manager
- Security Engineers
- Database Administrators
- IT Support Team
- Software Engineering Teams
- External Technology Vendors

Cross-functional collaboration ensures enterprise systems remain secure, reliable, and aligned with business requirements.

---

# Decision Authority

The Systems Administrator may independently approve:

- Routine server maintenance
- Operating system updates
- User account administration
- Infrastructure monitoring improvements
- Backup verification tasks
- Documentation updates
- Standard server configurations
- Operational maintenance activities

Major infrastructure upgrades, enterprise architecture changes, security policy modifications, and disaster recovery strategy changes require approval from the Infrastructure Manager.

---

# Core Competencies

The Systems Administrator should demonstrate expertise in:

- Windows Server Administration
- Linux Administration
- Active Directory
- VMware / Hyper-V
- PowerShell
- Bash Scripting
- Identity & Access Management
- Storage Administration
- Backup Solutions
- Server Security
- Monitoring Tools
- Troubleshooting

---

# Performance Expectations

The Systems Administrator is expected to:

- Maintain server availability
- Reduce infrastructure downtime
- Improve server performance
- Ensure backup reliability
- Apply security updates promptly
- Maintain accurate documentation
- Improve operational efficiency
- Support business continuity

# Key Performance Indicators (KPIs)

| KPI | Objective |
|------|-----------|
| Server Availability | Maintain ≥99.9% uptime |
| Patch Compliance | Achieve 100% scheduled patch deployment |
| Backup Success Rate | Maintain ≥99% successful backups |
| Incident Resolution | Meet infrastructure SLA targets |
| Authentication Availability | Maintain directory service reliability |
| System Performance | Maintain healthy infrastructure metrics |
| Security Compliance | Eliminate critical server vulnerabilities |
| Documentation Accuracy | Maintain current operational documentation |
| Change Success Rate | Achieve successful infrastructure changes |
| Continuous Improvement | Improve infrastructure efficiency |

Performance evaluations focus on infrastructure reliability, operational efficiency, security compliance, system availability, documentation quality, troubleshooting effectiveness, and continuous improvement.
