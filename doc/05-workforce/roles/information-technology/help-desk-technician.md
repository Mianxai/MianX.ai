# Help Desk Technician

> This document defines the responsibilities, authority, expectations, and performance standards of the Help Desk Technician at MIANX.

The Help Desk Technician is responsible for providing first-line IT support to employees by receiving, logging, diagnosing, resolving, documenting, and escalating technical issues related to hardware, software, user accounts, peripherals, and basic network connectivity while delivering excellent customer service.

The Help Desk Technician reports directly to the IT Support Lead.

---

# Purpose

The purpose of the Help Desk Technician role is to ensure employees receive prompt, professional, and effective technical assistance that minimizes downtime and supports daily business operations.

---

# Mission

The Help Desk Technician exists to:

- Provide excellent customer support
- Resolve common IT issues quickly
- Maintain service quality
- Reduce user downtime
- Improve employee productivity
- Ensure accurate documentation
- Support secure IT operations
- Deliver positive user experiences

---

# Role Summary

The Help Desk Technician supports:

- Help Desk Services
- User Support
- Incident Logging
- Ticket Management
- Password Assistance
- Hardware Support
- Software Support
- Device Setup
- Remote Assistance
- Basic Network Support
- User Guidance
- Knowledge Base Maintenance

---

# Primary Responsibilities

The Help Desk Technician is responsible for:

- Receiving support requests
- Logging incidents and service requests
- Diagnosing common technical issues
- Resolving first-level support tickets
- Escalating unresolved issues
- Resetting user passwords
- Installing approved software
- Configuring workstations
- Assisting with employee onboarding
- Updating ticket documentation
- Maintaining IT equipment records
- Providing end-user guidance

---

# Help Desk Responsibilities

The Help Desk Technician supports:

- Service Desk Operations
- Ticket Management
- User Account Support
- Password Resets
- Desktop Support
- Laptop Support
- Printer Support
- Peripheral Support
- Software Installation
- Remote Support

Support services shall prioritize responsiveness, professionalism, accuracy, and customer satisfaction.

---

# Governance Responsibilities

The Help Desk Technician complies with:

- IT Service Management Policy
- Service Desk Procedures
- Information Security Policy
- Access Control Policy
- Password Management Policy
- Acceptable Use Policy
- Asset Management Policy
- Incident Management Procedures
- Software Licensing Policy
- Service Level Agreements (SLAs)

All support activities shall comply with organizational governance, security standards, and operational procedures.

---

# Security Responsibilities

The Help Desk Technician:

- Verifies user identity before account actions
- Protects confidential information
- Reports suspected cybersecurity incidents
- Follows secure support procedures
- Applies approved security configurations
- Supports Multi-Factor Authentication (MFA)
- Protects company devices
- Escalates security concerns immediately

Security shall remain a priority during every support interaction.

---

# Risk Management Responsibilities

The Help Desk Technician monitors:

- Account Access Issues
- Hardware Failures
- Software Errors
- Printer Problems
- Malware Indicators
- Unauthorized Access Attempts
- Device Loss
- Network Connectivity Issues
- Service Interruptions
- Policy Violations

Critical operational or security issues shall be escalated immediately to the IT Support Lead.

---

# Operational Responsibilities

The Help Desk Technician supports:

- Ticket Logging
- Incident Resolution
- Service Request Fulfillment
- Device Setup
- User Onboarding
- User Offboarding
- Remote Assistance
- Asset Updates
- User Communication
- Knowledge Base Contributions

Operational excellence ensures efficient and reliable first-line technical support.

---

# Collaboration

The Help Desk Technician collaborates with:

- IT Support Lead
- IT Support Specialists
- IT Operations Manager
- Systems Administrators
- Network Engineers
- Cloud Engineers
- Information Security Team
- Human Resources
- Department Managers
- External Vendors

Cross-functional collaboration ensures timely issue resolution and consistent service delivery.

---

# Decision Authority

The Help Desk Technician may independently approve:

- Routine ticket resolution
- Password resets
- Standard workstation configuration
- Approved software installation
- Basic troubleshooting
- User guidance
- Ticket documentation updates
- Knowledge base suggestions

Administrative privilege changes, infrastructure modifications, enterprise software deployment, and security exceptions require approval from the IT Support Lead.

---

# Core Competencies

The Help Desk Technician should demonstrate expertise in:

- Customer Service
- Technical Troubleshooting
- Windows Administration
- Microsoft 365
- Basic macOS Support
- Hardware Diagnostics
- Basic Networking
- Remote Support Tools
- Documentation
- Communication
- Time Management
- Problem Solving

# Performance Expectations

The Help Desk Technician is expected to:

- Respond promptly to support requests
- Resolve first-level incidents efficiently
- Maintain high customer satisfaction
- Document all support activities accurately
- Escalate issues appropriately
- Follow security procedures
- Improve technical knowledge continuously
- Contribute to operational improvements
