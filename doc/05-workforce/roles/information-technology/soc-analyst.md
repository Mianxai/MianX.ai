# SOC Analyst

> This document defines the responsibilities, authority, expectations, and performance standards of the SOC Analyst at MIANX.

The SOC (Security Operations Center) Analyst is responsible for continuously monitoring, detecting, investigating, triaging, escalating, and responding to cybersecurity events affecting MIANX's infrastructure, cloud services, applications, endpoints, and networks. The role serves as the frontline defender against cyber threats and ensures rapid identification and containment of security incidents.

The SOC Analyst reports directly to the Information Security Manager.

---

# Purpose

The purpose of the SOC Analyst role is to provide 24/7 (or designated operational hours) security monitoring, threat detection, and incident response capabilities that minimize cybersecurity risks and protect enterprise operations.

---

# Mission

The SOC Analyst exists to:

- Detect cyber threats rapidly
- Respond to security incidents
- Reduce attacker dwell time
- Protect enterprise systems
- Improve threat visibility
- Strengthen operational resilience
- Support forensic investigations
- Continuously improve security monitoring

# Primary Responsibilities

The SOC Analyst is responsible for:

- Triaging security alerts
- Investigating suspicious activity
- Escalating confirmed incidents

- Supporting digital forensics

- Maintaining incident records

# Security Operations Responsibilities

The SOC Analyst manages:

- SIEM Dashboards
- Security Alerts
- Endpoint Detection & Response (EDR)
- Security Event Correlation
- Threat Intelligence Feeds
- Security Monitoring Tools
- Incident Queues
- IOC Management
- Detection Rules
- Security Playbooks

Security operations shall prioritize rapid detection, containment, investigation, and recovery.

# Governance Responsibilities

The SOC Analyst complies with:

- Information Security Policy
- Incident Response Plan
- Security Monitoring Standards
- Threat Intelligence Procedures
- Vulnerability Management Policy
- Log Retention Policy
- Digital Forensics Procedures
- Access Control Policy

- Documentation Standards

All SOC activities shall comply with enterprise governance, cybersecurity policies, and legal requirements.

# Security Responsibilities

The SOC Analyst:

- Monitors security events continuously
- Investigates malicious activity
- Validates security alerts
- Escalates confirmed incidents
- Supports containment efforts
- Collects forensic evidence
- Tracks indicators of compromise (IOCs)
- Maintains detection effectiveness

Security operations shall follow standardized incident response procedures and security playbooks.

---

# Risk Management Responsibilities

The SOC Analyst monitors:

- Malware Activity
- Ransomware Attacks
- Phishing Campaigns
- Insider Threats
- Privilege Escalation Attempts
- Unauthorized Access
- Data Exfiltration
- Cloud Security Threats
- Network Intrusions
- Advanced Persistent Threats (APT)

Critical cybersecurity incidents shall be escalated immediately to the Information Security Manager.

The SOC Analyst supports:

- 24/7 Security Monitoring
- Alert Triage

- Malware Investigation

# Decision Authority

The SOC Analyst may independently approve:

- Alert classifications
- Initial incident triage
- Routine threat investigations
- IOC documentation
- Security event escalation
- Incident documentation updates
- Detection tuning recommendations
- Routine operational improvements

Major incident declarations, enterprise-wide containment actions, security policy changes, and strategic security decisions require approval from the Information Security Manager.

- Detect threats rapidly
- Reduce false positives
- Improve detection coverage
- Respond to incidents efficiently
