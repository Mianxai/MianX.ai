# IT Support Specialist

> This document defines the responsibilities, authority, expectations, and performance standards of the IT Support Specialist at MIANX.

The IT Support Specialist is responsible for providing first-line and second-line technical support to employees by diagnosing, troubleshooting, resolving, documenting, and escalating hardware, software, network, and account-related issues while ensuring high-quality customer service and minimal business disruption.

The IT Support Specialist reports directly to the IT Support Lead.

---

# Purpose

The purpose of the IT Support Specialist role is to provide timely, reliable, and professional technical support that enables employees to work efficiently while maintaining stable and secure IT services.

---

# Mission

The IT Support Specialist exists to:

- Deliver excellent user support
- Resolve technical issues quickly
- Minimize business downtime
- Improve user productivity
- Maintain IT standards
- Support secure operations
- Enhance customer satisfaction
- Continuously improve support quality

---

# Role Summary

The IT Support Specialist is responsible for:

- End-User Support
- Incident Resolution
- Service Requests
- Hardware Support
- Software Installation
- Device Configuration
- User Account Management
- Basic Network Troubleshooting
- Asset Support
- Remote Assistance
- Knowledge Base Contributions
- Technical Documentation

---

# Primary Responsibilities

The IT Support Specialist is responsible for:

- Responding to support tickets
- Troubleshooting technical issues
- Installing operating systems and applications
- Configuring laptops, desktops, and mobile devices
- Managing user accounts and permissions
- Supporting Microsoft 365 services
- Assisting with printer and peripheral issues
- Maintaining IT asset records
- Escalating unresolved incidents
- Updating ticket documentation
- Assisting new employee onboarding
- Supporting IT projects when assigned

---

# IT Support Responsibilities

The IT Support Specialist manages:

- User Devices
- Software Installations
- Account Support
- Password Resets
- Printer Support
- Remote Support
- Desktop Troubleshooting
- Mobile Device Support
- Peripheral Configuration
- Basic Network Troubleshooting

Support services shall prioritize responsiveness, professionalism, security, and user satisfaction.

---

# Governance Responsibilities

The IT Support Specialist complies with:

- IT Service Management Policy
- Service Desk Procedures
- Information Security Policy
- Access Control Policy
- Acceptable Use Policy
- Asset Management Policy
- Incident Management Procedures
- Password Management Standards
- Software Licensing Policy
- Service Level Agreements (SLAs)

All support activities shall comply with organizational governance and security standards.

---

# Security Responsibilities

The IT Support Specialist:

- Verifies user identities before account actions
- Protects confidential information
- Reports suspected security incidents
- Maintains endpoint security standards
- Ensures software compliance
- Applies approved security configurations
- Supports MFA implementation
- Escalates cybersecurity concerns immediately

Security shall be integrated into every support interaction.

---

# Risk Management Responsibilities

The IT Support Specialist monitors:

- User Account Issues
- Device Failures
- Malware Symptoms
- Unauthorized Access Attempts
- Software Licensing Issues
- Hardware Failures
- Connectivity Problems
- Asset Loss
- Security Policy Violations
- Service Disruptions

Critical issues shall be escalated immediately to the IT Support Lead.

---

# Operational Responsibilities

The IT Support Specialist supports:

- Incident Resolution
- Service Requests
- User Onboarding
- User Offboarding
- Device Deployment
- Hardware Replacement
- Software Installation
- Asset Tracking
- User Training
- Knowledge Base Updates

Operational excellence ensures efficient support services and high employee productivity.

---

# Collaboration

The IT Support Specialist collaborates with:

- IT Support Lead
- IT Operations Manager
- Systems Administrators
- Network Engineers
- Cloud Engineers
- Information Security Team
- Human Resources
- Department Managers
- Software Engineering Teams
- External Vendors

Cross-functional collaboration ensures timely issue resolution and seamless technology support.

---

# Decision Authority

The IT Support Specialist may independently approve:

- Routine ticket resolution
- Password resets
- Standard software installations
- Approved hardware replacements
- User account updates
- Knowledge base improvements
- Routine troubleshooting
- Standard workstation configurations

Infrastructure modifications, privileged account changes, enterprise software deployments, and security policy exceptions require approval from the IT Support Lead or IT Operations Manager.

---

# Core Competencies

The IT Support Specialist should demonstrate expertise in:

- Technical Troubleshooting
- Windows Administration
- macOS Fundamentals
- Microsoft 365
- Active Directory
- Hardware Diagnostics
- Networking Fundamentals
- Customer Service
- Remote Support Tools
- IT Asset Management
- Documentation
- Communication

---

# Performance Expectations

The IT Support Specialist is expected to:

- Resolve tickets within SLA
- Deliver excellent customer service
- Maintain accurate documentation
- Reduce repeat incidents
- Improve first-contact resolution
- Protect organizational assets
- Follow security procedures
- Continuously improve technical knowledge
