# Junior QA Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Junior QA Engineer at MIANX.

The Junior QA Engineer is responsible for supporting software quality assurance activities by executing test cases, reporting defects, validating software functionality, assisting with test automation, maintaining testing documentation, and learning organizational testing standards under the guidance of senior QA professionals.

The Junior QA Engineer reports directly to the Senior QA Engineer.

---

# Purpose

The purpose of the Junior QA Engineer role is to build a strong foundation in software quality assurance while supporting the delivery of reliable, secure, and high-quality software products.

---

# Mission

The Junior QA Engineer exists to:

- Learn software testing best practices
- Support quality assurance activities
- Identify software defects
- Improve software reliability
- Contribute to successful releases
- Assist automation initiatives
- Maintain testing documentation
- Continuously develop technical skills

---

# Role Summary

The Junior QA Engineer is responsible for:

- Manual Testing
- Test Case Execution
- Defect Reporting
- Regression Testing
- Smoke Testing
- Sanity Testing
- Test Documentation
- Test Data Preparation
- Automation Support
- Release Verification
- Learning QA Processes
- Continuous Improvement

---

# Primary Responsibilities

The Junior QA Engineer is responsible for:

- Executing assigned test cases
- Reporting software defects
- Verifying resolved issues
- Performing regression testing
- Conducting smoke testing
- Supporting API testing
- Preparing testing data
- Maintaining testing records
- Assisting automation engineers
- Following QA procedures
- Participating in sprint testing
- Learning testing tools and methodologies

---

# Software Testing Responsibilities

The Junior QA Engineer performs:

- Functional Testing
- Manual Testing
- Smoke Testing
- Sanity Testing
- Regression Testing
- UI Testing
- Basic API Testing
- Browser Compatibility Testing
- Test Data Validation
- Bug Verification

Testing activities shall follow approved QA standards and documented testing procedures.

---

# Governance Responsibilities

The Junior QA Engineer complies with:

- Software Development Lifecycle (SDLC)
- Quality Assurance Policy
- Testing Standards
- Secure SDLC Policy
- Change Management Policy
- Release Management Policy
- Information Security Policy
- Documentation Standards
- Risk Management Policy
- Compliance Requirements

All testing activities shall comply with organizational quality standards and governance requirements.

---

# Security Responsibilities

The Junior QA Engineer:

- Uses secure testing practices
- Protects confidential test information
- Uses approved test environments
- Reports security-related defects
- Handles test credentials securely
- Follows access control procedures
- Protects customer information
- Escalates security concerns immediately

Security awareness is required throughout all testing activities.

---

# Risk Management Responsibilities

The Junior QA Engineer monitors:

- Functional Defects
- Regression Issues
- Test Execution Errors
- Test Data Problems
- UI Issues
- API Failures
- Environment Problems
- Documentation Errors
- Release Risks
- Quality Issues

Significant defects and quality risks shall be escalated immediately to the Senior QA Engineer.

---

The Junior QA Engineer supports:

- Test Execution
- Test Documentation
- Bug Reporting

- Sprint Testing
- Test Environment Validation
- Test Data Preparation
- Release Verification

Operational excellence ensures consistent testing quality and supports reliable software releases.

- Technical Leads

Collaboration ensures accurate testing and effective communication throughout the software development lifecycle.

# Decision Authority

The Junior QA Engineer may independently perform:

- Assigned test execution
- Test evidence collection
- Bug reporting
- Test documentation updates
- Regression execution
- Smoke testing
- Test data preparation
- Daily QA reporting

Release approvals, testing strategies, automation framework modifications, and quality process changes require approval from the Senior QA Engineer or QA Manager.

- Manual Testing

- SQL Fundamentals

The Junior QA Engineer is expected to:

- Execute assigned tests accurately
- Report clear and reproducible defects
- Follow QA procedures
- Meet sprint deadlines
- Produce accurate documentation
- Learn testing tools continuously
- Improve technical skills
- Support successful software releases
