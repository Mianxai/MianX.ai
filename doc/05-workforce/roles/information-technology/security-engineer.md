# Security Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Security Engineer at MIANX.

The Security Engineer is responsible for designing, implementing, configuring, maintaining, monitoring, and continuously improving enterprise security technologies and technical security controls to protect MIANX's infrastructure, applications, cloud environments, networks, and digital assets against cyber threats.

The Security Engineer reports directly to the Information Security Manager.

---

# Purpose

The purpose of the Security Engineer role is to implement and operate technical cybersecurity controls that ensure the confidentiality, integrity, and availability of enterprise systems while minimizing cybersecurity risks.

---

# Mission

The Security Engineer exists to:

- Strengthen enterprise cybersecurity
- Protect critical infrastructure
- Reduce cyber risks
- Secure cloud environments
- Improve threat detection
- Automate security operations
- Enhance cyber resilience
- Support secure business growth

---

The Security Engineer manages:

- Security Infrastructure

- Firewalls
- Web Application Firewalls (WAF)
- Identity & Access Security
- SIEM Integrations
- Vulnerability Management
- Cloud Security
- Email Security
- Security Automation
- Network Security
- Security Monitoring

# Primary Responsibilities

The Security Engineer is responsible for:

- Implementing security controls
- Configuring security platforms
- Managing endpoint security
- Securing cloud infrastructure
- Deploying security technologies
- Supporting incident response
- Managing vulnerability remediation
- Conducting security assessments
- Maintaining secure configurations
- Supporting compliance initiatives
- Automating security operations
- Maintaining security documentation

# Security Engineering Responsibilities

The Security Engineer manages:

- Endpoint Detection & Response (EDR)
- Firewalls
- Intrusion Detection Systems (IDS)
- Intrusion Prevention Systems (IPS)
- Security Information & Event Management (SIEM)
- Identity Security
- Multi-Factor Authentication (MFA)
- VPN Security
- Cloud Security Controls
- Email Security Platforms

Security controls shall prioritize prevention, detection, response, and continuous improvement.

---

# Governance Responsibilities

The Security Engineer complies with:

- Information Security Policy
- Cybersecurity Framework
- Access Control Policy
- Cloud Security Standards
- Infrastructure Standards
- Secure Configuration Standards
- Incident Response Plan
- Vulnerability Management Policy
- Change Management Procedures
- Regulatory Security Requirements

All engineering activities shall comply with organizational governance and cybersecurity standards.

# Security Responsibilities

The Security Engineer:

- Deploys technical security controls
- Hardens enterprise systems
- Implements zero-trust security
- Configures network protections
- Protects cloud workloads
- Supports penetration testing
- Monitors security events
- Assists with incident investigations

Security engineering shall follow defense-in-depth principles and industry best practices.

---

# Risk Management Responsibilities

The Security Engineer monitors:

- Security Vulnerabilities
- Malware Threats
- Unauthorized Access
- Configuration Weaknesses
- Cloud Security Risks
- Endpoint Risks
- Identity Risks
- Firewall Misconfigurations
- Third-Party Security Risks
- Emerging Cyber Threats

Critical security issues shall be escalated immediately to the Information Security Manager.

- Security Monitoring

# Decision Authority

The Security Engineer may independently approve:

- Security configuration updates
- Routine firewall rule changes
- Endpoint security policies
- Vulnerability remediation activities
- Security monitoring improvements
- Security documentation updates
- Technical security maintenance
- Security automation enhancements

Major security architecture changes, enterprise security platform selection, organization-wide policy changes, and strategic cybersecurity initiatives require approval from the Information Security Manager.
