# Security Analyst

> This document defines the responsibilities, authority, expectations, and performance standards of the Security Analyst at MIANX.

The Security Analyst is responsible for monitoring, analyzing, investigating, documenting, and responding to cybersecurity events while continuously assessing vulnerabilities, improving security posture, and supporting regulatory compliance across MIANX's technology environment.

The Security Analyst reports directly to the Information Security Manager.

---

# Purpose

The purpose of the Security Analyst role is to proactively identify, assess, and mitigate cybersecurity risks while ensuring enterprise systems remain secure, compliant, and resilient against evolving threats.

---

# Mission

The Security Analyst exists to:

- Detect cyber threats
- Reduce security risks
- Improve threat visibility
- Support incident response
- Strengthen compliance
- Enhance security monitoring
- Protect enterprise assets
- Continuously improve cybersecurity maturity

---

The Security Analyst is responsible for:

The Security Analyst manages:

- Vulnerability Scanning

# Security Responsibilities

The Security Analyst:

- Monitors enterprise security events
- Investigates suspicious activity
- Performs log analysis
- Assesses vulnerabilities
- Tracks remediation efforts
- Supports forensic investigations
- Escalates confirmed threats
- Maintains security evidence

Security monitoring shall support continuous detection and proactive defense.

# Risk Management Responsibilities

The Security Analyst monitors:

- Malware Activity
- Unauthorized Access Attempts
- Insider Threats
- Vulnerability Exposure
- Phishing Campaigns
- Cloud Security Risks
- Privilege Misuse
- Compliance Risks
- Third-Party Risks
- Emerging Threat Intelligence

Critical threats shall be escalated immediately to the Information Security Manager.

# Decision Authority

The Security Analyst may independently approve:

- Alert classification
- Routine security investigations
- Vulnerability validation
- Security reporting updates
- Monitoring rule tuning recommendations
- Documentation updates
- Security metrics reporting
- Routine operational improvements

Security policy changes, incident declarations, major remediation priorities, and enterprise security decisions require approval from the Information Security Manager.
