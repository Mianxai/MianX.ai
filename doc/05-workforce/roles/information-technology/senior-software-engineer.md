# Senior Software Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Senior Software Engineer at MIANX.

The Senior Software Engineer is responsible for designing, developing, testing, optimizing, and maintaining enterprise software applications while providing technical leadership, mentoring junior engineers, contributing to architectural decisions, and ensuring the delivery of secure, scalable, maintainable, and high-quality software solutions.

The Senior Software Engineer reports directly to the Technical Lead.

---

# Purpose

The purpose of the Senior Software Engineer role is to build reliable enterprise software while serving as a senior technical contributor who improves engineering quality, mentors team members, and supports successful software delivery.

---

# Mission

The Senior Software Engineer exists to:

- Build enterprise software
- Deliver reliable solutions
- Improve engineering quality
- Mentor software engineers
- Reduce technical debt
- Support architecture implementation
- Promote engineering excellence
- Drive continuous improvement

# Decision Authority

The Senior Software Engineer may independently approve:

- Technical implementation details
- Code improvements
- Refactoring activities
- Internal development documentation

Architecture decisions, framework selection, infrastructure changes, and strategic engineering initiatives require approval from the Technical Lead or Software Architect.
