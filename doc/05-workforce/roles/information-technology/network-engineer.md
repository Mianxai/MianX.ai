# Network Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Network Engineer at MIANX.

The Network Engineer is responsible for designing, implementing, configuring, securing, monitoring, troubleshooting, and optimizing enterprise network infrastructure, including LAN, WAN, WLAN, VPN, firewalls, routers, switches, internet connectivity, and network security services to ensure reliable, secure, and high-performance communication across MIANX.

The Network Engineer reports directly to the Infrastructure Manager.

---

# Purpose

The purpose of the Network Engineer role is to build and maintain secure, scalable, resilient, and highly available enterprise network infrastructure that supports business operations, cloud connectivity, and digital transformation.

---

# Mission

The Network Engineer exists to:

- Build reliable networks
- Improve network security
- Ensure high network availability
- Optimize network performance
- Support business continuity
- Enable secure connectivity
- Reduce operational risks
- Drive infrastructure modernization

The Network Engineer is responsible for:

- Managing firewall policies

- Optimizing network performance

# Network Infrastructure Responsibilities

The Network Engineer manages:

- Core Network Infrastructure
- Distribution Switches
- Access Switches
- Enterprise Routers
- Firewalls
- Wireless Controllers
- VPN Gateways
- Internet Links
- DNS Services
- Network Monitoring Systems

Network infrastructure shall prioritize availability, scalability, redundancy, performance, and security.

The Network Engineer ensures compliance with:

- Network Standards

- Firewall Standards
- Remote Access Policies
- VPN Policies
- Infrastructure Standards
- Change Management Procedures
- Disaster Recovery Policies

- Asset Management Policies

All networking activities shall comply with enterprise governance and cybersecurity requirements.

# Security Responsibilities

The Network Engineer:

- Configures firewall rules
- Maintains network segmentation
- Secures remote access
- Protects network infrastructure
- Monitors network threats
- Implements secure routing
- Supports vulnerability remediation
- Maintains secure network configurations

Network security shall follow zero-trust architecture and organizational cybersecurity standards.

# Risk Management Responsibilities

The Network Engineer monitors:

- Network Outages
- Internet Connectivity Risks
- Firewall Failures
- Routing Failures
- Network Congestion
- Bandwidth Utilization
- Security Threats
- VPN Availability Risks
- Hardware Failures
- Disaster Recovery Risks

Critical network incidents shall be escalated immediately to the Infrastructure Manager.

# Decision Authority

The Network Engineer may independently approve:

- Standard network configuration changes
- Routine firewall rule updates
- Network monitoring improvements
- Performance tuning
- Documentation updates
- Scheduled maintenance activities
- Network troubleshooting actions
- Routine firmware upgrades

Enterprise network architecture changes, core infrastructure redesign, major security policy modifications, and large-scale networking investments require approval from the Infrastructure Manager or Head of Information Technology.

| Security Compliance | Eliminate critical network vulnerabilities |
