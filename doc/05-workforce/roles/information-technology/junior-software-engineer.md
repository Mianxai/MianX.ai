# Junior Software Engineer

> This document defines the responsibilities, authority, expectations, and performance standards of the Junior Software Engineer at MIANX.

The Junior Software Engineer is responsible for assisting in the design, development, testing, debugging, documentation, and maintenance of enterprise software applications while learning engineering best practices, collaborating with senior engineers, and contributing to secure, reliable, and scalable software solutions.

The Junior Software Engineer reports directly to the Technical Lead.

---

# Purpose

The purpose of the Junior Software Engineer role is to develop foundational software engineering skills while contributing to enterprise software projects under the guidance of experienced engineering professionals.

---

# Mission

The Junior Software Engineer exists to:

- Learn enterprise software development
- Deliver quality code
- Support engineering teams
- Improve technical knowledge
- Follow engineering standards
- Solve technical problems
- Build reliable software
- Grow into a professional software engineer

---

# Role Summary

The Junior Software Engineer contributes to:

- Software Development
- Bug Fixes
- Feature Implementation
- Unit Testing
- Code Reviews
- Technical Documentation
- API Development
- Database Integration
- Software Maintenance
- Sprint Activities
- Production Support
- Continuous Learning

---

# Primary Responsibilities

The Junior Software Engineer is responsible for:

- Developing assigned software features
- Fixing software bugs
- Writing clean and readable code
- Participating in code reviews
- Writing unit tests
- Maintaining technical documentation
- Assisting with application debugging
- Supporting software deployments
- Learning engineering standards
- Collaborating with engineering teams
- Following development processes
- Continuously improving technical skills

---

# Engineering Responsibilities

The Junior Software Engineer assists in developing:

- Web Applications
- Backend Services
- Frontend Components
- REST APIs
- Database Queries
- Business Logic
- Internal Tools
- Software Utilities
- Automated Tests
- Technical Documentation

Engineering work shall prioritize quality, security, maintainability, and continuous learning.

---

# Governance Responsibilities

The Junior Software Engineer complies with:

- Software Development Lifecycle (SDLC)
- Coding Standards
- Secure Coding Standards
- Source Control Policies
- Code Review Guidelines
- Documentation Standards
- Testing Standards
- Information Security Policies
- Change Management Procedures
- Engineering Best Practices

All assigned work must comply with organizational engineering and security requirements.

---

# Technical Responsibilities

The Junior Software Engineer:

- Implements assigned development tasks
- Writes maintainable source code
- Resolves basic software defects
- Assists with debugging
- Supports testing activities
- Updates documentation
- Participates in sprint planning
- Learns enterprise technologies

---

# Risk Management Responsibilities

The Junior Software Engineer monitors:

- Software Bugs
- Coding Errors
- Security Issues
- Performance Problems
- Integration Errors
- Data Validation Issues
- Deployment Failures
- Documentation Gaps
- Testing Deficiencies
- Application Stability Risks

Any significant technical issue shall be reported immediately to the Technical Lead or Software Engineer.

---

# Operational Responsibilities

The Junior Software Engineer supports:

- Sprint Development
- Feature Implementation
- Bug Resolution
- Unit Testing
- Documentation Updates
- Code Reviews
- Software Releases
- Production Monitoring
- Incident Resolution
- Continuous Improvement

Operational activities support reliable software delivery and stable enterprise applications.

---

# Collaboration

The Junior Software Engineer collaborates with:

- Technical Lead
- Senior Software Engineer
- Software Engineer
- Software Architect
- QA Engineers
- DevOps Engineers
- Product Managers
- Business Systems Analysts
- UX/UI Designers
- Information Security Team

Regular collaboration supports knowledge sharing and successful software delivery.

---

# Decision Authority

The Junior Software Engineer may independently approve:

- Assigned development tasks
- Documentation updates
- Unit test implementation
- Minor bug fixes
- Code improvements within assigned scope
- Development estimates for assigned work
- Internal development notes
- Personal task prioritization

Architectural decisions, framework selection, production deployments, infrastructure changes, and major implementation changes require approval from the Technical Lead or Senior Software Engineer.

---

# Core Competencies

The Junior Software Engineer should demonstrate knowledge of:

- Programming Fundamentals
- Object-Oriented Programming
- Software Development
- Git Version Control
- SQL Fundamentals
- REST APIs
- Unit Testing
- Debugging
- Secure Coding Basics
- Problem Solving
- Communication
- Teamwork

# Performance Expectations

The Junior Software Engineer is expected to:

- Complete assigned development tasks
- Produce maintainable code
- Learn engineering standards quickly
- Improve technical competency
- Participate actively in team activities
- Deliver work on schedule
- Support software quality
- Demonstrate continuous professional growth
