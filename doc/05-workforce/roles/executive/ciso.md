# Chief Information Security Officer (CISO)

> This document defines the responsibilities, authority, and expectations of the Chief Information Security Officer (CISO) at MIANX. The CISO is responsible for protecting the company's information, infrastructure, products, AI systems, employees, and customers from cybersecurity threats while ensuring compliance, resilience, and trust.

As an AI-first technology company, MIANX's CISO is responsible for securing not only traditional IT systems but also cloud platforms, AI infrastructure, developer environments, APIs, and software supply chains.

---

# Purpose

The purpose of the CISO role is to establish and maintain a comprehensive security program that enables innovation while protecting MIANX's people, technology, data, and reputation.

---

# Mission

The CISO exists to:

- Protect company assets
- Secure customer data
- Reduce cyber risk
- Build secure products
- Ensure regulatory compliance
- Improve organizational resilience
- Strengthen security culture
- Enable secure innovation

---

# Role Summary

The CISO leads every security function across MIANX.

The CISO ensures that:

- Security is integrated into every product
- Infrastructure remains protected
- Risks are identified early
- Compliance requirements are satisfied
- Incidents are handled effectively
- Security awareness becomes part of company culture

# Key Performance Indicators (KPIs)

| KPI | Objective |
|------|-----------|
| Critical Vulnerabilities | Continuous reduction |
| Mean Time to Detect (MTTD) | Faster threat detection |
| Mean Time to Respond (MTTR) | Faster incident response |
| Security Incident Rate | Minimize incidents |
| Compliance Score | Maintain regulatory compliance |
| Security Awareness Completion | 100% workforce participation |
| Patch Compliance | Timely security updates |
| Identity Compliance | Strong access governance |
| Third-Party Risk Reviews | Secure vendor ecosystem |
