# Mianx.ai Automation Engine Compliance Framework

> **Compliance is an applicability-driven control and Evidence
> discipline, not a documentation label.**
>
> Permanent:
>
> ```text
> DOCUMENTED
> CONTROL
> ≠
> COMPLIANCE
> PROVEN
> ```
>
> and:
>
> ```text
> COMPLIANCE
> CLAIM
> ≠
> CERTIFICATION
> ```

---

# 1. Purpose

This document defines:

```text
doc/24-automation-engine/governance/compliance.md
```

It establishes the detailed compliance model for the Automation Engine.

---

# 2. Compliance Mission

The mission is:

> **Identify applicable obligations, map them to accountable controls,
> preserve verifiable Evidence, detect deficiencies and prevent
> Automation from exceeding legal, contractual, privacy, Security or
> governance boundaries.**
