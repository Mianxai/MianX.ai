# 1. Purpose

This document defines the target Usage Cost framework for Mianx.ai Model Management.

It establishes:

1. Usage Cost identity.
2. raw usage events.
3. normalized usage.
4. Provider pricing references.
5. internal infrastructure pricing references.
6. token cost.
7. request cost.
8. multimodal usage cost.
9. cache cost.
10. batch cost.
11. RAG cost.
12. Memory cost.
13. Tool cost.
14. Agent cost.
15. Multi-Agent cost.
16. retry cost.
17. fallback cost.
18. Fine-Tuning cost.
19. evaluation cost.
20. Benchmark cost.
21. Research cost.
22. Project/Tenant attribution.
23. shared-cost allocation.
24. estimated versus actual cost.
25. reconciliation.
26. corrections.
27. dashboards and reporting.
28. chargeback/showback.
29. Audit.
30. Runtime Truth boundaries.

# 2. Non-Goals

This document does not:

* define actual Provider prices.
* define approved Model budgets.
* define tax treatment.
* define accounting standards.
* guarantee invoice accuracy.
* authorize Provider purchases.
* authorize Model use.
* authorize Project or Tenant access.
* prove current cost metering exists.
* prove chargeback exists.
* equate usage with value.
* equate Provider-reported usage with invoice truth.
* define universal allocation methodology.
* define Production authorization.
