# Founder Admin User Guide (Phase I)

## Primary navigation (Founder Mode)

1. **Home** — what is happening, next action, readiness
2. **Projects** — select the active project (isolation boundary)
3. **Objectives** — business goals
4. **Founder Proof** — guided Level-1 proof path
5. **Founder Inbox** — approvals and attention items
6. **Workforce** — readiness truth (catalogue / executable / capacity)
7. **Results** — outputs, analytics, memory, learning

**Advanced Operations** stays collapsed by default (Runtime, Queue, Full Audit, Technical Settings).

## Page structure (every Founder surface)

1. What is happening
2. What needs my attention
3. What will happen after clicking
4. What will not happen
5. Primary action
6. Progress
7. Results
8. Advanced / Technical details (collapsed)

## Founder Proof vs Runtime

- **Founder Proof** — guided deterministic path for a project objective (simulation, evidence, memory/learning, final review).
- **Runtime / Queue** — Advanced Operations for job ticks and instances. Not required to complete Level-1 Founder Proof.

## What never happens automatically

- Production deploy / `production_deployment`
- Sending email
- Auto-approving protected actions
- Auto-promoting memory or learning
- Calling Anthropic when unconfigured (Level-1 stays deterministic)
- Creating a second Founder Proof while one is active
