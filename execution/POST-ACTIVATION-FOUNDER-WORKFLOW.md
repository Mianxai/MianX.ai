# Post-Activation Founder Workflow

After migration, bootstrap, OpenRouter key, and controlled activation succeed:

## Normal flow

1. **Home** — open Admin Control Center  
2. **New Objective** — describe the work in plain language  
3. **MianX analyses objective** — classification + workflow family  
4. **MianX proposes project team** — seats allocated from the 445 capacity pool  
5. **Founder reviews plan** — scope, roles, budgets  
6. **Founder approves plan** — protected actions only  
7. **Agents allocate** — durable project instances + leases  
8. **Work enters queue** — scheduler / Run tick processes jobs  
9. **Agents execute** — free-only OpenRouter by default  
10. **Independent QA reviews** — producer cannot self-approve  
11. **Founder Inbox** — protected decisions only  
12. **Results** — outputs + evidence pack  

## Founder must not manually

- Create every seat  
- Register every agent  
- Assign all tasks  
- Manage leases  
- Enqueue internal jobs by hand  
- Edit raw JSON contracts  
- Choose every model  
- Inspect raw provider responses  

Capacity seats remain **ready to allocate** until assigned. **Live tested** only grows with durable provider evidence.
