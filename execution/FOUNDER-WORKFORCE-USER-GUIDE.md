# Founder Workforce User Guide

## What “445 seats” means

MianX has 445 workforce seats ready to allocate. They are **not** 445 robots running all day. When you start an objective, MianX picks only the specialists that objective needs.

## How to start work

1. Open **Home** or **Objectives**  
2. Describe what you want in plain language  
3. Review the proposed plan (who will work, what approvals are needed)  
4. Approve the plan  
5. Watch progress under **Results** and **Founder Inbox**

You do **not** need to register agents, edit JSON, or open Advanced Operations.

## Approvals

Some actions (send email, deploy, spend, legal commitments) always come back to you. Agents cannot approve their own important work — another reviewer checks first.

## Outputs and evidence

Finished work appears in Results with sources and evidence. If something looks unsupported, send it back for revision.

## Memory and learning

Agents may propose memories and improvements. Nothing becomes trusted policy automatically.

## Pause or stop

Use project controls / Inbox to pause or cancel. Capacity seats return to available when work releases.
