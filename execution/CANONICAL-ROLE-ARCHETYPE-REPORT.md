# Canonical Role Archetype Report

Archetypes compile from:

1. Named workforce definitions (`lib/workforce/definitions.js`)
2. Executable runtime catalogue agents not already linked
3. Department team pool archetypes for justified capacity expansion

Each archetype includes id, version, title, department, hierarchy, reportsTo, mission, responsibilities, capabilities, knowledge domains, I/O/evidence schemas, tools, protected actions, provider capability profile, memory/learning/delegation/QA policies, workload limits, risk, escalation, project-scoped flag, source refs, contract checksum, lifecycle.

**Fabrications: 0.** Pool archetypes are not personal filler names — they are documented department capacity pools.
